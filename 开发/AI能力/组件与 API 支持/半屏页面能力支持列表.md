# [#](#半屏页面能力支持列表) 半屏页面能力支持列表

半屏页面可使用能力几乎与小程序的完全一致，但会有一些约束，以下从新增 API 和原有 API 两个维度分别列出所有支持的 API

## [#](#新增-API) 新增 API

1. 上行消息：`wx.modelContext.getContext().sendFollowUpMessage({ content })`
2. 获取左上角关闭按钮位置信息：`wx.getDetailPageCloseButtonBoundingClientRect()`
3. 从半屏页面返回并更新卡片：`wx.modelContext.getContext().reapplyApiCall({ arguments })`
