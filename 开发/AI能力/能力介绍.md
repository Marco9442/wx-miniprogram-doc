# [#](#小程序-AI-开发模式（beta）接入指南) 小程序 AI 开发模式（beta）接入指南

小程序 AI 开发模式（以下简称此模式）提供了一套智能化的运行环境和开发框架，开发者基于该框架，将小程序的功能抽象为原子接口和原子组件，并封装成 `SKILL`，供小程序 AI 调用。

当用户通过小程序 AI 发起对话时，小程序 AI 会通过小程序 MCP 协议分析并选择合适的原子接口和原子组件，完成数据处理和任务执行，最终整合结果给到用户。

用户在此模式下的登录身份跟原小程序保持一致，开发者可以通过 `storage` 接口共享小程序内的登录凭证，也可以通过 `wx.login`、`wx.getPhoneNumber` 等接口完成登录流程。

> 注意事项：
>
> 当前处于内测阶段，暂未开放小程序 AI 开发模式的代码提审，提审时间将另行通知。请勿将此模式相关代码合入正式版本提交审核，以免影响正常版本发布。

## [#](#基本概念) 基本概念

### [#](#_1、小程序-MCP) 1、小程序 MCP

小程序 MCP 是向小程序 AI 暴露可调用能力的一套协议，与标准 MCP 不同，小程序 MCP 适应于小程序开发的特点，开发者只需要按设计提供完整的 `SKILL` 实现，小程序 AI 就能正确地推理及执行相应的原子接口，最终完成用户的需求。

### [#](#_2、原子接口) 2、原子接口

此模式的最小执行单元，封装单一的业务功能，具有标准化输入参数和输出结构，运行在微信客户端的独立 JS 环境中。

### [#](#_3、原子组件) 3、原子组件

原子接口的可视化展示单元，将原子接口返回的结构化数据渲染为 GUI 卡片，展示在对话流中。

> 暂不支持调试

### [#](#_4、页面接力) 4、页面接力

原子接口在小程序内可视化展示的实现方式，将原子接口返回的结构化数据传递到小程序中，展示在页面中。

用户发送对话后，小程序AI会根据原子接口、知识库等内容输出文本回复和小程序「账号卡片」回复，用户轻触小程序「账号卡片」可进入对应的接力页面。

> 建议开发者针对原子接口配置好对应接力页面，配置的页面信息会影响评测结果，从而对小程序AI调用效果产生影响。

### [#](#_5、SKILL) 5、SKILL

完成特定场景任务的完整能力封装，一个小程序可封装多个 `SKILLs`，每个 `SKILL` 包含：业务说明（`SKILL.md`）、模型可调用能力的声明（`mcp.json`）、原子接口与原子组件的实现。

## [#](#开发指南) 开发指南

### [#](#申请开启) 申请开启

在网页端「微信公众平台 - 基础功能 - AI能力」或小程序「微信开发者助手」中「管理 - 微信AI管理」中的接入模式选择「开发模式」进行申请。

### [#](#接入方式) 接入方式

开发者可参考 [接入方式](integration) ，将小程序的功能抽象为原子接口和原子组件，并封装成 `SKILL`，供小程序 AI 调用。

### [#](#运行机制) 运行机制

此模式的运行机制涉及微信客户端运行时、小程序 AI 后台、第三方服务之间的交互，其中原子接口、原子组件在微信客户端的执行环境是独立的，不同于小程序运行环境的，具体机制可参考[运行机制](operating-mechanism)

### [#](#调试指南) 调试指南

开发接入需下载安装 [微信开发者工具（Nightly Electron Build 最新版本）](https://developers.weixin.qq.com/miniprogram/dev/devtools/log#nightly)，具体开发调试过程操作指引请参考 [调试指南](debugging)

### [#](#最佳实践) 最佳实践

如何封装好 `SKILL`，使得小程序 AI 能够准确地识别用户意图，提供更好的用户体验，可参考[最佳实践](best-practices)

### [#](#组件与-API-支持) 组件与 API 支持

此模式下提供的接口能力，在用法上，基本与小程序环境下的保持一致。相比于小程序环境下的接口，此模式新增了若干特有 API，以及支持了原有的绝大部分内置组件与 API，具体可参考[组件与 API 支持](reference/component)

## [#](#示例-Demo) 示例 Demo

我们提供一个使用了完整能力的[示例 demo](https://github.com/wechat-miniprogram/ai-mode-demo)，可通过微信开发者工具打开，预览体验。

> 注意：demo 代码的 appid 需改成在「微信公众平台 - 基础功能 - AI 能力」申请了「开发模式」的 appid
