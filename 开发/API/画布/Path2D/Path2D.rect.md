# [#](#Path2D-rect-number-x-number-y-number-width-number-height) Path2D.rect(number x, number y, number width, number height)

> 基础库 2.11.0 开始支持，低版本需做[兼容处理](../../framework/compatibility.html)。

> **小程序插件**：不支持

> 相关文档: [画布指南](../../framework/ability/canvas.html)、[canvas 组件介绍](../../component/canvas.html)

## [#](#功能描述) 功能描述

添加方形路径。

## [#](#参数) 参数

### [#](#number-x) number x

开始点横坐标。

### [#](#number-y) number y

开始点纵坐标。

### [#](#number-width) number width

方形宽度，正数向右，负数向左。

### [#](#number-height) number height

方形高度，正数向下，负数向上。

Incorrect translation.
