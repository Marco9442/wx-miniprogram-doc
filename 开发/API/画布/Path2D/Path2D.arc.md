# [#](#Path2D-arc-number-x-number-y-number-radius-number-startAngle-number-endAngle-boolean-counterclockwise) Path2D.arc(number x, number y, number radius, number startAngle, number endAngle, boolean counterclockwise)

> 基础库 2.11.0 开始支持，低版本需做[兼容处理](../../framework/compatibility.html)。

> **小程序插件**：不支持

> 相关文档: [画布指南](../../framework/ability/canvas.html)、[canvas 组件介绍](../../component/canvas.html)

## [#](#功能描述) 功能描述

添加一段圆弧路径。

## [#](#参数) 参数

### [#](#number-x) number x

圆心横坐标。

### [#](#number-y) number y

圆心纵坐标。

### [#](#number-radius) number radius

圆形半径，必须为正数。

### [#](#number-startAngle) number startAngle

圆弧开始角度。

### [#](#number-endAngle) number endAngle

圆弧结束角度。

### [#](#boolean-counterclockwise) boolean counterclockwise

是否逆时针绘制。如果传 true, 则会从 endAngle 开始绘制到 startAngle。

Incorrect translation.
