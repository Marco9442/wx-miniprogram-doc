# [#](#CanvasContext-setTransform-number-scaleX-number-skewX-number-skewY-number-scaleY-number-translateX-number-translateY) CanvasContext.setTransform(number scaleX, number skewX, number skewY, number scaleY, number translateX, number translateY)

CanvasContext 是旧版的接口，新版 [Canvas 2D](../../component/canvas.html) 接口与 Web 一致

从基础库 [2.9.0](../../framework/compatibility.html) 开始，本接口停止维护，请使用 [RenderingContext](RenderingContext.html) 代替

> 基础库 1.9.90 开始支持，低版本需做[兼容处理](../../framework/compatibility.html)。

> **小程序插件**：支持

> 相关文档: [旧版画布迁移指南](../../framework/ability/canvas-legacy-migration.html)、[canvas 组件介绍](../../component/canvas.html)

## [#](#功能描述) 功能描述

使用矩阵重新设置（覆盖）当前变换的方法

## [#](#参数) 参数

### [#](#number-scaleX) number scaleX

水平缩放

### [#](#number-skewX) number skewX

水平倾斜

### [#](#number-skewY) number skewY

垂直倾斜

### [#](#number-scaleY) number scaleY

垂直缩放

### [#](#number-translateX) number translateX

水平移动

### [#](#number-translateY) number translateY

垂直移动

Incorrect translation.
