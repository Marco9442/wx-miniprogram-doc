# [#](#CanvasContext-arcTo-number-x1-number-y1-number-x2-number-y2-number-radius) CanvasContext.arcTo(number x1, number y1, number x2, number y2, number radius)

CanvasContext 是旧版的接口，新版 [Canvas 2D](../../component/canvas.html) 接口与 Web 一致

从基础库 [2.9.0](../../framework/compatibility.html) 开始，本接口停止维护，请使用 [RenderingContext](RenderingContext.html) 代替

> 基础库 1.9.90 开始支持，低版本需做[兼容处理](../../framework/compatibility.html)。

> **小程序插件**：支持

> 相关文档: [旧版画布迁移指南](../../framework/ability/canvas-legacy-migration.html)、[canvas 组件介绍](../../component/canvas.html)

## [#](#功能描述) 功能描述

根据控制点和半径绘制圆弧路径。

## [#](#参数) 参数

### [#](#number-x1) number x1

第一个控制点的 x 轴坐标

### [#](#number-y1) number y1

第一个控制点的 y 轴坐标

### [#](#number-x2) number x2

第二个控制点的 x 轴坐标

### [#](#number-y2) number y2

第二个控制点的 y 轴坐标

### [#](#number-radius) number radius

圆弧的半径

Incorrect translation.
