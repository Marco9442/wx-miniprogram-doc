## [#](#功能描述) 功能描述

对 xyz 坐标进行平移变换

## [#](#参数) 参数

### [#](#number-tx) number tx

在 X 轴平移的距离，单位为 px

### [#](#number-ty) number ty

在 Y 轴平移的距离，单位为 px

### [#](#number-tz) number tz

在 Z 轴平移的距离，单位为 px

## [#](#返回值) 返回值

### [#](#Animation) [Animation](Animation.html)

Incorrect translation.
