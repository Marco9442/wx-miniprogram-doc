## [#](#功能描述) 功能描述

从 固定 轴顺时针旋转一个角度

## [#](#参数) 参数

### [#](#number-x) number x

旋转轴的 x 坐标

### [#](#number-y) number y

旋转轴的 y 坐标

### [#](#number-z) number z

旋转轴的 z 坐标

### [#](#number-angle) number angle

旋转的角度。范围 [-180, 180]

## [#](#返回值) 返回值

### [#](#Animation) [Animation](Animation.html)

Incorrect translation.
