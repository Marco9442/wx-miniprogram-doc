# [#](#worklet-cancelAnimation-SharedValue-SharedValue) worklet.cancelAnimation(SharedValue SharedValue)

> **小程序插件**：不支持

> 相关文档: [worklet 动画](../../../../framework/runtime/skyline/worklet.html)

## [#](#功能描述) 功能描述

取消由 `SharedValue` 驱动的动画。

## [#](#参数) 参数

### [#](#SharedValue-SharedValue) SharedValue SharedValue

共享变量。

## [#](#示例代码) 示例代码

```
const { shared, timing, cancelAnimation } = wx.worklet
const offset = shared(0);
offset.value = timing(100);
cancelAnimation(offset)
```
