# [#](#VKSession-cancelAnimationFrame-number-requestID) VKSession.cancelAnimationFrame(number requestID)

> 基础库 2.20.0 开始支持，低版本需做[兼容处理](../../../framework/compatibility.html)。

> **小程序插件**：支持，需要小程序基础库版本不低于 [2.20.0](../../../framework/compatibility.html)

## [#](#功能描述) 功能描述

取消由 requestAnimationFrame 添加到计划中的动画帧请求。

### [#](#number-requestID) number requestID

Incorrect translation.
