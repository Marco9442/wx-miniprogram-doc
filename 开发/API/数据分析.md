# [#](#wx-reportMonitor-string-name-number-value) wx.reportMonitor(string name, number value)

从基础库 [2.31.1](../../framework/compatibility.html) 开始，本接口停止维护，请使用 [wx.reportEvent](wx.reportEvent.html) 代替

> 基础库 2.0.1 开始支持，低版本需做[兼容处理](../../framework/compatibility.html)。

> **小程序插件**：不支持
>
> **微信 Windows 版**：支持
>
> **微信 Mac 版**：支持
>
> **微信 鸿蒙 OS 版**：支持

## [#](#功能描述) 功能描述

自定义业务数据监控上报接口。

## [#](#参数) 参数

### [#](#string-name) string name

监控ID，在「小程序管理后台」新建数据指标后获得

### [#](#number-value) number value

上报数值，经处理后会在「小程序管理后台」上展示每分钟的上报总量

## [#](#使用说明) 使用说明

使用前，需要在「小程序管理后台-运维中心-性能监控-业务数据监控」中新建监控事件，配置监控描述与告警类型。每一个监控事件对应唯一的监控ID，开发者最多可以创建128个监控事件。

## [#](#示例代码) 示例代码

```
wx.reportMonitor('1', 1)
```
