# [#](#AudioContext-wx-createAudioContext-string-id-Object-this) [AudioContext](AudioContext.html) wx.createAudioContext(string id, Object this)

从基础库 [1.6.0](../../../framework/compatibility.html) 开始，本接口停止维护，请使用 [wx.createInnerAudioContext](wx.createInnerAudioContext.html) 代替

> **小程序插件**：支持，需要小程序基础库版本不低于 [1.9.6](../../../framework/compatibility.html)

## [#](#功能描述) 功能描述

创建 [audio](../../../component/audio.html) 上下文 [AudioContext](AudioContext.html) 对象。

## [#](#参数) 参数

### [#](#string-id) string id

[audio](../../../component/audio.html) 组件的 id

### [#](#Object-this) Object this

在自定义组件下，当前组件实例的this，以操作组件内 [audio](../../../component/audio.html) 组件

## [#](#返回值) 返回值

### [#](#AudioContext) [AudioContext](AudioContext.html)

Incorrect translation.
