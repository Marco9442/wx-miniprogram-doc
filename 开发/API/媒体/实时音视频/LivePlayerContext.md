# [#](#LivePlayerContext) LivePlayerContext

> 相关文档: [live-player 组件](../../../component/live-player.html)

`LivePlayerContext` 实例，可通过 [wx.createLivePlayerContext](wx.createLivePlayerContext.html) 获取。
