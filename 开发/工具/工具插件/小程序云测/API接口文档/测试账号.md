## [#](#获取绑定测试账号) 获取绑定测试账号

#### [#](#简要描述) 简要描述

- 查询项目已绑定的微信测试账号列表，其中 nickname 字段可用于提交任务时指定测试账号

#### [#](#请求URL) 请求URL

- `https://minitest.weixin.qq.com/thirdapi/account/entity_accounts`

#### [#](#请求方式) 请求方式

- GET

#### [#](#参数) 参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| **token** | 是 | string | 可以从页面右上角头像右侧下拉菜单中的 “我的信息” 获取 |
| **group\_en\_id** | 是 | string | 项目英文ID，可在 项目管理/产品管理 页面获取 |
