# [#](#真机调试性能工具) 真机调试性能工具

真机调试支持录制小程序/小程序真机性能

## [#](#_1-环境要求) 1. 环境要求

- Android: 微信客户端版本 **8.0.54** 及以上
- iOS：暂未支持
- 工具：**1.06.2412040** 版本及以上
- 基础库：**3.7.4** 版本及以上

## [#](#_2-录制流程) 2. 录制流程

### [#](#_2-1-打开真机调试-2-0) 2.1. 打开真机调试 2.0

参考 [真机调试2.0](remote-debug-2) 文档。

### [#](#_2-2-找到-Performance-面板) 2.2. 找到 Performance 面板

![](https://res8.wxqcloud.qq.com.cn/wxdoc/1e4c1e56-d770-4255-b2b0-c0400d8b8976.png)

点击开始录制按钮即可开始录制小程序性能

![](https://res8.wxqcloud.qq.com.cn/wxdoc/1e4c1e56-d770-4255-b2b0-c0400d8b8976.png)

之后点击停止录制即可查看录制结果

![](https://res8.wxqcloud.qq.com.cn/wxdoc/98f035c0-ab21-465d-8e76-51a70aa11a92.png)

## [#](#_3-录制冷启动) 3. 录制冷启动

点击重启并录制按钮，客户端将会自动重启开始录制，之后结束录制即可看到启动时的性能录制结果

![](https://res8.wxqcloud.qq.com.cn/wxdoc/f90fc731-6416-4d5c-8eb8-8d810c8a875f.png)

## [#](#_4-性能类别解读) 4. 性能类别解读

- JS Engine： 小程序/小游戏逻辑层的 JS 运行火焰图，包含了基础库以及小程序代码的执行情况
- Performance： 小程序/小游戏关键事件，路由跳转以及 wx 接口调用等
- Component Framework： 小程序组件系统的分组件性能信息，需要使用 develop 基础库，暂只支持 skyline
- 页面路径：具体页面的绘制层运行关键事件
- nt.mm:appbrand：微信客户端的关键事件
