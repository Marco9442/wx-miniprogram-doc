# [#](#功能描述) 功能描述

开发者工具需要使用微信号登录，我们以此账号作为所有打开的项目的主账号，当登录的账号改变时，其登录态将同步到所有已打开的项目窗口；
当小程序/小游戏需要多个微信号才能共同完成一项工作的话，我们提供了多账号调试的功能。

## [#](#功能入口) 功能入口

通过 菜单 - 工具 - 多账号调试 可以使用多账号调试功能
