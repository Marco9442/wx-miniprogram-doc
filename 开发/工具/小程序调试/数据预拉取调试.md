# [#](#功能概述) 功能概述

为了方便调试数据预拉取，工具提供了下面的调试能力给到开发者

### [#](#工具触发数据预拉取) 工具触发数据预拉取

目前在新版开发者工具（1.02.1911202及以上版本）本地设置中新增设置 `启用数据预拉取`, 设置后开发者工具会在小程序运行时向用户配置的预拉取数据下载地址请求数据，如下图所示：
![](https://res8.wxqcloud.qq.com.cn/wxdoc/885ec20f-60fd-4b03-adeb-d49c07d6210b.png)

### [#](#工具清除预拉取数据) 工具清除预拉取数据

如果需要清除工具缓存的预拉取数据，可以通过点击工具栏的 `清除数据缓存` 或者 `全部清除` 来进行清除。

### [#](#常规错误情况) 常规错误情况

#### [#](#没有设置-TOKEN) 没有设置 TOKEN

当出现 `token not set, maybe you should setBackgroundFetchToken first` 错误信息，表示当前小程序没有主动去设置预拉取数据所需要的 TOKEN 信息。这边可以查看下面文档[周期性数据调试](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/pre-fetch)。

#### [#](#_10007-no-permission) -10007 no permission

当出现该情况标识没有拉取的权限，可以查看下面文档[周期性数据调试](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/background-fetch) 来配置数据周期性更新的能力。
