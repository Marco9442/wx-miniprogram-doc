为了让开发者更方便开发小程序，开发者工具提供了对音视频处理相关的小程序API的支持

> 工具从 1.03.2004292 版本开始，支持了音视频合成API

## [#](#运行环境) 运行环境

- 下载并安装ffmpeg

## [#](#安装ffmpeg步骤) 安装ffmpeg步骤

### [#](#Mac) Mac

Mac可以直接使用homebrew安装ffmpeg

打开终端输入以下内容并运行

```
brew install ffmpeg
```

### [#](#Windows) Windows

前往官网下载ffmpeg并安装 [下载地址](https://www.ffmpeg.org/download.html)

![下载入口](https://res8.wxqcloud.qq.com.cn/wxdoc/1f17079c-c0f3-448b-af49-cd271da09411.png)

选择static版本

![下载static版本](https://res8.wxqcloud.qq.com.cn/wxdoc/67436d73-df3b-4845-8545-ca68faca3d72.png)

下载解压到所选目录后，配置环境变量

1. 单击此电脑，单击右键
2. 单击菜单里的属性，单击高级系统设置
3. 单击环境变量。在用户变量里，找到并选择 Path 环境变量，单击编辑。如果 Path 环境变量不存在，请单击新建。
4. 在编辑用户变量（或新建用户变量）窗口中，ffmpeg解压后的路径\bin，单击确定保存。
   ![配置环境变量](https://res8.wxqcloud.qq.com.cn/wxdoc/b259b5b2-6ccb-4737-a493-3d6025f93005.png)

配置完成后，打开终端输入以下命令，能正确输出信息后，重启微信开发者工具即可

```
ffmpeg -version
```
