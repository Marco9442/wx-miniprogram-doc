## [#](#TDesign) TDesign

TDesign 小程序组件库，遵循微信小程序设计指南，由腾讯内部多个 BG 和团队联合打造而成，帮助小程序开发者和设计师快速搭建体验优异的微信小程序。组件库代码现已在 GitHub 正式开源，欢迎使用、Star、提 Issue 或参与共建。
