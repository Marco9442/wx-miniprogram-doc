# [#](#上传文件) 上传文件

将网页内文件对象上传至对象存储空间，如果上传至同一路径则是覆盖写

本文档适用于微信公众号H5中使用，如果你不是微信公众号H5，请移步适合的文档

- [微信小程序](../miniapp/upload)
- [服务端和其他客户端](../service/upload)

## [#](#请求参数) 请求参数

| 字段 | 说明 | 数据类型 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| cloudPath | 云存储路径，命名限制见[文件名命名限制](../../../guide/storage/manage) | String | - | 是 |
| file | 要上传文件资源的路径 | [File](https://developer.mozilla.org/en-US/docs/Web/API/File) | - | 是 |
| config | 配置 | Object | - | 否 |
| success | 成功回调 |  |  |  |
| fail | 失败回调 |  |  |  |
| complete | 结束回调 |  |  |  |

#### [#](#config-对象定义) config 对象定义

| 字段 | 说明 | 数据类型 |
| --- | --- | --- |
| env | 使用的环境 ID，填写后忽略 init 指定的环境 | String |

#### [#](#success-返回参数) success 返回参数

| 字段 | 说明 | 数据类型 |
| --- | --- | --- |
| fileID | 文件 ID | String |
| statusCode | 服务器返回的 HTTP 状态码 | Number |
| errMsg | 错误信息，格式 uploadFile:ok | String |

#### [#](#fail-返回参数) fail 返回参数

| 字段 | 说明 | 数据类型 |
| --- | --- | --- |
| errCode | [错误码](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/reference/errcode) | Number |
| errMsg | 错误信息，格式 uploadFile:fail msg | String |

## [#](#使用示例) 使用示例

#### [#](#_1-Callback-风格) 1. Callback 风格

```
cloud.uploadFile({
  cloudPath: 'example.png', // 对象存储路径，根路径直接填文件名，文件夹例子 test/文件名，不要 / 开头
  file: new File(), // 通过 input 或者 new File 获取
  config: {
    env: 'werun-id' // 需要替换成自己的微信云托管环境ID
  }
  success: res => {
    console.log(res.fileID)
  },
  fail: err => {
    console.error(err)
  }
})
```

#### [#](#_2-Promise-风格) 2. Promise 风格

```
cloud.uploadFile({
  cloudPath: 'example.png', // 对象存储路径，根路径直接填文件名，文件夹例子 test/文件名，不要 / 开头
  file: new File(), // 通过 input 或者 new File 获取
  config: {
    env: 'werun-id' // 需要替换成自己的微信云托管环境ID
  }
}).then(res => {
  console.log(res.fileID)
}).catch(error => {
  console.error(err)
})
```
