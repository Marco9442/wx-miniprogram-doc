# [#](#对象存储-公众号H5) 对象存储-公众号H5

在微信公众号H5网页中操作微信云托管对象存储，使用是[WEB-SDK](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/guide/web/sdk)方法对象

[WEB-SDK](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/guide/web/sdk)同时适用于微信云开发、微信云托管。

由于链路不同，SDK在支持微信云托管环境时会有一些调整，请以微信云托管文档为准，至于未明确提到的，可以按SDK文档使用。

需要注意，WEB-SDK需要替换引用此CDN文件

```
https://web-9gikcbug35bad3a8-1304825656.tcloudbaseapp.com/sdk/1.3.0/cloud.js
```

> **使用注意：**  
> WEB-SDK在未登录情况下操作对象存储，需要配置安全规则  
> WEB-SDK在登录时需要云开发云函数支持，具体参见[文档](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/basis/web)，所以WEB-SDK无法独立使用微信云托管环境完成有用户状态的运作，我们将尽快支持
