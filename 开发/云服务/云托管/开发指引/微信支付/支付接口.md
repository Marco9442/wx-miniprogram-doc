# [#](#支付接口) 支付接口

微信云托管通过[开放接口服务](../../../guide/weixin/open)封装了微信支付原有的接口，所以在使用前需要开启「开放接口服务」

要了解微信支付接口的运作和使用理论，请前往[使用指南](../../../guide/weixin/pay)

具体方法的详细文档如下：

| 接口名称 | 接口 | 需要 OpenID |
| --- | --- | --- |
| [统一下单](unified) | `http://api.weixin.qq.com/_/pay/unifiedOrder` | ✅ |
| [查询订单](query) | `http://api.weixin.qq.com/_/pay/queryorder` |  |
| [关闭订单](close) | `http://api.weixin.qq.com/_/pay/closeorder` |  |
| [下载对账单](bill) | `http://api.weixin.qq.com/_/pay/downloadbill` |  |
| [申请退款](refund) | `http://api.weixin.qq.com/_/pay/refund` | ✅ |
| [查询退款](queryrefund) | `http://api.weixin.qq.com/_/pay/queryrefund` |  |
