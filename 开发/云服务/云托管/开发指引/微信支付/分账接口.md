# [#](#分账接口) 分账接口

微信云托管通过[开放接口服务](../../../guide/weixin/open)封装了微信支付原有的接口，所以在使用前需要开启「开放接口服务」

要了解微信支付接口的运作和使用理论，请前往[使用指南](../../../guide/weixin/pay)

具体方法的详细文档如下：

| 接口名称 | 接口 | 需要 OpenID |
| --- | --- | --- |
| [添加分账接收方](addreceiver) | `http://api.weixin.qq.com/_/pay/profitsharingaddreceiver` |  |
| [删除分账接收方](delreceiver) | `http://api.weixin.qq.com/_/pay/profitsharingremovereceiver` |  |
| [请求单次分账](onesharing) | `http://api.weixin.qq.com/_/pay/profitsharing` |  |
| [请求多次分账](sharing) | `http://api.weixin.qq.com/_/pay/multiprofitsharing` |  |
| [完结分账](doneshare) | `http://api.weixin.qq.com/_/pay/profitsharingfinish` |  |
| [查询分账结果](queryshare) | `http://api.weixin.qq.com/_/pay/profitsharingquery` |  |
| [分账回退](refundshare) | `http://api.weixin.qq.com/_/pay/profitsharingreturn` |  |
| [回退结果查询](queryrefundshare) | `http://api.weixin.qq.com/_/pay/profitsharingreturnquery` |  |
