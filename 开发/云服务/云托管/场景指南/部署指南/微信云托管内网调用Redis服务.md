# [#](#微信云托管内网调用Redis服务) 微信云托管内网调用Redis服务

微信云托管目前已实现通过私有网络设置的方式打通腾讯云资源，实现与腾讯云资源内网调用。以下以Redis服务为例进行使用流程说明。

### [#](#步骤一：前往微信云托管绑定的腾讯云账号中，购买上海地域Redis服务；) 步骤一：前往微信云托管绑定的腾讯云账号中，购买**上海**地域Redis服务；

1. 微信云托管绑定的腾讯云账号登录，有以下2种方式可以登录

- 前往腾讯云控制台，点击登录，选择【小程序公众号】方式登录，使用微信扫一扫选择微信云托管对应的小程序或公众号，点击确认授权即可。![](https://res.wx.qq.com/op_res/TM37_5MDymIuwKBuQyRHTCV6MAQ0r0eEfgw37QbB-lyMmq6V6iKnhna5-0dI8DBPKfk1eCnl4F6wV6RXRnDOiw)
- 前往微信云托管控制台，选择对应的小程序或公众号账号，前往「费用中心-代金券-充值与账单」，即可获取对应腾讯云账号登录态，进入腾讯云控制台选择云数据库 Redis 服务；

2. 目前微信云托管服务部署在「上海」地域，VPC 私有网络设置暂不支持跨地域，如购买腾讯云Redis服务，请一定选择「上海」地域

### [#](#步骤二：前往「微信云托管控制台-服务详情-设置-私有网络设置」，设置对接腾讯云-VPC-私有网络；) 步骤二：前往「微信云托管控制台-服务详情-设置-私有网络设置」，设置对接腾讯云 VPC 私有网络；

- 1. 私有网络设置按服务进行设置，需要访问腾讯云资源的服务可以启用并设置私有网络；
- 2. 需要将服务设置到腾讯云资源所在的 VPC ，子网可以不用相同，同一 VPC 内子网间默认是互通的；
- 3. 访问腾讯云资源时，使用资源在 VPC 内的内网 IP 即可；

### [#](#步骤三：内网调用Redis服务) 步骤三：内网调用Redis服务

服务内可以通过通过腾讯云资源的内网IP进行调用。购买腾讯云资源服务时，腾讯云会分配一个固定的内网IP给到服务。使用该内网IP进行内网调用即可。
