# [#](#开发指引) 开发指引

云开发提供了一整套云服务及简单、易用的 API 和管理界面，以尽可能降低后端开发成本，让开发者能够专注于核心业务逻辑的开发、尽可能轻松的完成后端的操作和管理。

云开发是小程序的基础能力，如果你对小程序的了解程度不够，建议先阅读指南部分。

下面我们将分以下部分介绍如何上手使用云能力：

- [云开发控制台](console)：可视化的云资源管理器
- [初始化](init)：云 API 的初始化
- [数据库开发指引](database)：如何上手数据库开发
- [数据模型开发指引](model/quickstart)：如何上手数据模型开发
- [存储开发指引](storage)：如何上手云存储开发
- [云函数开发指引](functions)：如何上手云函数开发
