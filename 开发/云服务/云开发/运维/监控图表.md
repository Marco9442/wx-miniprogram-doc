## [#](#监控图表) 监控图表

开发者可以在**云开发控制台**的**监控图表**页面中，浏览各项云开发资源的使用情况。

监控数据的存储时长与监控粒度相关，最长支持半年内的监控数据查询。

| 监控粒度 | 储存时长 |
| --- | --- |
| 秒级 | 1天 |
| 1分钟 | 15天 |
| 5分钟 | 31天 |
| 1小时 | 93天 |
| 1天 | 186天 |

### [#](#云数据库) 云数据库

云数据库的监控图表中，包括以下指标：

- 读取次数
- 写入次数
- 耗时 10~50ms 请求数
- 耗时 50~100ms 请求数
- 耗时 100ms 以上请求数

### [#](#存储) 存储

存储的监控图表中，包括以下指标：

- 下载次数

- CDN 回源流量
