微信云开发

微信云开发是微信团队联合腾讯云推出的专业的小程序开发服务。

开发者可以使用云开发快速开发小程序、小游戏、公众号网页等，并且原生打通微信开放能力。

开发者无需搭建服务器，可免鉴权直接使用平台提供的 API 进行业务开发。

[前往官网](https://cloud.weixin.qq.com/cloudbase)
，了解更多信息

### 云开发优势

![](https://res8.wxqcloud.qq.com.cn/wxdoc/fcccf6bb-85a1-4e8a-af45-8c805341488b.png)

无需搭建服务器  
快速构建小程序、公众号

无需搭建服务器，只需使用平台提供的各项能力，即可快速开发业务。

![](https://res8.wxqcloud.qq.com.cn/wxdoc/1bc2b976-5935-48b5-8a85-29bf5b35d4f8.png)

免登录、免鉴权调用微信开放服务

无需管理证书、签名、秘钥，直接调用微信 API 。复用微信私有协议及链路，保证业务安全性。

![](https://res8.wxqcloud.qq.com.cn/wxdoc/feb31e84-3131-4b88-816e-098a29efdeb2.png)

统一开发多端应用

支持环境共享，一个后端环境可开发多个小程序、公众号、网页等，便捷复用业务代码与数据。

![](https://res8.wxqcloud.qq.com.cn/wxdoc/5bf70b5e-55b2-45c8-a8da-52685b13c7dc.png)

按量计费，成本更低

支持按量计费模式，后端资源根据业务流量自动扩容，先使用后付费，无需支付闲置成本。

### 能力概览

![](https://res8.wxqcloud.qq.com.cn/wxdoc/9f63665c-8579-432f-8d63-670f7202b4ac.png)

储存数据与文件

[云数据库：](1003011)
文档型数据库，稳定可靠；支持在小程序端和云函数中调用。

[存储：](1003105)
云端文件存储，自带 CDN
加速，支持在前端直接上传/下载，可在云开发控制台可视化管理。

![](https://res8.wxqcloud.qq.com.cn/wxdoc/7818786f-effe-4633-89bc-8ea413fd5787.png)

运行后端代码

[云函数：](1003062)
在云端运行的代码，微信私有协议天然鉴权，开发者只需编写自身业务逻辑代码。

[工作流：](1003042)
服务端业务逻辑的可视化编排工具，可清晰、灵活、高效地组织和管理业务逻辑。

![](https://res8.wxqcloud.qq.com.cn/wxdoc/71c388ae-5f0d-421f-8887-0f150c4fc079.png)

扩展能力

[静态网站：](1003095)
快速部署网站，支持自定义域名、网站防刷等配置。

[内容管理（CMS）：](1003030)
一键部署，可视化管理文本、Markdown、图片等多种内容，使用云数据库读取数据并使用数据。

![](https://res8.wxqcloud.qq.com.cn/wxdoc/da730c6f-b221-4403-9d7c-5660163f4584.png)

开箱即用

[云后台：](1003038)
完备的业务运营管理系统，涵盖后台管理、支付管理、公众号管理

[云模板：](#)
简单调整活动配置即可快速上线页面，也可以基于模版进行二次开发，满足个性化需求。

![](https://res8.wxqcloud.qq.com.cn/wxdoc/37a76541-7518-479c-a48c-c95dab789c7c.png)

打通微信生态

[免登录鉴权：](1003059)
云函数、云数据库、云存储都能够直接识别小程序端用户信息，你可通过配置安全规则或直接编写代码来使用。

[云调用：](1003078)
云函数内免鉴权调用小程序开放接口，包括服务端调用、获取开放数据等能力。

[微信支付：](1003122)
免鉴权、免签名计算、免 access\_token，在云函数内原生调用微信支付接口。

[环境共享：](1003091)
跨账号资源和能力复用，可授权云开发资源给其他小程序/公众号使用。
