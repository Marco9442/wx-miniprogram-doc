## [#](#数据模型命名空间) 数据模型命名空间

### [#](#models) `models`

在初始化 SDK 之后，会自动在 `models` 上挂载针对当前云开发环境下的数据模型的操作方法

通过 `models.<model_name>` 可以访问某个模型的操作方法

例如：

```
// const wxCloud = client.init(wx.cloud);
// const models = wxCloud.models;

models.<model_name>.create() // 创建单条数据
models.<model_name>.createMany()  // 创建多条数据
models.<model_name>.update() // 更新单条数据
models.<model_name>.updateMany() // 更新多条数据
models.<model_name>.delete() // 删除单条数据
models.<model_name>.deleteMany() // 删除多条数据
models.<model_name>.get() // 查询单条数据
models.<model_name>.list() // 查询多条数据
```

数据模型的方法可以在云函数中和小程序中均可使用

- 在小程序端运行时，默认是当前登录用户的身份调用
- 在云函数中运行时，默认是管理员权限，后续会支持选择以客户端小程序用户身份调用

## [#](#模型查询方法) 模型查询方法

### [#](#create) `create()`

`create` 方法会创建一条新的数据

> (`params`) => `Promise`<[`MethodResponse`](../client/globals#methodresponset)<[`CreateResponse`](../client/globals#createresponset)<`T`>>>

#### [#](#参数) 参数

| 属性 | 类型 | 默认值 | 示例 | 必填 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `params.data` | `T` | 无 | `{name: "hello"}` | 是 | 对应数据模型的字段结构 |

#### [#](#返回值) 返回值

`Promise`<[`MethodResponse`](../client/globals#methodresponset)<[`CreateResponse`](../client/globals#createresponset)<`T`>>>

| 属性 | 类型 | 默认值 | 示例 | 必填 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `data.id` | `string` | 无 | `"7L5G32U9PE"` | 是 | `id` 为对应创建数据对应的标识 |

#### [#](#示例) 示例

创建新文章：

```
const { data } = await models.post.create({
  data: {
    body: "你好，世界nnfrom china",
    title: "你好，世界",
    slug: "hello-world-cn",
  },
});

// 返回创建的文章 id
console.log(data);
// { id: "7d8ff72c665eb6c30243b6313aa8539e"}
```

### [#](#update) `update()`

`update` 方法用于更新一条已存在的数据记录。

> (`params`) => `Promise`<[`MethodResponse`](../client/globals#methodresponset)<[`UpdateResponse`](../client/globals#updateresponset)<`T`>>>

#### [#](#参数-3) 参数

| 属性 | 类型 | 默认值 | 示例 | 必填 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `params.data` | `T` | 无 | `{name: "hello"}` | 是 | 对应数据模型的字段结构 |
| `params.filter` | [`FilterParams`](../client/globals#filterparamst)<`T`> | 无 | `{filter: {where: {_id:{$eq:"foo"}}}}` | 是 | 过滤条件 |

> [`FilterParams`](../client/globals#filterparamst)<`T`> 为查询参数的结构，请参考查询参数说明
> 该方法为单条更新方法，如果使用筛选条件，筛选得到多条数据，则不能用这个方法更新

#### [#](#返回值-3) 返回值

`Promise`<[`MethodResponse`](../client/globals#methodresponset)<[`UpdateResponse`](../client/globals#updateresponset)<`T`>>>

| 属性 | 类型 | 默认值 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| `data.count` | `count: 0 or 1` | 无 | `1` | 变更的条数，返回非 0 值代表更新成功。 |

#### [#](#示例-3) 示例

更新文章内容：

```
const { data } = await models.post.update({
  data: {
    title: "Hello World",
    body: "Hello World",
  },
  filter: {
    where: {
      _id: {
        $eq: "xxxx", // 推荐传入_id数据标识进行操作
      },
    },
  },
});

// 返回更新成功的条数
console.log(data);
// { count: 1}
```

### [#](#upsert) `upsert()`

`upsert` 方法用于创建或更新一条记录

> (`params`) => `Promise`<[`MethodResponse`](../client/globals#methodresponset)<[`UpsertResponse`](../client/globals#upsertresponset)<`T`>>>

#### [#](#参数-4) 参数

| 属性 | 类型 | 默认值 | 示例 | 必填 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `params.update` | `T` | 无 | `{name: "hello", _id: "foo" }` | 是 | 对应数据模型的字段结构, 更新记录时会用根据这个来更新 |
| `params.create` | `T` | 无 | `{name: "hello", _id: "foo"}` | 是 | 对应数据模型的字段结构，新增记录是会根据这个来新增 |
| `params.filter` | [`FilterParams`](../client/globals#filterparamst)<`T`> | 无 | `{filter: {where: {_id:{$eq:"foo"}}}}` | 是 | 过滤条件 |

> [`FilterParams`](../client/globals#filterparamst)<`T`> 为查询参数的结构，请参考查询参数说明
> 该方法为单条更新方法，如果使用筛选条件，筛选得到多条数据，则不能用这个方法更新

#### [#](#返回值-4) 返回值

`Promise`<[`MethodResponse`](../client/globals#methodresponset)<[`UpsertResponse`](../client/globals#upsertresponset)<`T`>>>

| 属性 | 类型 | 默认值 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| `data.count` | `count: 0 or 1` | 无 | `1` | 变更的条数，返回非 0 值代表更新成功。 |
| `data.id` | `string` | 无 | `1` | 新增的记录的 id |

#### [#](#示例-4) 示例

创建或更新文章内容：

```
const post = {
  title: "Hello World",
  body: "Hello World",
  _id: "foo",
};
const { data } = await models.post.upsert({
  create: post,
  update: post,
  filter: {
    where: {
      _id: {
        $eq: post._id,
      },
    },
  },
});
console.log(data);
// 新增时返回
//   {
//     "count": 0,
//     "id": "foo"
// }

// 更新时返回
//   {
//     "count": 1,
//     "id": ""
// }
```

### [#](#updateMany) `updateMany()`

`updateMany` 方法用于更新多条匹配特定条件的数据记录。

> (`params`) => `Promise`<[`MethodResponse`](../client/globals#methodresponset)<[`CreateManyResponse`](../client/globals#createmanyresponset)<`T`>>>

#### [#](#参数-5) 参数

| 属性 | 类型 | 默认值 | 示例 | 必填 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `params.data` | `T` | 无 | `{name: "hello"}` | 是 | 对应数据模型的字段结构 |
| `params.filter` | [`FilterParams`](../client/globals#filterparamst)<`T`> | 无 | `{filter: {where: {}}}` | 是 | 查询条件 |

> [`FilterParams`](../client/globals#filterparamst)<`T`> 为查询参数的结构，请参考查询参数说明
> 批量更新一次最多只能更新 200 条

#### [#](#返回值-5) 返回值

`Promise`<[`MethodResponse`](../client/globals#methodresponset)<[`CreateManyResponse`](../client/globals#createmanyresponset)<`T`>>>

| 属性 | 类型 | 默认值 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| `data.count` | `count: 0 or 1` | 无 | `1` | 变更的条数，返回非 0 值代表更新成功 |

#### [#](#示例-5) 示例

例如筛选内容不为空的数据，更新文章内容和别名：

```
const { data } = await models.post.updateMany({
  data: {
    slug: "hello-world",
    body: `
        "你好世界"可以翻译成以下几种语言：
        
        英语：Hello World 西班牙语：Hola Mundo 法语：Bonjour le Monde 德语：Hallo Welt 意大利语：Ciao Mondo 葡萄牙语：Olá Mundo 荷兰语：Hallo Wereld 日语：こんにちは、世界 (Konnichiwa, Sekai) 韩语：안녕하세요, 세계 (Annyeonghaseyo, Segye)`,
  },
  filter: {
    where: {
      title: {
        $nempty: 1, // 不为空的数据
      },
    },
  },
});

// 返回更新成功的条数
console.log(data);
// {
//   "count": 33
// }
```

### [#](#list) `list()`

`list` 方法用于获取多条数据记录。

> (`params`) => `Promise`[`<MethodResponse`](../client/globals#methodresponset)<`{ records: T[]; total?: number }`>>

#### [#](#参数-9) 参数

入参结构

| 属性 | 类型 | 默认值 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `params.filter`? | [`FilterParams`](../client/globals#filterparamst)<`T`> | 无 | 是 | 查询过滤参数 |
| `params.select`? | [`SelectParams`](../client/globals#selectparamst)<`T`> | 无 | 是 | `{ $master: true }` 可以指定返回本表或者关联表的字段，如果想查询本表所有字段，请使用 `{ $master: true }` |
| `params.getCount`? | `boolean` | `false` | 否 | 获取 filter 命中条件的查询条数 |
| `params.pageSize`? | `number` | 10 | 否 | 分页大小，建议指定，如需设置为其它值，需要和 pageNo 配合使用，两者同时指定才会生效 |
| `params.pageNumber`? | `number` | 1 | 否 | 分页数目 |
| `params.orderBy`? | [`OrderByParams`](../client/globals#orderbyparams)[] | 无 | 否 | 排序，当前仅支持最多 3 字段排序 |

> 对于`orderBy`的排序，在默认情况下以底层数据库查询结果为准，不存在新建数据一定会排在最前的情况。
> 查询请求单次最大仅支持 200 条

#### [#](#返回值-9) 返回值

`Promise`[`<MethodResponse`](../client/globals#methodresponset)<`{ records: T[]; total?: number }`>>

| 属性 | 类型 | 默认值 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| `data.records` | `T[]` | 无 | `[{ name: "hello" }, { name: 'world"'}]` | records 内的数组为对应的数据源数据对象 |
| `data.total`? | `number` | 无 | `3` | 入参配置了 `getCount` 为 `true` 时会返回满足筛选查询条件的大小，注意，此字段不代表返回 records 的长度，可以用作页面大小的计算。当`getCount`为`false`的时候，不应该对此值做任何期待 |

获取所有文章，返回查询到的数据列表 `records` 和 总数 `total`

##### [#](#返回指定字段) 返回指定字段

## [#](#数据库原始查询) 数据库原始查询

数据模型 SDK 提供了模型化的数据操作接口，为了进一步满足用户在特定场景下的需求：

- 利用数据库特定的功能或优化策略
- 数据模型 SDK 尚未提供的功能
  - 对于底层为 NoSQL 云数据库类型的模型，我们推荐使用云数据库的 SDK 中的 [聚合搜索](../../guide/database/aggregation/aggregation)、[事务](../../guide/database/transaction) 等来完成数据模型尚未提供的功能，使用数据模型创建的 NoSQL 类型的模型，仍可以使用云数据库的所有能力。

对于底层为 MySQL 数据库类型的模型，我们提供了 MySQL 类型的原生数据库查询语句。

MySQL 数据库类型的模型，数据模型 SDK 提供两种模式的查询方法：

- `$runSQL`: 预编译模式, 通过参数化查询来避免 SQL 注入风险
- `$runSQLRaw` 原始模式, 更加灵活的模式，SQL 语句会当做原始字符串进行查询，存在 SQL 注入的风险

> 注意：
>
> 1. `runSQL`、`runSQLRaw` 接口仅支持在服务端调用，如云函数/云托管/服务器等场景，不支持小程序/web 端直接调用
> 2. 建议优先采用预编译模式，避免 SQL 注入风险
> 3. 当前仅开放了 `select` 语句，如果有其他 SQL 语句需求，请通过官方社群联系我们

### [#](#runSQL) `$runSQL`

此方法仅支持服务端调用
