## [#](#支付结果回调云函数协议) 支付结果回调云函数协议

在发起[统一下单](CloudPay.unifiedOrder)时指定的云函数会在用户完成支付后接收到支付结果回调，此时云函数的返回协议和入参协议如下；

支付结果回调的云函数**必须**返回如下一个对象，否则会视为回调不成功，云函数会收到重复的支付回调：

| 字段名 | 变量名 | 必填 | 类型 | 描述 |
| --- | --- | --- | --- | --- |
| 错误码 | errcode | 是 | Number | 0 |
| 错误信息 | errmsg | 是 | String |  |

此时云函数的入参对象（JS 对象）的结构定义可见[微信支付文档-支付结果通知-通知参数](https://pay.weixin.qq.com/doc/v2/merchant/4011935221)
