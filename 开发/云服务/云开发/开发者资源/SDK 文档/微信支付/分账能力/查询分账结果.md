# [#](#CloudPay-profitSharingQuery) CloudPay.profitSharingQuery()

> 支持端：[云函数 2.0.2](../../../reference/changelog-server-sdk)

查询分账结果

## [#](#说明) 说明

发起分账请求后，可调用此接口查询分账结果；发起分账完结请求后，可调用此接口查询分账完结的执行结果。

接口频率：80QPS
*接口说明*\*

此接口与微信支付原分账接口（[文档](https://pay.weixin.qq.com/doc/v2/partner/4011984717)）的不同点在于：

- 私有安全链路，免证书管理，免签名计算
- 商户号填入 sub\_mch\_id 字段，小程序/公众号 appid 填入 sub\_appid 字段
- 免填写以下字段：mch\_id、appid、sign、sign\_type
- 接口入参和返回值都为 JSON 而不是 XML
