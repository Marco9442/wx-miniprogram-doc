# [#](#CloudPay-profitSharingReturnQuery) CloudPay.profitSharingReturnQuery()

> 支持端：[云函数 2.0.2](../../../reference/changelog-server-sdk)

回退结果查询

## [#](#说明) 说明

应用场景

- 商户需要核实回退结果，可调用此接口查询回退结果。
- 如果分账回退接口返回状态为处理中，可调用此接口查询回退结果。

接口频率：30QPS
*接口说明*\*

此接口与微信支付原分账接口（[文档](https://pay.weixin.qq.com/doc/v2/partner/4011985243)）的不同点在于：

- 私有安全链路，免证书管理，免签名计算
- 商户号填入 sub\_mch\_id 字段，小程序/公众号 appid 填入 sub\_appid 字段
- 免填写以下字段：mch\_id、appid、sign、sign\_type
- 接口入参和返回值都为 JSON 而不是 XML
