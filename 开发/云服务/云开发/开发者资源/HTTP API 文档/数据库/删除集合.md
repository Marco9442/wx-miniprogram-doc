# [#](#databaseCollectionDelete) databaseCollectionDelete

> 本接口应在服务器端调用，详细说明参见[服务端API](https://developers.weixin.qq.com/miniprogram/dev/server/getting_started/api_signature)。

删除集合

### [#](#请求地址) 请求地址

```
POST https://api.weixin.qq.com/tcb/databasecollectiondelete?access_token=ACCESS_TOKEN
```

### [#](#请求参数) 请求参数

| 属性 | 类型 | 默认值 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| access\_token / cloudbase\_access\_token | string |  | 是 | [接口调用凭证](../functions/invokeCloudFunction) |
| env | string |  | 是 | 云环境ID |
| collection\_name | string |  | 是 | 集合名称 |

### [#](#返回值) 返回值

### [#](#Object) Object
