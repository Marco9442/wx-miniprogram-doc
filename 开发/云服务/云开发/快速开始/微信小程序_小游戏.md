# [#](#微信小程序-小游戏-快速开始) 微信小程序/小游戏-快速开始

## [#](#准备工作) 准备工作

1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download)；
2. [注册微信小程序](https://mp.weixin.qq.com/)，获取小程序的 AppID（开发管理-开发设置）；
   ![image.png](https://res.wx.qq.com/op_res/Y8qFMBDRtI4lTYzPUtX4zW_TmzCg03Hvu35sP-YaF8DzEFTSC4z9IwDstQNxlSKLGmgoLulehve2gM5QUvj8Vw)

## [#](#第-1-步：创建项目) 第 1 步：创建项目

打开并登录微信开发者工具，新建小程序项目，填入 AppID，后端服务选择「微信云开发」并勾选同意「云开发服务条款」：

![image.png](https://res.wx.qq.com/op_res/B6GwYon5f0cZAeFCSQ5J0a6V8vM34hCLwFN7VwWyJbWurT7bxj1VcOfbnqbpOgLSfV9aE-eWRlvhZ2eNjsjYqA)

点击创建后，即可得到一个展示云开发基础能力的示例小程序：

![](https://main.qcloudimg.com/raw/0820d0ac5fd503e7712cfe996d54ffba.png)

## [#](#第-2-步：开通云开发，创建环境) 第 2 步：开通云开发，创建环境

在使用云开发能力之前，需要先开通云开发。

在开发者工具的工具栏左侧，点击「云开发」按钮即可打开云控制台，根据提示开通云开发，并且创建一个新的云开发环境。

![](https://main.qcloudimg.com/raw/eb4739da3c8d504ee71dc48faacc9eee.png)

- 每个环境相互隔离，拥有唯一的**环境 ID**，包含独立的数据库实例、存储空间、云函数配置等资源；
- 初始创建的环境自动成为**默认环境**；
- 腾讯云控制台创建的云开发环境也可在微信云开发中使用。登录微信云开发控制台-设置-环境设置，点击环境名称，选择「管理我的环境」，点击「使用已有腾讯云环境」按钮，选择所需腾讯云环境，即可在微信云开发控制台使用该环境。

## [#](#第-3-步：开始开发) 第 3 步：开始开发

开通创建环境后，即可以开始在模拟器上操作小程序体验云开发提供的部分基础能力演示。

## [#](#可选：使用-Skill-MCP-辅助开发) 可选：使用 Skill / MCP 辅助开发

完成环境开通后，如果你希望减少在编辑器、控制台和文档之间的切换，也可以按需在支持 MCP 的 AI IDE 或其他开发工具中接入云开发服务，并结合云开发 Skill 使用。这样可以直接用对话方式处理分析小程序数据、查询云函数日志报错、排查 `wx.cloud.callFunction` 调用问题等高频操作。

其中，MCP 负责连接环境与执行操作，Skill 负责补充小程序与云开发场景规则；两者结合后，工具通常能更贴近实际开发流程提供辅助。

如果你是第一次接触云开发，建议先按本文手动完成一次基础流程；熟悉后，再引入这类开发辅助方式会更合适。

详见：[使用 Skill / MCP 辅助小程序开发（可选）](../guide/development-assistant)
