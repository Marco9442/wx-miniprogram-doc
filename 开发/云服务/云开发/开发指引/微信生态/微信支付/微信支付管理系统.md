# [#](#微信支付管理系统) 微信支付管理系统

[云开发管理系统](../extensions/manage-system/introduction)内置了「小程序支付管理」模板，开发者开通后，简易配置商户号相关证书、密钥即可使用。

![](https://qcloudimg.tencent-cloud.cn/raw/96c7e61f493a0d1aaa91da48afde225e.png) ![](https://qcloudimg.tencent-cloud.cn/raw/6850477d6ade05ea100d3b307a16d148.png)

目前云开发管理系统「小程序支付管理」提供以下能力：

- 订单查询
  - 使用商户号或订单号查询订单信息
- 退款管理
  - 退款订单查询
  - 退款申请
- 交易账单
  - 通过时间、账单类型查询账单
  - 支持下载账单
- 资金账单
  - 通过时间、账单类型查询账单
  - 支持下载账单

## [#](#使用流程) 使用流程

### [#](#第-1-步：进入管理系统控制台，安装模板) 第 1 步：进入管理系统控制台，安装模板

进入云开发控制台，点击「更多」-「管理工具」

![](https://qcloudimg.tencent-cloud.cn/raw/4c3676e08fd77a537a4ed2b19c3327a6.png)

选择「小程序支付管理」模板，并安装模板

![](https://qcloudimg.tencent-cloud.cn/raw/b953691794e83733a9315adf8813b7bf.png)

安装完成后，点击「编辑」，进入低代码编辑器

### [#](#第-2-步：完成微信支付相关配置) 第 2 步：完成微信支付相关配置

在低码编辑器的侧边栏中，点击「数据源」

进入「APIs」-「微信支付-小程序」-「基本信息」，点击编辑按钮，配置微信支付的基础信息：

- 你的小程序 AppID
- 支付商户号
- 商户证书序列号
- 商户 API 私钥
- API V3 密钥

你可以参考以下文档获取上述信息：

- [获取微信支付商户号](https://pay.weixin.qq.com/static/applyment_guide/applyment_detail_miniapp.shtml)
- [商户号绑定小程序 AppID](https://pay.weixin.qq.com/static/pay_setting/appid_protocol.shtml)
- [商户 API 证书序列号](https://kf.qq.com/faq/161222NneAJf161222U7fARv.html)
- [商户 API 私钥](https://kf.qq.com/faq/161222NneAJf161222U7fARv.html)
- [API V3 密钥](https://pay.weixin.qq.com/doc/v3/merchant/4012072195)

![](https://qcloudimg.tencent-cloud.cn/raw/e436feda0eb9d015c3b97c500cd3c9a0.png)

配置完成后，点击保存按钮。

### [#](#第-3-步：发布应用) 第 3 步：发布应用

1. 回到页面编辑器，点击右上角发布，将会自动触发依赖项检查
2. 点击发布数据源
3. 发布数据源完毕后，再次点击发布应用

![](https://qcloudimg.tencent-cloud.cn/raw/42a4b2f292bd4a69bddd9a596bb0b2a2.png)

### [#](#第-4-步：访问管理系统) 第 4 步：访问管理系统

发布成功后，你可以直接在编辑器内跳转至管理系统，或者在应用详情页中获得管理系统的地址和初始账号密码：

![](https://qcloudimg.tencent-cloud.cn/raw/99f55ce905eabbebff5e5a54cf3062e3.png)

你也可以在下方的用户管理中，自行创建运营者账号，详情可参考 [云开发管理系统-用户管理](../extensions/manage-system/manage-users)。
