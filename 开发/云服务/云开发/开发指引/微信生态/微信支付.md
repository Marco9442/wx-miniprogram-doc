## [#](#微信支付) 微信支付

微信云开发针对微信支付场景，提供了多种能力帮助开发者快速打通微信支付：

| 能力 | 介绍 |
| --- | --- |
| 云调用 | 使用云函数免密调用微信支付接口，开发者无需关心证书、签名、微信支付服务器端文档，使用简单，代码较少，只需要调用相应的函数即可 |
| 工作流 | 使用云开发工作流进行逻辑编排，通过连接器调用微信支付接口，相比云调用支持更加复杂、通用的业务场景 |
| 微信支付管理系统 | 云开发管理系统内置了「微信支付管理」模板，支持 Web 端登录使用，提供订单查询、退款等功能，开发者也可对模板进行自定义修改 |
