# [#](#使用-Skill-MCP-辅助小程序开发（可选）) 使用 Skill / MCP 辅助小程序开发（可选）

## [#](#概述) 概述

在完成微信云开发环境开通和基础初始化后，你也可以在支持 MCP 的 AI IDE 或其他开发工具中接入云开发服务，并结合云开发 Skill 使用。MCP 负责连接环境与调用工具，Skill 负责补充小程序、云函数、数据库等场景规则；两者结合后，更适合处理分析小程序数据、查询云函数日志报错、排查 `wx.cloud.callFunction` 调用问题等高频任务。

这种方式不会改变原有开发流程，更适合作为日常开发时的补充。若你是第一次接触微信云开发，建议先按文档手动完成一遍基础流程，再逐步引入。

## [#](#快速开始) 快速开始

### [#](#方式一：在微信开发者工具中安装-MCP) 方式一：在微信开发者工具中安装 MCP

如果你主要在微信开发者工具中开发，可以先完成下面两个步骤：

**步骤 1：安装 CodeBuddy 扩展**

1. 在微信开发者工具 2.0 以上版本中，使用快捷键 `Ctrl + Shift + X`（Windows/Linux）或 `Shift + Command + X`（macOS）打开扩展面板。
2. 在扩展市场中搜索「CodeBuddy」。
3. 安装「腾讯云代码助手 CodeBuddy」扩展。

**步骤 2：安装 CloudBase MCP**

1. 安装完成后，在工具栏找到 CodeBuddy 图标。
2. 点击右上角的 CodeBuddy 设置图标。
3. 在 MCP 市场中搜索并安装“CloudBase MCP”。

配置完成后，可直接在对话中尝试：

- 帮我统计最近 7 天小程序新增用户数
- 帮我查看 `login` 云函数最近一次报错日志
- 帮我看一下当前小程序项目绑定的是哪个云开发环境

如果你使用其他 AI IDE，可参考 [CloudBase MCP 快速开始](https://docs.cloudbase.net/ai/cloudbase-ai-toolkit/getting-started) 完成对应配置。

### [#](#方式二：安装云开发-Skill) 方式二：安装云开发 Skill

如果你使用支持 Skill 的 AI IDE，可在项目根目录执行：

```
npx skills add tencentcloudbase/cloudbase-skills
```

安装完成后，Skill 会出现在当前项目对应目录中（如 `.cursor/skills`、`.claude/skills` 等，具体以所用工具为准）。

### [#](#验证是否生效) 验证是否生效

配置完成后，可以先尝试一个直接任务，例如：

- 帮我统计最近 7 天小程序新增用户数
- `wx.cloud.callFunction` 调用 `login` 失败了，帮我结合最近日志排查一下
- 帮我看一下当前小程序项目绑定的是哪个云开发环境

如果 MCP 和 Skill 都已生效，工具通常不仅能发起环境连接与资源查询，也会按小程序与云开发场景给出更贴近实际流程的辅助。

## [#](#可直接尝试的问题) 可直接尝试的问题

### [#](#_1-分析小程序数据) 1. 分析小程序数据

适合需要快速查看小程序业务数据、做简单统计或先定位异常数据时使用，例如：

- 帮我统计最近 7 天小程序新增用户数
- 帮我分析订单集合里最近一周的小程序支付趋势
- 帮我看一下今天哪些用户数据明显异常

### [#](#_2-查询云函数日志报错) 2. 查询云函数日志报错

适合出现报错、超时、调用失败等情况时使用，例如：

- `login` 云函数报错了，帮我看看最近日志
- `wx.cloud.callFunction` 调用失败，帮我排查一下可能原因
- 最近一次部署后为什么小程序开始报错

### [#](#_3-查询小程序环境与资源) 3. 查询小程序环境与资源

适合在你不想来回切换控制台时使用，例如：

- 当前小程序项目绑定的是哪个环境？
- 帮我看一下这个环境里有哪些云函数、数据库集合或托管服务？

### [#](#_4-创建和部署小程序云函数) 4. 创建和部署小程序云函数

适合频繁修改、上传和验证云函数时使用，例如：

- 帮我创建一个用于小程序登录的 `login` 云函数
- 把这个云函数部署到当前测试环境

### [#](#_5-梳理小程序数据库与权限规则) 5. 梳理小程序数据库与权限规则

适合需要一边设计数据结构、一边补齐权限配置时使用，例如：

- 帮我设计小程序订单集合字段
- 这个集合的读写权限应该怎么配，才能只允许用户操作自己的数据

## [#](#使用建议) 使用建议

- 先让工具处理查询、整理步骤、生成初稿等重复性工作，再由开发者确认关键变更
- 涉及生产环境、计费资源、权限策略或批量数据操作时，建议保留人工确认
- 如果工具回答过于泛化，可在问题中明确“小程序 + 微信云开发”场景，或补充安装云开发 Skill
