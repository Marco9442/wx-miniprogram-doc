# [#](#大模型接入) 大模型接入

在小程序中，直接调用大模型的文本生成能力，实现最简单的文本生成

小程序基础库需要在 3.15.1 及以上版本，开发者可以直接通过小程序中的 `wx.cloud.extend.AI` 调用云开发售卖的 DeepSeek、混元、GLM、Minimax、Kimi等最新模型。

## [#](#初始化) 初始化

在小程序代码中，通过以下代码进行云开发环境初始化：

```
wx.cloud.init({
    env: "<云开发环境ID>",
});

const ai = wx.cloud.extend.AI;
```

## [#](#createModel) createModel()

创建指定的 AI 模型。[详细参数定义](../../../reference-sdk-api/extend/ai#AI-createModel)

支持如下模型：

| 模型标识 | 说明 | 模型列表 |
| --- | --- | --- |
| cloudbase | 云开发售卖的模型 | hy3-preview、deepseek-v4-flash、deepseek-v4-pro、hy3-preview、glm-5.1、kimi-k2.6、minimax-m2.7 等 |
| hunyuan-v3 | 仅供体验的模型 | hy3-preview |

### [#](#使用示例) 使用示例

```
const model = ai.createModel("cloudbase");
```

## [#](#ChatModel-streamText) ChatModel.streamText()

以流式调用大模型生成文本。流式调用时，生成的文本及其他响应数据会通过 [SSE](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events) 返回，该接口的返回值对 SSE 做了不同程度的封装，开发者能根据实际需求获取到文本流和完整数据流。[详细参数定义](../../../reference-sdk-api/extend/ai#ChatModel-streamText)

### [#](#使用示例-2) 使用示例

```
// 连接模型提供商
const provider = ai.createModel("cloudbase");

const res = await provider.streamText({
  data: {
    model: "hy3-preview", // 模型名称
    messages: [
      {
        role: "user",
        content: "hi"
      }
    ]
  }
});

for await (let str of res.textStream) {
   // 打印生成的文本
  console.log(str);
}
for await (let event of res.eventStream) {
  // 打印每次返回的完整数据
  console.log(event); 

  // 当大模型结束传输时，通常会发一条 [DONE] 数据，在此之后即可停止循环
  if (event.data === "[DONE]") {
    break;
  }
}
```
