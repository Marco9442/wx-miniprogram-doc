# [#](#工作流) 工作流

在小程序、公众号的开发过程中，开发者经常遇到以下场景：

- 接收来自微信的服务端回调消息，例如公众号事件推送、微信支付付款回调等；
- 运行定时任务，例如每天 0 点进行数据清理、统计等；
- 进行任务逻辑编排，例如使用云函数进行任务的批量处理等场景。

为了让开发者更好地应对上述业务场景，我们推出了「**工作流**」功能。工作流是云开发推出的服务端业务逻辑的可视化编排工具，帮助开发者更清晰、灵活、高效地组织和管理业务逻辑。

![](https://qcloudimg.tencent-cloud.cn/raw/04e3a0f8d7001e7db3046ba69afdd006.png)

## [#](#功能特性) 功能特性

工作流主要有以下特性：

1、**可视化**：开发者通过拖拉拽方式以及简单的节点完成配置与调试，快速开发业务流程，使其更直观和易于理解，同时便于团队成员之间沟通和协作；

![](https://qcloudimg.tencent-cloud.cn/raw/ca57f512e89b27cba00a29e668403f5b.png)

2、**可扩展**：工作流提供基于云函数的脚本节点，支持用自定义代码实现复杂逻辑，满足各种不同的业务场景和需求。

![](https://qcloudimg.tencent-cloud.cn/raw/1be0b66884f53917e58d2933b66bed05.png)

工作流主要有以下能力：

能力一：接收并处理微信公众平台推送的消息和事件，其中包括：

- 公众号：[普通消息](https://developers.weixin.qq.com/doc/service/guide/product/message/Receiving_standard_messages) 和 [事件推送](https://developers.weixin.qq.com/doc/service/guide/product/message/Receiving_standard_messages)
- 小程序：[客服消息与事件](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/customer-message/receive) 和 [发货信息管理服务消息](https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/order-shipping/order-shipping#%E5%85%AB%E3%80%81%E7%9B%B8%E5%85%B3%E6%B6%88%E6%81%AF%E6%8E%A8%E9%80%81)

![](https://qcloudimg.tencent-cloud.cn/raw/92863d311e4401aedc0532808c5c08c1.png)

能力二：支持 JS 脚本节点，快速编写、调试自定义代码

![](https://qcloudimg.tencent-cloud.cn/raw/0d5ef6865ee1f42ab23c84c091c61e47.png)

能力三：支持快速回复微信公众号或小程序客服消息。通过「响应 HTTP 请求」节点，返回自定义的响应信息，实现回复消息功能

![](https://qcloudimg.tencent-cloud.cn/raw/763192285efece45abf6529c8fd32585.png)
