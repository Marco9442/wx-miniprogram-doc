## [#](#静态网站) 静态网站

> 开发者工具 1.03.2006042 起

静态网站是云开发为开发者提供的 Web 资源托管服务，网站的静态资源（HTML、JavaScript、CSS、图片、音频、视频等）可以托管在该服务上，并享有以下能力：

1. 默认域名：获得对应云环境的唯一专属默认域名，通过域名可访问静态资源，域名可以用于测试或线上使用
2. 自定义域名：你也可以绑定自己域名，绑定后自己的域名可访问静态网站资源
3. 小程序 webview：小程序不用配置业务域名即可在 `<web-view>` 打开云开发静态网站的域名（仅支持能够使用 `<web-view>` 标签的小程序）
4. CDN 加速
5. 可以免鉴权直接打开小程序：非个人主体的认证的小程序，使用静态网站的网页，可以免鉴权跳转任意合法合规的小程序，[查看详细介绍和示例](jump-miniprogram)。

### [#](#开通方式) 开通方式

静态网站仅支持按量付费的环境开通，如环境支付方式不是按量付费，请先切换至按量付费、或新创建一个按量付费的环境。

静态网站的开通入口在「更多 - 静态网站」中。

### [#](#文件管理) 文件管理

静态资源文件的管理操作同云开发的文件存储能力。

### [#](#网站配置) 网站配置

网站配置支持绑定自定义域名、配置网站索引文档、设置文件缓存时间、以及安全相关的 IP 黑白名单配置、Referrer 黑白名单配置、频率限制。

**自定义域名**

除了使用静态网站提供的默认域名外，你还可以绑定自己拥有的域名到静态网站，绑定之后，访问该域名即可访问静态网站中的所有资源文件。

**索引文档**

索引文档即网站的首页，如果直接访问域名而不指定具体资源文件路径，则默认访问索引文档。

### [#](#Web-SDK) Web SDK

可使用云开发 Web SDK 访问云开发资源。如果在 Web SDK 需要使用公众号登录态，则网站域名需要使用静态网站承载的域名（静态网站提供的默认域名或绑定的自定义域名都可以）。

Web SDK [介绍](../../basis/crossplatform)。
