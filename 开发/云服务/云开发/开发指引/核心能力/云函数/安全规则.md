## [#](#云函数安全规则) 云函数安全规则

云函数安全规则可以用于限制 C 端用户访问，默认不允许未登录用户访问，即默认值为：

```
{
  "*": {
    "invoke": "auth != null"
  }
}
```

### [#](#语法规则) 语法规则

以示例规则说明：

```
{
  // * 为通配符，表示对所有函数适用
  "*": {
    // invoke 表示调用权限控制
    // auth 包含鉴权信息，如果是未登录模式，则 auth == null
    "invoke": "auth != null"
  },
  // 函数名，该规则优先级会高于通配符
  "function1": {
    // 表示允许所有来源调用，包括未登录用户
    "invoke": true
  }
}
```
