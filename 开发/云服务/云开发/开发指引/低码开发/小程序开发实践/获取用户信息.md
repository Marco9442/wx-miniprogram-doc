# [#](#获取用户信息) 获取用户信息

## [#](#步骤-1：创建获取用户信息按钮) 步骤 1：创建获取用户信息按钮

在左侧组件区中选择一个按钮组件。
![img](https://qcloudimg.tencent-cloud.cn/raw/ae81c267a72a73add613d3d0818e5b68.png)

## [#](#步骤-2：创建用户信息获取方法) 步骤 2：创建用户信息获取方法

进入低码编辑器，创建一个名为 `getuserinfo` 的自定义方法，自定义方法示例如下:

```
export default async function({event, data}) {

    wx.getUserProfile({
            desc: '用于完善用户信息',
            success: (res) => {
            console.log(res);
            }
    })
}
```

## [#](#步骤-3：将按钮与自定义方法进行绑定) 步骤 3：将按钮与自定义方法进行绑定

选中步骤 1 中新建的**按钮**组件，进入右侧配置区的**事件**页面，进行自定义方法的绑定。
![img](https://qcloudimg.tencent-cloud.cn/raw/7a25d4e95fdd43fcc4fb69cbd6c1ba4e.png)

## [#](#步骤-4：上传小程序并测试) 步骤 4：上传小程序并测试

1. 单击右上角的**上传**，进行小程序的上传，并联系管理员将此次上传设置为体验版本。
   ![img](https://qcloudimg.tencent-cloud.cn/raw/ffad474520084bd0e2b281d7569da08f.png)
2. 上传完成后进入体验版小程序，开启小程序的调试模式
3. 在小程序中单击**按钮**，观察是否调起获取弹窗，若调起成功，单击**允许**即可。
4. 单击下方 `vConsole`，查看是否出现用户信息的打印信息，若正常展示，则表示该功能已可以正常使用。
