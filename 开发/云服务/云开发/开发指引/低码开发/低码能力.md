# [#](#一、组件) 一、组件

微搭提供满足不同需求的低码组件，组件选择位置在低码编辑器左侧区域。
![](https://qcloudimg.tencent-cloud.cn/raw/2396aa5fadcf68dcd4509365071af9d3.png)
使用组件时，不同组件的用法可通过点击**了解详情**详细查看。
![](https://qcloudimg.tencent-cloud.cn/raw/131ecd5e1fe978397116a75167268b34.png)

全部组件能力支持，可参考[组件列表](https://cloud.tencent.com/document/product/1301/59110)。

## [#](#二、数据源) 二、数据源

低码平台的数据源提供了一套数据的存储和管理数据的方法集合，支持创建、管理多个数据源。  
 ![](https://qcloudimg.tencent-cloud.cn/raw/76ad47b0328d22e4eb32307ea15773a8.png)
同时提供 APIs（开放服务）能力，打通外部应用数据或调用外部应用开放的服务，例如：腾讯文档、腾讯会议、腾讯地图、微信支付、腾讯云文字识别、腾讯云短信等。微搭开发者只需要创建 API 时完成授权或少量填写一些配置信息，即可使用对应产品的服务接口，而无需关注实现细节。  
 ![](https://qcloudimg.tencent-cloud.cn/raw/48f5cf33a0e25a732ea25555f21a8b23.png)
