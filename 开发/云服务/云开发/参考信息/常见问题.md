### [#](#_1-云开发模板提示「当前小程序没有配置云开发环境，请在-envList-js-中配置你的云开发环境」) 1. 云开发模板提示「当前小程序没有配置云开发环境，请在 envList.js 中配置你的云开发环境」

解决这个问题，需要将你的云开发环境 ID 填入到项目中的 `envList.js` 中，具体操作如下：

1. 在开发者工具的工具栏左侧，点击 「云开发」 按钮打开云控制台，根据提示开通云开发，并且创建一个新的云开发环境。 ![](https://main.qcloudimg.com/raw/eb4739da3c8d504ee71dc48faacc9eee.png)
2. 进入云开发控制台，复制环境 ID ![](https://qcloudimg.tencent-cloud.cn/raw/a76819650fb4f4453c694532536f797c.png)
3. 将环境 ID 填入到小程序项目中的 `envList.js`，例如：

```
const envList = [
  {
    envId: "<第2步中获取到的环境ID>",
    alias: "<第2步中获取到的环境ID>",
  },
];
module.exports = {
  envList,
};
```
