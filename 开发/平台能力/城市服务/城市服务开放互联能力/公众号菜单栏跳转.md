# [#](#公众号菜单栏跳转微信城市服务) 公众号菜单栏跳转微信城市服务

## [#](#一、配置步骤) 一、配置步骤

1. 打开[公众号管理MP端后台](https://mp.weixin.qq.com/)并登陆。

   ![](https://res8.wxqcloud.qq.com.cn/wxdoc/718a08a6-1372-4d53-89b0-dad9d9481892.png)
2. 左边菜单栏下滑找到 `小程序-小程序管理`

   ![](https://res8.wxqcloud.qq.com.cn/wxdoc/db1ec00d-5fc1-4d7c-b0aa-7d245e418047.png)
3. 点击`添加-关联小程序`，管理员扫码确认后输入城市服务`APPID`(wx308bd2aeb83d3345)发送绑定邀请。

   ![](https://res8.wxqcloud.qq.com.cn/wxdoc/8ea7588e-7f9f-4d88-b671-45838c80c8f9.png) ![](https://res8.wxqcloud.qq.com.cn/wxdoc/2a26f7e3-d303-4bfa-929d-58d2a3ddfa72.png)
4. 待微信城市服务管理员确认关联请求后，在MP后台左边菜单中找到`自定义菜单`，选择`跳转小程序`。在已绑定的小程序中选择`微信城市服务`，点击确定再点击`保存并发布`。

   ![](https://res8.wxqcloud.qq.com.cn/wxdoc/68ec6ef8-c566-4e3c-8ab6-746d8273ea96.png)
