# [#](#服务概览及开放范围) 服务概览及开放范围

## [#](#服务概览) 服务概览

TenPay Global 全球收银台，为微信小程序商户一站式接入全球主流支付方式，助力商户便捷接收各国消费者在小程序场景下的付款。全球收银台服务目前开放国家/地区为新加坡、中国澳门、日本，支持的支付方式可见[支付方式](payment_method)，后续将持续覆盖更多国家/地区，请开发者保持关注

- **TenPay Global 全球收银台功能详情：** 请参见[TenPay Global 全球收银台服务介绍](https://doc.weixin.qq.com/slide/p3_AbwAWAbJAP8e0aPYVP4QmWyjACgoi)
- **开通并接入 TenPay Global 全球收银台：** 请参见[服务开通手册](https://www.tenpayglobal.com/docs/checkout/activate)和[API 说明及集成指引](https://www.tenpayglobal.com/docs/checkout/integration)，或查阅本文档「[服务开通及技术集成](service_access)」章节
- **立即开启小程序全球收银体验：** 登录[微信公众平台](https://mp.weixin.qq.com)，进入「全球收银台」（新加坡、中国澳门、日本主体小程序默认开启入口，其他地区商家可参考下方「面向商户范围」进行申请）

  ![](https://res8.wxqcloud.qq.com.cn/wxdoc/d14072d0-f7b3-420b-ad17-0e800de6d28e.png)
- **向 TenPay Global 咨询详情：** 如需了解业务功能、商务定价、开通流程、技术集成等方面信息，可联系 TenPay Global 全球收银台团队官方邮箱 [tenpayglobal\_cko@tencent.com](mailto:tenpayglobal_cko@tencent.com)

## [#](#开放范围) 开放范围

### [#](#面向消费者范围) 面向消费者范围

支持通过全球收银台进行付款的消费者，需满足以下条件：

1. **微信注册手机号：** 消费者需为非中国内地手机号注册的微信用户，中国内地手机号注册的微信用户暂无使用权限
2. **微信客户端版本：** 微信客户端版本不低于 8.0.54，基础库版本不低于 3.6.6。**低于此基础库版本将无法拉起收银台，调用前开发者需对用户的版本进行判断，建议引导低版本用户使用微信支付（接口[wx.requestPayment](https://developers.weixin.qq.com/miniprogram/dev/api/payment/wx.requestOrderPayment.html)）或更新微信客户端（接口[wx.updateWeChatApp](https://developers.weixin.qq.com/miniprogram/dev/api/base/update/wx.updateWeChatApp.html)）后进行付款。**

### [#](#面向商户范围) 面向商户范围

1. **商户主体属地：** 目前仅支持经营主体注册地为新加坡、中国澳门、日本的商户开通全球收银台服务，更多国家/地区持续覆盖中，请开发者保持关注

## [#](#FAQ) FAQ

**Q：接入全球收银台，是否需要更换原有微信支付链路？**   
A：全球收银台为微信小程序商户提供海外主流支付方式的接入，解决各国家本地消费者在微信小程序场景下的支付问题。
全球收银台和微信支付目前是分开的两套账号开设流程和资金链路。因此，已经接入过微信支付的商户，原资金链路不变，但需另外向 TenPay Global 完成 KYC 流程并单独进行结算。
在 API 调用方面，直接调用微信支付接口可继续单独拉起微信支付，而调用全球收银台接口时微信支付和其他海外支付方式将在 C 端聚合展示（小程序基础库 3.6.6 以上），详情请参见：[支付方式](payment_method)   
   
 **Q：全球收银台未来会扩展哪些地区？**   
A：全球收银台目前支持新加坡、中国澳门、日本，其他地区正在加速筹备中，请开发者保持关注。如有强烈的其他地区展业需求，也可通过邮件与我们联系。
