# [#](#小程序支付管理服务介绍) 小程序支付管理服务介绍

**该功能已下线，所有参加灰度实验的小程序已恢复普通微信支付功能。**

为了优化消费者的支付体验，微信小程序提供了小程序支付管理服务。你可以在小程序后台或通过接口申请微信支付商户号。成功申请商户号后，即可在小程序中使用微信支付收款，以及在小程序后台查看流水、管理资金。

## [#](#接入流程) 接入流程

### [#](#一、商户号申请) 一、商户号申请

调用[wx.requestOrderPayment](https://developers.weixin.qq.com/miniprogram/dev/api/payment/wx.requestOrderPayment.html)前，需在小程序「微信公众平台 - 功能 - 支付管理入口」申请商户号。

| 商户类型 | 定义 | 所需资料 |

| 个体工商户 | 营业执照上的主体类型一般为个体户、个体工商户、个体经营 | 需提供营业执照、经营者证件 |
| 企业 | 营业执照上的主体类型一般为有限公司、有限责任公司 | 需提供营业执照、法人证件、管理员身份证信息 |

| 政府机关 | 包括各级、各类政府机关，如机关党委、税务、民政、人社、工商、商务、市监等。 | 需提供营业执照、法人证件、管理员身份证信息 |

#### [#](#商户号绑定小程序) 商户号绑定小程序

通过小程序后台申请的商户号无需前往微信支付商户平台发起绑定，将自动绑定申请商户号的小程序。

### [#](#二、引用组件并调用接口) 二、引用组件并调用接口

将组件引用到小程序后，需完成其他接口的对接，小程序才能拉起支付。

### [#](#三、测试并发布小程序) 三、测试并发布小程序

完成接口对接后，需测试小程序并完成小程序发布。

### [#](#四、管理资金) 四、管理资金

在小程序后台查看资金流水，修改银行账号以及操作提现。开手续费发票，修改主体信息、超管信息，处理支付侧微信投诉等能力需要前往[微信支付商户平台](https://pay.weixin.qq.com/index.php/core/home/login?return_url=%2F)完成。

### [#](#七、常见问题) 七、常见问题

#### [#](#Q：为什么会出现支付管理的页面？) Q：为什么会出现支付管理的页面？

A：为优化小程序平台交易双方的体验，平台近期推出了新的小程序支付管理服务功能，将会对部分新注册的线上售卖商品小程序进行灰度升级。

#### [#](#Q：小程序支付管理服务如何绑定商户号？) Q：小程序支付管理服务如何绑定商户号？

A：小程序支付管理服务提供了小程序专用商户号的进件服务，通过该页面申请商户号后，自动和当前小程序绑定，无需再单独绑定。

#### [#](#Q：我怎么找不到原来的微信支付绑定页面？) Q：我怎么找不到原来的微信支付绑定页面？

A：在升级为小程序支付管理服务后，无需再走原来的支付绑定流程，也不能使用之前申请的商户号，需要在小程序支付管理服务重新申请新的专用商户号。

#### [#](#Q：第三方平台在代小程序调用支付时出现问题？) Q：第三方平台在代小程序调用支付时出现问题？

A：平台目前的灰度范围不涉及已授权第三方的小程序。
