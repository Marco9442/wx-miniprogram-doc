# [#](#经营交易流水核对) 经营交易流水核对

商户可以通过 TenPay Global 提供的交易明细报告，与经营交易流水进行核对

## [#](#交易明细报告) 交易明细报告

交易明细报告包括商户所选时间范围内成功的支付及退款交易

> 查看报告样例：[[Excel] 交易明细报告 - TenPay Global 全球收银台](https://drive.weixin.qq.com/s?k=AJEAIQdfAAoTVriE0QAbwAWAbJAP8#/)

下表展示了交易明细报告中的字段及字段说明：

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| mch\_id | 商户号 | TenPay Global 分配的商户唯一标识 |
| listed | TenPay Global交易号 | TenPay Global 为每笔交易分配的唯一标识。 当 trade\_type = `PAYMENT` 时，等于 TenPay Global 支付单号； 当 trade\_type = `REFUND` 时，等于 TenPay Global 退款单号 |
| trade\_type | 交易类型 | 枚举值包括： `PAYMENT`（支付）、 `REFUND` （退款） |
| out\_trade\_no | 商户订单号 | 商户为每笔支付分配的唯一标识 |
| out\_refund\_no | 商户退款单号 | 商户为每笔退款分配的唯一标识。 当 trade\_type = `PAYMENT` 时，为空 |
| trade\_amount | 交易金额 | 当 trade\_type = `PAYMENT` 时，等于支付金额； 当 trade\_type = `REFUND` 时，等于退款金额 |
| trade\_currency | 交易币种 | 以 [ISO 4217](https://www.iso.org/iso-4217-currency-codes.html) 中定义的三位字母币种代码展示。 当 trade\_type = `PAYMENT` 时，等于支付币种； 当 trade\_type = `REFUND` 时，等于退款币种 |
| payment\_method\_key | 支付方式名称 | 交易对应支付方式 |
| ref\_order\_no | 参考订单号 | 商户用于追溯消费而指定的标识 |
| acquirer\_name | 合作机构名称 | 处理交易的合作机构 |
| acquirer\_trade\_no | 合作机构交易单号 | 合作机构分配的交易唯一标识 |
| trade\_finish\_time | 交易完成时间 | 当 trade\_type = `PAYMENT` 时，等于支付成功时间； 当 trade\_type = `REFUND` 时，等于退款成功时间 |
| store\_id | 门店编号 | 商户门店编号 |
| app\_id | 应用 ID | 商户小程序 ID |

## [#](#获取交易明细) 获取交易明细

通过小程序商户平台生成并下载交易明细文件：

> 注意：当日的支付或退款，可以在次日生成交易明细文件

- 登录[微信公众平台](https://mp.weixin.qq.com)，进入「全球收银台」
- 点击「交易」，进入「交易明细」页面，选择「下载交易明细」

  ![](https://res8.wxqcloud.qq.com.cn/wxdoc/c4492373-775e-4f6a-8399-21a4e3565380.png)
- 筛选「订单创建时间」、「下载文件格式」（Excel 或 PDF）后，点击「生成交易明细」

  ![](https://res8.wxqcloud.qq.com.cn/wxdoc/a435764f-15ac-4188-bbaa-a0beef5ea069.png)
- 文件生成可能需要较长时间，此时离开页面不会影响生成进度。生成完成后，点击「下载」即可获取交易明细文件
