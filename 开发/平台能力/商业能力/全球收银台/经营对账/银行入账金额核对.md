# [#](#银行入账金额核对) 银行入账金额核对

商户可以通过 TenPay Global 提供的结算账单报告，与银行入账金额进行核对

## [#](#结算规则) 结算规则

开始核对前，请先了解不同支付方式对应的结算规则

### [#](#结算规则相关术语及说明) 结算规则相关术语及说明

结算规则通常由以下信息组成：

- **结算：** 指交易完成后，合作机构扣算费用，将资金从交易完成状态扭转为预打款状态的动作。资金达到预打款状态后，还需满足打款条件，才会触发物理资金向商户银行的划转
- **结算日：** 指合作机构进行结算的时间。根据结算类型不同，结算日的计算方式也有所不同：

  | 结算类型 | 计算方式 | 示例 |
  | --- | --- | --- |
  | 日结算 (T) | 结算日根据 T+n 计算。代表 T 日成功的交易，在 n 个工作日后进行结算 |  |
  | 日结算 (D) | 结算日根据 D+n 计算。代表 D 日成功的交易，在 n 个自然日后进行结算 |  |
  | 周结算 (W) | 结算日根据 W+n 计算。代表 W 周内的交易，在次周起的第 n 个自然日进行结算 |  |
- **结算币种：** 合作机构结算时使用的货币
- **打款币种：** 合作机构将物理资金提现划转至商户银行时使用的货币
- **打款条件：** 资金结算后，物理资金向商户银行划转所需满足的条件。通常为累计金额条件，例如：尚未打款的累计结算金额需 ≥ 100 SGD，则触发物理资金打款

> 注意：若希望调整结算规则，请联系 TenPay Global 全球收银台团队

### [#](#查阅结算规则) 查阅结算规则

商户可通过以下两种方式查看结算规则：

1. 查询商户与 TenPay Global 或合作机构签订的协议中结算条款描述
2. 通过「结算管理」页面查看，步骤如下：

- 登录[微信公众平台](https://mp.weixin.qq.com)，进入「全球收银台」
- 点击「结算」，进入「结算管理」页面
- 查看不同支付方式对应的「结算日」、「结算币种」、「打款条件」等规则

| payout\_currency | 提现币种 | 提现金额对应币种，参考[ISO 4217](https://www.iso.org/iso-4217-currency-codes.html)标准； 「data unavailable」代表机构未返回对应内容 |

### [#](#结算明细表) 结算明细表

结算明细表展示了结算日所涉及的交易流水、每笔交易手续费情况及每笔交易的结算金额等信息

下表为结算明细表的字段及字段说明：

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| settle\_batch\_id | 结算批次号 | TenPay Global 分配的本次结算唯一标识 |
| listed | TenPay Global交易号 | TenPay Global 为每笔交易分配的唯一标识。 当 trade\_type = `PAYMENT` 时，等于 TenPay Global 支付单号； 当 trade\_type = `REFUND` 时，等于 TenPay Global 退款单号； 当 trade\_type = `DISPUTE` 或 `DISPUTE_REVERSE` 时，等于 TenPay Global 争议单号 |
| trade\_type | 交易类型 | 枚举值包括：`PAYMENT`（支付）、 `REFUND` （退款）、`DISPUTE` （争议扣款）、`DISPUTE_REVERSE` （争议抗辩成功，争议扭转）、`OTHER` （其他导致结算金额变动的交易类型） |
| out\_trade\_no | 商户订单号 | 商户为每笔支付分配的唯一标识 |
| out\_refund\_no | 商户退款单号 | 商户为每笔退款分配的唯一标识。 当 trade\_type = `PAYMENT` 或 `DISPUTE` 或 `DISPUTE_REVERSE` 时，为空 |
| trade\_state | 交易状态 | 当 trade\_type= `PAYMENT` 时，等于支付状态； 当 trade\_type= `REFUND` 时，等于退款状态； 当 trade\_type = `DISPUTE` 或 `DISPUTE_REVERSE` 时，为空 |
| trade\_amount | 交易金额 | 当 trade\_type = `PAYMENT` 时，等于支付金额； 当 trade\_type = `REFUND` 时，等于退款金额； 当 trade\_type = `DISPUTE` 时，等于争议扣款金额； 当 trade\_type = `DISPUTE_REVERSE` 时，等于争议扭转金额 |
| trade\_currency | 交易币种 | 以 [ISO 4217](https://www.iso.org/iso-4217-currency-codes.html) 中定义的三位字母币种代码展示。 当 trade\_type = `PAYMENT` 时，等于支付币种； 当 trade\_type = `REFUND` 时，等于退款币种； 当 trade\_type = `DISPUTE` 时，等于争议扣款币种； 当 trade\_type = `DISPUTE_REVERSE` 时，等于争议扭转币种 |
| trade\_create\_time | 交易创建时间 | 当 trade\_type = `PAYMENT` 时，等于支付创建时间； 当 trade\_type = `REFUND` 时，等于退款创建时间； 当 trade\_type = `DISPUTE` 或 `DISPUTE_REVERSE` 时，等于争议产生时间 |
| trade\_finish\_time | 交易完成时间 | 当 trade\_type = `PAYMENT` 时，等于支付成功时间； 当 trade\_type = `REFUND` 时，等于退款成功时间； 当 trade\_type = `DISPUTE` 或 `DISPUTE_REVERSE` 时，等于争议达到终态的时间，达到终态前为空 |
| payment\_method\_key | 支付方式名称 | 交易对应支付方式 |
| ref\_order\_no | 参考订单号 | 商户用于追溯消费而指定的标识； 当 trade\_type = `REFUND` 或 `DISPUTE` 或 `DISPUTE_REVERSE` 时，为空 |
| acquirer\_name | 合作机构名称 | 处理该笔交易的合作机构 |
| acquirer\_amount | 合作机构侧金额 | 该笔交易对应的合作机构受理金额 |
| acquirer\_currency | 合作机构侧币种 | 合作机构受理的币种 |
| fee\_amount | 手续费金额 | 当 trade\_type = `PAYMENT` 时，等于支付手续费金额； 当 trade\_type = `REFUND` 时，等于退款手续费金额； 当 trade\_type = `DISPUTE` 时，SG 地区表示拒付受理费用金额，JP 地区表示拒付调单费用金额 |
| fee\_currency | 手续费币种 | 当 `trade_type = PAYMENT` 时，等于支付手续费币种； 当 `trade_type = REFUND` 时，等于退款手续费币种； 当 trade\_type = `DISPUTE` 时，等于争议扣款手续费币种 |
| settle\_amount | 结算金额 | 该笔交易扣除手续费后的结算金额 |
| settle\_currency | 结算币种 | 该笔交易结算至商户的币种 |
| acquirer\_trade\_no | 合作机构交易单号 | 合作机构为该笔交易分配的唯一标识 |
| note | 交易注释 | 对于 trade\_type = `OTHER` 的交易，该字段用于解释变动原因 |
| store\_id | 门店编号 | 商户门店编号 |
| app\_id | 应用 ID | 商户小程序 ID |

## [#](#获取结算账单) 获取结算账单

通过小程序商户平台生成并下载结算账单文件：

> 注意：结算账单文件的最早可生成时间，通常为结算日后 1 自然日的下午 15:30

- 登录[微信公众平台](https://mp.weixin.qq.com)，进入「全球收银台」
- 点击「结算」，进入「结算账单」页面，选择「下载结算账单」

  ![](https://res8.wxqcloud.qq.com.cn/wxdoc/e34703e6-2bd3-468c-97ae-370a7357ba4d.png)
- 筛选「结算时间」、「收单机构」、「下载文件格式」（Excel 或 PDF）后，点击「生成结算账单」

  ![](https://res8.wxqcloud.qq.com.cn/wxdoc/2958f7f8-f607-475b-8c17-a865b5e3ddc5.png)
- 文件生成可能需要较长时间，此时离开页面不会影响生成进度。生成完成后，点击「下载」即可获取结算账单文件

  ![](https://res8.wxqcloud.qq.com.cn/wxdoc/c00fe64a-3e1b-4889-8071-720ae49a71be.png)
  > 注意：针对每个收单机构的每个结算日，仅可生成一次 Excel 格式和一次 PDF 格式的结算账单文件。生成后的文件按照结算时间排序，若需重新下载已生成过的历史结算账单，请翻阅结算账单生成记录，找到目标文件并点击下载

## [#](#FAQ) FAQ

**Q：为何某个结算日的结算金额出现负数？**

A：在开启全球收银台服务的初期，可能会出现结算金额为负值的情况，这是由于本结算周期内的逆向金额超过了正向金额扣费后的净额。结算金额出现负值是服务初期的正常现象，随着服务进行，正向支付与逆向退款等交易滚动起来后，结算金额通常会恢复为正值。若结算金额为负值，商户的结算银行账户不会收到打款，负值金额将从下一次结算金额中扣除。
