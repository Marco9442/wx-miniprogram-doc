# [#](#微信可回溯) 微信可回溯

## [#](#一、产品介绍) 一、产品介绍

可回溯是微信小程序团队推出的面向互联网保险、理财等销售场景的留痕能力，解决合规要求的可视化回溯管理问题，满足监管要求。微信可回溯支持在小程序及 H5 网页中，高性能还原销售下单现场，并灵活进行回溯管理。

**接入要求**

仅互联网保险、互联网理财场景的业务(小程序或 H5 网页)出于合规场景的需要，申请接入此能力。

**接入说明**

该能力为定向开放能力且需付费使用，有意向的开发者需填写以下资料申请体验：

[接入申请](https://wj.qq.com/s2/12995218/1016/)

我们仅用于接入评估与需求分析，会保障以上信息安全，评估通过的开发者会收到接入邀请通知以及详细的计费说明。

## [#](#二、优势介绍) 二、优势介绍

**接入便捷、无需维护**

- 提供小程序 SDK ，仅需一行代码快速接入，当天即可完成对接
- 提供全套可嵌入的回溯管理系统，查询操作便捷

**安全可靠、低成本**

- 采用自研深度优化数据格式，性能优异、存储成本极低
- 用户数据直连保司数据库，存储更安全合规

**标签关联、灵活查询**

- 回溯时可标记订单 ID 等业务标签和业务事件，灵活查询定位回溯信息
- 灵活控制可回溯范围，自定义选择所需回溯的页面与区域

**多端回溯、效果清晰**

- 微信官方回溯能力，支持原生小程序、 H5 页面统一回溯，无需额外修改代码
- 页面内容、 PDF 文件、用户点击、滑动等信息均清晰回溯
