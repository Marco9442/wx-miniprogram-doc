# [#](#评价管理) 评价管理

[小程序交易评价](https://docs.qq.com/doc/DV1lFVnBBRXFOcWVm)是小程序官方提供的真实公正的评价系统。在小程序的交易用户可针对某次交易体验进行评价打分、发表建议和感受。

## [#](#一、相关接口) 一、相关接口

以下接口提供给小程序开发者用于查询、回复、处理小程序用户交易评价。

| 接口名称 | 请求路径 | 描述 |
| --- | --- | --- |
| [查询评价列表](https://developers.weixin.qq.com/miniprogram/dev/server/API/transaction-guarantee/comment/api_getccommentlist) | /wxaapi/comment/mpcommentlist/get | 查询某小程序下面所有的评价 |
| [查询评论列表](https://developers.weixin.qq.com/miniprogram/dev/server/API/transaction-guarantee/comment/api_getcommentreplylist) | /wxaapi/comment/replyandcommentreplylist/get | 查询某评价下面所有的评论和回复 |
| [查询评价详情](https://developers.weixin.qq.com/miniprogram/dev/server/API/transaction-guarantee/comment/api_getcommentinfo) | /wxaapi/comment/commentinfo/get | 查询某条评价的详细内容 |
| [创建评论](https://developers.weixin.qq.com/miniprogram/dev/server/API/transaction-guarantee/comment/api_addreply) | /wxaapi/comment/reply/add | 目前开发者创建的第一条回复定义为评论 |
| [删除评论](https://developers.weixin.qq.com/miniprogram/dev/server/API/transaction-guarantee/comment/api_deletereply) | /wxaapi/comment/reply/delete | 目前开发者创建的第一条回复定义为评论，如果删除该条评论，基于这条评论的所有回复将会被一并删除 |
| [创建回复](https://developers.weixin.qq.com/miniprogram/dev/server/API/transaction-guarantee/comment/api_addcommentreply) | /wxaapi/comment/commentreply/add | 本接口用于对某条评论发起回复 |
| [删除回复](https://developers.weixin.qq.com/miniprogram/dev/server/API/transaction-guarantee/comment/api_deletecommentreply) | /wxaapi/comment/commentreply/delete | 本接口用于删除评论的回复 |
| [重置 API 客服 quota](https://developers.weixin.qq.com/miniprogram/dev/server/API/transaction-guarantee/comment/api_resetapikfquota) | /wxaapi/comment/apikfquota/reset | 本接口用于重置客服 quota 的 API |
| [确认和解](https://developers.weixin.qq.com/miniprogram/dev/server/API/transaction-guarantee/comment/api_confirmcompromise) | /wxaapi/comment/confirmcompromise | 本接口用于向平台反馈和解状态 |
