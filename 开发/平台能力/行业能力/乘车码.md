# [#](#仿原生乘车码) 仿原生乘车码

业务方可通过接入仿原生乘车码行业模板，在业务方小程序中快速实现公共交通的线上扫码乘车功能，以及开通线路、乘车记录、帮助中心等相关页面。

仿原生乘车码行业模板包括以下接口（在调用前需先完成小程序账号注册、微信支付商户号申请流程，并向 city\_api@tencent.com 发送接入仿原生乘车码行业模板能力的申请邮件）：

| API 名称 | API 描述 |
| --- | --- |
| [仿原生跳转](https://developers.weixin.qq.com/miniprogram/dev/server/API/cityservice/basic/api_transportcode_getbusinessview) | 根据需求不同跳转不同的微信仿原生页面实现不同的功能需求。 |
| [生码](create-code) | 微信后台向业务方请求二维码源数据，微信前端可以根据源数据生成乘车码。 |
| [支付回调](scan-code-to-pay) | 微信后台向业务方请求二维码源数据，微信前端可以根据源数据生成乘车码。 |
| [微信扣费](scan-code-to-pay#二、微信扣费接口（微信API接口）) | 用于接收业务方依据扫码接口获取到的信息对用户进行免密扣费。 |
| [用户注册/签约](user-registration-contract) | 微信后台向业主方发起用户注册。 |
| [用户解约](user-cancellation) | 微信后台向业主方通知用户注销/解约。 |
| [用户签约状态查询](contract-status) | 业主方查询用户签约状态接口。 |
| [欠费支付](payment-in-arrears) | 微信后台向业主方通知用户支付成功（支付失败时无通知）。 |
| [查询线路](check-route) | 查询设置的公交/地铁线路 |
| [设置线路](set-route) | 设置公交/地铁线路 |
| [查询欠费用户列表](query-list-arrears-users) | 微信后台会定时（每天6点开始）获取所有欠费用户列表，并提供接口查询列表接口，此后如果有用户完成欠费缴纳会在收到成功支付通知时删除记录。 |
