# [#](#短剧播放器) 短剧播放器

## [#](#一、介绍) 一、介绍

短剧播放器是微信官方为微短剧类目小程序提供的播放器插件，旨在帮助短剧开发者降低开发及运营成本，提供短剧行业的运营组件能力，提升微信内短剧播放质量及优化用户体验。
开发者可引入短剧播放器插件后，基于自身需求进行开发配置。

**具体介绍**：[短剧播放器介绍](https://docs.qq.com/slide/DRWp3Zk1RWWdWTllt)

**接入示例**：[代码示例](https://developers.weixin.qq.com/s/aswCzvmR8Q89)

## 3.1 插件如何引入

首先在小程序的 app.json 文件中添加插件的引入配置，示例代码如下：

```json
{
"plugins": {
 "playlet-plugin": {
   "version": "latest",
   "provider": "wx94a6522b1d640c3b"
 }
}
}
```

"provider"字段为插件提供方的appid，设置为"wx94a6522b1d640c3b"即可。请确保将 "version" 字段设置为 "latest"，以使用最新版本的插件。

### [#](#_3-2-插件接入流程) 3.2 插件接入流程

下面的接入流程涉及的一些字段的含义，先提前说明下：

- •`srcAppid`: 提审方 appid，通过小程序[媒资管理](mini-drama/mini_drama)上传了剧目的账号 appid。
- •`dramaId`: 剧目 ID，通过小程序[媒资管理](mini-drama/mini_drama)提审的剧目 id。
- •`serialNo`: 剧集 ID，从1开始递增，比如第 1 集则 serialNo 是 1，注意这里跟媒资管理的 mediaNo 是不一样的。

插件提供的能力说明：

- •插件提供了播放器页面，接入后可以通过播放器页面的路径使用，播放器的路径前缀为 `plugin-private://wx94a6522b1d640c3b/pages/playlet/playlet`。
- •播放器页面和小程序之间有比较多的逻辑交互，例如某一集是否能解锁观看，需要开发者提供，插件提供了一些接口来让小程序去交互。接口通过 `const playletPlugin = requirePlugin('playlet-plugin')` 返回的插件实例来调用。
- •点击可查看详细 [接口文档](videoplayer-interface)

播放器里面是否可解锁等数据，需要开发者提供，开发者可以参考下面的步骤进行接入。

#### [#](#_3-2-1-跳转到播放器页面) 3.2.1 跳转到播放器页面

在开发者的页面中跳转到播放器页面，请参考以下示例代码：

```
Page({
  onJumpPlayer() {
    const { srcAppid, dramaId } = this.data
    const extParam = encodeURIComponent('a=b&c=d') // 需要 encodeURIComponent

    // 跳转到短剧播放页
    wx.navigateTo({
      url: `plugin-private://wx94a6522b1d640c3b/pages/playlet/playlet?dramaId=${dramaId}&srcAppid=${srcAppid}&serialNo=${serialNo}&extParam=${extParam}`
    })
  },
})
```

播放器页面接收 srcAppid 参数、dramaId 参数和 serialNo 等参数，其中：

- dramaId 是开发者通过媒资管理的 API 上传的剧目 id，必填
- srcAppid 是提审方的 appid，必填
- serialNo 是指定播放的剧集id，从 1 开始递增（不是媒资管理的 mediaNo），选填，如果不传，进入播放器页面则会从上次播放的剧集开始继续播放
- extParam 是可选的扩展参数，选填，PlayletManager.getInfo() 可获得传入的此参数，分享的时候也会带上此参数，可以作为上报的参数使用。

当进入播放页时，会触发插件的 onPageLoad 回调给开发者。

#### [#](#_3-2-2-监听播放页加载) 3.2.2 监听播放页加载

```
const playletPlugin = requirePlugin('playlet-plugin')

App({
  onLaunch() {
    playletPlugin.onPageLoad(info => {
      const pm = playletPlugin.PlayletManager.getPageManager(info.playerId)

      // 初始化剧集列表状态
      pm.setCanPlaySerialList({
        serialList: [{
          start_serial_no: 1,
          end_serial_no: 4,
          status: 1, // 1-4 集解锁
        }, {
          start_serial_no: 5,
          end_serial_no: 20,
          status: 2, // 5 - 20 集未解锁
        }],
        freeList: [], // 免费剧集
      })

      // 用户进入未解锁的剧集时会触发此事件
      pm.onCheckIsCanPlay(param => {
        const serialNo = param.serialNo
        if (serialNo <= 10) {
          // 10 集以内解锁
          pm.isCanPlay({
            serialNo,
            serialList: [{
              start_serial_no: serialNo,
              end_serial_no: serialNo,
              status: 1,
            }],
          })
        } else {
          // 其他剧集不解锁 并展示支付弹窗
          pm.isCanPlay({
            serialNo,
            serialList: [{
              start_serial_no: serialNo,
              end_serial_no: serialNo,
              status: 2,
            }],
          })
          pm.showChargeDialog()
        }
      })
    })
  },
})
```

#### [#](#_3-2-3-实现后台接口初始化剧集状态) 3.2.3 实现后台接口初始化剧集状态

在上述代码中，setCanPlaySerialList({ serialList, freeList }) 接口来初始化剧集状态。

其中 serialList 是剧集解锁状态列表，类型为 `Array<SerialItem>`，SerialItem 定义如下：

| 字段名 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| start\_serial\_no | number | 是 | 起始免费剧集编号，从 1 开始 |
| end\_serial\_no | number | 是 | 结束免费剧集编号，包含此集 |
| status | number | 是 | 上面的起始和结束区间内剧集是否解锁；1 - 已解锁，2 - 未解锁 |

freeList 参数是免费剧集列表，类型为 `Array<FreeItem>`，FreeItem 定义如下：

| 字段名 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| start\_serial\_no | number | 是 | 起始免费剧集编号，从 1 开始 |
| end\_serial\_no | number | 是 | 结束免费剧集编号，包含此集 |

> 注意：免费剧集配置与“微短剧”优质小程序流量主激励政策有重要关联；它是已解锁剧集的一个特殊状态，和普通的已解锁剧集只有 ui 上的不同。免费剧集的 ui 如下：

#### [#](#_3-2-4-解锁剧集) 3.2.4 解锁剧集

当用户进入到未解锁的剧集时，会触发开发者使用 `onCheckIsCanPlay` 方法注册的回调函数。开发者需要在此回调函数中判断用户是否可以解锁该集。

开发者可以调用 `isCanPlay({ serialNo, serialList })` 方法来设置该集的解锁状态，同时消除播放器的 loading。此处的 `serialList` 定义和 `setCanPlaySerialList` 的 `serialList` 参数一致。

开发者将该集设置为解锁后，播放器便会自动开始播放该集内容；如果开发者将该集仍然设置为未解锁，播放器便会显示相应的未解锁界面，提示用户需要解锁才能继续观看。

#### [#](#_3-2-5-充值组件) 3.2.5 充值组件

充值组件是一个自定义组件，会渲染在播放页面的半屏弹窗中。开发者需要自己实现此组件的充值逻辑，充值组件存在最大高度限制，如果内容高度超过弹窗高度，需使用 scroll-view 组件实现滚动。开发者需提前获取到渲染弹窗内容所需要的数据，避免在弹窗拉起的时候内容变化导致弹窗高度发生变化。

![image.png](https://res.wx.qq.com/op_res/qz5adP_wJ2mYx6Z3FW6p0fS41mCOyKdesuC3XMQulMI40GEF80ipt7niqtNF1SrWnriNor-OprUO3LPFJ6UAFA)

1. 1.在 app.json 文件中，需要定义组件 charge-dialog，指向开发者自己实现的充值组件。示例代码如下：

  "plugins": {
    "playlet-plugin": {
      "version": "latest",

          "charge-dialog": "/components/charge-dialog/charge-dialog"

> 注意：如果是在分包引入插件，上面定义的充值组件也需要在分包内。
```

#### [#](#_3-2-7-数据加密方案) 3.2.7 数据加密方案

上述例子中的 setCanPlaySerialList 和 isCanPlay 方法的调用都是直接传递剧集解锁信息给播放器来实现剧集解锁状态的变更。如果开发者对剧集解锁状态的变更有更高的安全性要求且能承担**一定的性能损失**，还可以选用传递加密数据的方式来实现剧集解锁。

> 注意：选用加密方案的话安全性相对较高，但性能会有所损耗，可根据实际情况选用对应方案。

具体调用方式如下：

```
// 无需加密方案
pm.setCanPlaySerialList({
  serialList: [{
    start_serial_no: 1,
    end_serial_no: 4,
    status: 1, // 解锁
  }, {
    start_serial_no: 5,
    end_serial_no: 20,
    status: 2, // 未解锁
  }],
  freeList: [],
})
pm.onCheckIsCanPlay(param => {
  pm.isCanPlay({
    serialNo: 15,
    serialList: [{
      start_serial_no: 15,
      end_serial_no: 15,
      status: 1, // 解锁
    }],
  })
})

// 加密方案
const data = await getEncryptData() // getEncryptData 需要开发者自行实现
pm.setCanPlaySerialList({
  data,
  freeList: [],
})
pm.onCheckIsCanPlay(async param => {
  const data = await getEncryptData() // getEncryptData 需要开发者自行实现
  pm.isCanPlay({
    serialNo: 15,
    data,
  })
})
```

其中 data 参数是加密后的数据，即 LockDataReq 对象经过 JSON.stringify，然后再加密后得到的字符串。LockDataReq 定义如下：

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| openid | string | 当前观看用户的openid |
| src\_appid | string | 提审方小程序的appid |
| drama\_id | string | 提审的剧目id |
| serial\_list | `Array<SerialItem>` | SerialItem 数组，SerialItem 定义同上 |
| data\_expire\_at | number | 数据有效期，时间戳（秒）。到时间过期不可用，建议当前时间戳 +2 小时 |

> 注意：接入了免开发激励视频广告解锁必须采用加密方案来调用 setCanPlaySerialList 和 isCanPlay 方法。

##### [#](#具体加密流程) 具体加密流程

上述加密方案中的加密数据需要经过在开发者后台使用 session\_key 的前16个字节作为密钥加密（不足 16 个字节后面补零），加密算法 AES-128-ECB。

加密步骤：

1. 1.调用微信 api 获取当前登录用户的最新 session\_key

![image.png](https://res.wx.qq.com/op_res/qz5adP_wJ2mYx6Z3FW6p0fK8lvPkPC_9S_MGJsIRcqcLLswrg4NmYx1bdmGeyW7w2Gd1lVBKVv30ymr5gJLKBQ)

1. 2.使用 LockDataReq 结构组装待加密的明文数据（LockDataReq 定义见上述介绍）
2. 3.将 LockDataReq 转成 json 字符串 data
3. 4.使用 AES-128-ECB 算法对 data 进行加密，密钥是第 1 步获取的 session\_key 的前 16 个字节
4. 5.对 data 加密后的密文进行 base64 编码

示例：

1. 1.LockDataReq 转成 json 的示例（以下示例表示解锁第 10-12 集,不解锁第 13-15 集）

```
{"openid":"xJad239kjafkjakdjfe","src_appid":"wx98293892389823","drama_id":"21212","serial_list":[{ "start_serial_no":10,"end_serial_no":12,"status":1},{"start_serial_no":13,"end_serial_no":15,"status":2}], "data_expire_at":1703474855}
```

1. 2.加密示例

### [#](#_4-4-数据上报) 4.4 数据上报

```

开发者可通过此方法注册回调函数获得数据上报相关的回调，其中event表示上报的点，event是个枚举值，具体的取值如下。
每个上报事件，都会有一些公共的字段会带回给开发者：

| 字段名 | 描述 |
| --- | --- |
| playerId | 播放器id |
| srcAppid | 提审方appid |
| extParam | 分享扩展参数 |

每个事件还有自己额外的一些字段，具体如下：

| 值 | 描述 | 额外字段说明 |
| --- | --- | --- |
| LOAD | 进入播放器页面 |  |
| SHOW | 播放器页面 show |  |
| START\_PLAY | 开始播放 |  |
| UNLOAD\_OR\_HIDE | 离开页面或者退后台 | 例如 { type: 1 }。type 为 1 表示Unload，为 2 表示 hide |
| VIDEO\_END | 播放视频结束 |  |

### [#](#_4-8-设置免费剧集列表) 4.8 设置免费剧集列表

开发者可以进入页面就通过 `setCanPlaySerialList(freeList: [])` 接口设置免费剧列表（只针对已解锁剧集生效），如果开发者需要在用户观看过程中重新设置免费剧列表，可通过setFreeList设置，注意：此接口仅改变目录中的剧集显示状态，并不会做真正的解锁处理。

```
PlayletManager.setFreeList({
  list: [{ start_serial_no: 1, end_serial_no: 10 }], // 1~10集是免费剧集
})
```

### [#](#_4-9-设置用广告解锁剧集) 4.9 设置用广告解锁剧集

开发者可以进入页面就通过 `setUseAdUnlock(list: [])` 接口设置需要广告解锁的剧集，设置后，解锁按钮的文案变为“看广告后播放”，点击后不会拉起充值弹窗，会回调给开发者事件。

> 注意：通过此接口设置的剧集，在选集界面上的 ui 表现会和免费剧集一样。

```
PlayletManager.setUseAdUnlock({
  list: [{ start_serial_no: 79, end_serial_no: 80 }], // 79~80集会通过广告解锁
})
```

开发者可通过接口 `onUseAdUnlock` 注册点击按钮的事件，通过激励视频去解锁

```
pm.onUseAdUnlock(function() {
  // 拉起激励视频广告去解锁
})
```

设置广告解锁后，当用户即将进入需要广告解锁的剧集时，会出现广告倒计时提示。此时开发者可在广告倒计时提示的曝光事件（即 `AD_WILL_PLAY_TIPS_SHOW` 事件）中提取拉取并初始化广告，然后在进入对应广告解锁剧集触发的 `checkIsCanPlay` 事件中会有 `needToCancelAdTimer` 字段为 `true`，表示当前用户已经看到了对应当前剧集的广告倒计时提示，可以不用再显示广告倒计时弹窗。

如果用户在广告倒计时中点击了“暂不观看”，则会触发 `CLICK_CANCEL_AD_TIPS` 事件，表示用户暂时不想观看广告。此时进入到对应广告解锁剧集时不会触发 `checkIsCanPlay` 事件，并停留在该集的解锁页面。

### [#](#_4-10-设置剧集未解锁时的视频预览) 4.10 设置剧集未解锁时的视频预览

开发者可以设置剧集未解锁时的视频预览。当用户进入未解锁剧集时，可以在展示解锁按钮的同时在后台播放剧集视频预览：

```
// 播放预览
pm.startBackgroundPreview({
	loop: true, // 是否循环
	mask: true, // 是否遮罩
	muted: true, // 是否静音
})

// 停止预览播放
pm.stopBackgroundPreview()
```

> 注意：视频预览功能，会有泄漏播放链接的风险，且该能力会消耗商家流量，请按需使用。

### [#](#_4-11-退出横屏) 4.11 退出横屏

### [#](#_4-13-最近观看组件) 4.13 最近观看组件

{

    "recent-list": "plugin://playlet-plugin/recent-list"
  }

`recent-list`即是最近观看组件，在页面 `wxml` 中添加组件：

<recent-list
    showHeader="{{true}}"

组件的使用和小程序组件类似，两个组件接收参数 `url`，`url` 表示列表为空的时候，点击“去看剧”跳转的链接，`tapempty` 事件表示点击了“去看剧”。

`click` 事件表示点击了对应的剧。

`showHeader` 属性表示是否显示组件的标题。

### [#](#_4-14-刷剧组件) 4.14 刷剧组件

提供刷剧组件以供开发者实现类似短剧广场等类似功能。在页面的 page.json 里引入组件：

```
{
  "usingComponents": {
    "drama-feed-list": "plugin://playlet-plugin/drama-feed-list"
  }
}
```

在页面wxml中添加组件：

```
<drama-feed-list
  id="drama-feed-list"
  autoplay
  bind:videoPlay="onVideoPlay"
  bind:videoPause="onVideoPause"
  bind:videoEnded="onVideoEnded"
  bind:videoError="onVideoError"
  bind:change="onChange"
  bind:watchFullDrama="onWatchFullDrama"
></drama-feed-list>
```

其中组件支持的参数如下：

| 参数名 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| shareSrcAppid | string |  | 置顶短剧的 srcAppid |
| shareDramaId | string | 置顶短剧的 dramaId |  |
| autoplay | boolean | false | 组件初创时是否需要自动播放 |
| mode | string |  | 刷剧模式，默认为普通刷剧，可传入 `custom-list` 表示自定义刷剧 |
| custom-list | Array | [] | 当 mode 为 `custom-list` 时需传入，表示自定义的刷剧列表 |

组件支持的事件如下：

| 事件名 | 描述 |
| --- | --- |
| videoPlay | 视频播放事件 |
| videoPause | 视频暂停事件 |
| videoEnded | 视频播放结束 |
| videoError | 视频播放报错 |
| change | 切换视频 |
| watchFullDrama | 点击“看全集”按钮 |
| willReachEnd | 列表即将触底事件，当 mode 为 `custom-list` 时才会触发 |
| reachEnd | 列表触底事件 |

事件中的 detail 字段会带有下述参数：

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| dramaId | string | 当前短剧的 dramaId |
| srcAppid | string | 当前短剧的 srcAppid |
| desc | string | 当前短剧的描述 |
| mediaCount | number | 当前短剧的总集数 |
| dramaName | string | 当前短剧的剧名 |
| playTime | number | 当前视频的播放时长 |
| duration | number | 当前视频的总时长 |
| err | Object | 错误对象，videoError 事件才会返回 |
| index | number | 当前短剧在列表中的下标 |
| direction | number | 划动方向，change 事件才会返回，1 表示向下划动，2 表示向上划动 |

如果需要控制刷剧组件的播放和暂停，可通过调用组件实例的方法实现：

```
this.selectComponent('#drama-feed-list').play()
this.selectComponent('#drama-feed-list').pause()

// 当 mode 为 custom-list 的时候，还支持以下接口
this.selectComponent('#drama-feed-list').appendCustomList([{ dramaId: '', srcAppid: '' }])
this.selectComponent('#drama-feed-list').replaceCustomList([{ dramaId: '', srcAppid: '' }])
```

使用刷剧组件有以下几点需要注意：

1. 1.目前刷剧组件播放的都是短剧的第一集。
2. 2.当前视频播放完后，刷剧组件并不会切到下一集/下一部短剧，而是自动重播当前视频。
3. 3.点击“看全集”按钮时触发的 watchFullDrama 事件需要开发者处理，一般可处理为跳转到该短剧的实际播放页。

刷剧组件本身有两种模式，一种是普通模式，一种是自定义刷剧模式。其中普通模式为开发者通过下述后台接口设置刷剧剧目，然后刷剧组件会从后台拉取推荐列表进行展示；而自定义刷剧模式则完全由开发者提供刷剧列表，刷剧组件只补全对应的信息再进行展示。

1. 1.刷剧剧目设置接口：[刷剧剧目设置](https://developers.weixin.qq.com/miniprogram/dev/server/API/dramaOthersAPI/api_developersetflushdrama)
2. 2.自定义刷剧模式：当组件属性 mode 传入 `custom-list` 字符串时表示切换到自定义刷剧模式，此时要求开发者必须传入 custom-list 属性：

```
```html
<drama-feed-list
  id="drama-feed-list"
  mode="custom-list"
  custom-list=""
  autoplay
  bind:videoPlay="onVideoPlay"
  bind:videoPause="onVideoPause"
  bind:videoEnded="onVideoEnded"
  bind:videoError="onVideoError"
  bind:change="onChange"
  bind:watchFullDrama="onWatchFullDrama"
  bind:willReachEnd="onWillReachEnd"
  bind:reachEnd="onReachEnd"
></drama-feed-list>
```

其中 customList 的结构如下：

```js
Component({
  data: {
    customList: [
      { dramaId: '', srcAppid: '' },
      { dramaId: '', srcAppid: '' },
      // ...
    ],
  },
})
```

因为短剧是通过 dramaId 和 srcAppid 来确定唯一一部剧，所以开发者只需要传入 dramaId 和 srcAppid 即可，刷剧组件会将这部剧的其余信息填补进去后进行展示。

当短剧列表即将被划动到底部时，刷剧组件会触发 willReachEnd 事件，开发者可在此事件中进行列表补充：

```js
// 此处传入的列表会追加到现有的刷剧列表后面
this.selectComponent('#drama-feed-list').appendCustomList([
  { dramaId: '', srcAppid: '' },
  { dramaId: '', srcAppid: '' },
  // ...
])
```

> 注意：刷剧组件里会将列表中每 3 项计为一组，willReachEnd 事件目前会在划到倒数第二组的时候触发。建议传入的自定义列表至少为两组以上。

如果开发者想直接替换掉完整的刷剧列表，可以调用下述接口：

```js
// 此处传入的列表会替换掉现有的刷剧列表
this.selectComponent('#drama-feed-list').replaceCustomList([
  { dramaId: '', srcAppid: '' },
  { dramaId: '', srcAppid: '' },
  // ...
])
```

#### [#](#_5-1-3-分享参数) 5.1.3 分享参数

您可以在 URL 中传入 `extParam` 参数，在分享时会将此参数带到分享出去的卡片上。有两种设置 `extParam` 的方式：

1. 1.在 `navigateTo` 跳转页面时，将此参数放到 URL 上。
2. 2.通过 `PlayletManager.setExtParam(extParam)` 设置。注意，我们会对此参数进行 `encodeURIComponent` 编码，因此在获取此参数时，开发者需要进行 `decodeURIComponent` 解码操作后再解析。

#### [#](#_5-1-4-shareId) 5.1.4 shareId

每次分享都会在分享出去的小程序卡片或者小程序码的 `path` 里面带参数 `shareId`，而且此 `shareId` 会通过 `onDataReport` 事件报给开发者，当用户再从卡片进入播放器，开发者可通过 `getShareParams` 方法获得此参数，进一步关联之前分享的用户，做一些分享相关的运营活动。

```
// 开启分享以及 withShareTicket
pm.setDramaFlag({
  share: true,
  withShareTicket: true
})

// 获取分享参数,页面栈只有短剧播放器一个页面的时候可获取到此参数
// 例如从分享卡片进入、从投流广告直接跳转到播放器页面，从二维码直接进入播放器页面等情况
playletPlugin.getShareParams().then(res => {
  console.log('getLaunch options query res', res)

  // 关于 extParam 的处理，需要先做 decodeURIComponent 之后才能得到原值
  const extParam = decodeURIComponent(res.extParam)
  console.log('getLaunch options extParam', extParam)

  // 如果设置了 withShareTicket 为true，可通过文档的方法获取更多信息
  // 1003848
  const enterOptions = wx.getEnterOptionsSync()
  console.log('getLaunch options shareTicket', enterOptions.shareTicket)
}).catch(err => {
  console.error('getLaunch options query err', err)
})

// 设置分享参数
pm.setExtParam('scene')
```

#### [#](#_5-1-5-分享组件) 5.1.5 分享组件

分享组件用于自定义一些分享信息，具体使用如下：

首先在组件中的 `json` 里引用分享组件：

```
{
  "usingComponents": {
    "playlet-share": "plugin://playlet-plugin/share"
  }
}
```

在组件 `wxml` 中引入分享组件：

```
<playlet-share
  imageUrl="{{imageUrl}}"
  title="{{title}}"
  shareExt="ext%3D1%26extb%3D2"
>
  <text>点击分享</text>
</playlet-share>
```

`imageUrl` 是分享卡片的图片，`title` 是分享卡片的标题，`shareExt` 是分享的自定义参数，会带在小程序的页面路径上。

### [#](#_5-3-自定义开放区域) 5.3 自定义开放区域

为了最大程度提高播放器的灵活性，目前开放了一些区域让开发者自定义，可开放的的区域如下图所示：

![image.png](https://res.wx.qq.com/op_res/JexfFJndbjLMAEuxoC4DS7S-rlto6Hi7l-LHbf49S8YOUMJSyGf1N-BenL2E_IxjNOwK30OQcTMDWa_bJnK_AQ)
> 注意：open-area-left-side 和 open-area-left 的区域是一样的，均如上图所述，其中 open-area-left-side 可设置多个实例，且可定义每个组件实例的宽高和位置。

具体接入类似充值弹窗的内容，首先在 app.json 内注册组件，如下所示

```
{
  "usingComponents": {
    "charge-dialog": "/components/charge-dialog/charge-dialog",
    "open-area-left": "/components/open-area-left/open-area-left",
    "open-area-left-side": "/components/open-area-left-side/open-area-left-side",
  },
  "plugins": {
    "playlet-plugin": {
      "version": "latest",
      "provider": "wx94a6522b1d640c3b",
      "genericsImplementation": {
        "playlet": {
          "charge-dialog": "/components/charge-dialog/charge-dialog",
          "open-area-left": "/components/open-area-left/open-area-left",
          "open-area-left-side": "/components/open-area-left-side/open-area-left-side",
        }
      }
    }
  }
}
```

open-area-left、open-area-left-side 是开发者需要实现的组件，当需要展示这几个组件的时候，可调用 PlayletManager 的 updateOpenArea 方法来显示/隐藏组件：

```
pm.updateOpenArea({
  showLeft: true, // 显示 open-area-left 组件
  leftWidth: 72, // 宽度，超出截断
  leftHeight: 100, // 高度，超出截断

  // 显示 open-area-left-side 组件
  leftsideAreaList: [{
    // left、top、width、height 定义每个元素的位置
    left: 10,
    top: 100,
    width: 400,
    height: 172,

    // 同时可以透传一些字段给组件内部
    xxx: '',
  }],
  ext: '', // 如果需要统一额外传一些数据给组件，可通过此参数传入
})
```

以下为组件的实现参考：

```
// open-area-left 组件
Component({
  properties: {
    playerId: {

    },

      type: Number,

    },
    ext: {
      type: String,
      value: '',
    },
  },
})

// open-area-left-side 组件
Component({
  properties: {
    playerId: {
      type: String,
      value: ''
    },
    serialNo: {
      type: Number,
      value: 0
    },
    ext: {
      type: String,
      value: ''
    },
    item: { // 对应的 leftsideAreaList 数组中的某一项
      type: Object,
      value: {},
    },
    index: { // 对应的 leftsideAreaList 数组中的下标
      type: Number,
      value: 0,
    },
  },

### [#](#_6-3-投放路径设置) 6.3 投放路径设置

**投放的页面路径**

`plugin-private://wx94a6522b1d640c3b/pages/playlet/playlet?dramaId={dramaId}&srcAppid={srcAppid}&extParam={extParam}`

其中 `{dramaId}` 表示剧集 id，`{srcAppid}` 提审方 `appid`，请替换成对应的参数，`{extParam}` 是分享参数，具体见分享章节介绍

**存量投放链接处理**

若之前投放的链接是 `pages/player/index`，可使用 `redirectTo` 跳转到播放器的页面链接
（即 `plugin-private://wx94a6522b1d640c3b/pages/playlet/playlet` 开头的链接），用户在播放器页面点击左上角后，可返回首页。
