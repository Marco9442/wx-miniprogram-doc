# [#](#用户解约（可选）) 用户解约（可选）

微信后台向业主方通知用户注销/解约。

## [#](#_1、请求参数) 1、请求参数

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| appid | string | Y | 小程序 |
| mch\_id | string | Y | 支付商户号 |
| nonce\_str | string | Y | 随机字符串 |
| encrypted\_data | string | Y | 使用AESCBCPKCS7PADDING |
| iv | string | Y | 用于解密的 IV（base64） |
| sign | string | Y | 1~5字段的签名 |

encrypted\_data 解密后的数据

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| openid | string | Y | 用户 openid |
| cardid | string | N | 业主方的用户标识 |

## [#](#_2、返回参数) 2、返回参数

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| errcode | int | Y | 0为成功 |
| errmsg | string | N | 错误信息 |
| nonce\_str | string | Y | 原样带回 |

## [#](#_3、示例代码) 3、示例代码

请求：

```
{"appid":"test","mch_id":"123456","nonce_str":"abcdefg","encrypted_data":"jfiwajeofjiefef","iv":"afweifwefe"}
```

encrypted\_data 解密后为:

```
{"openid":"1234","cardid":"1234"}
```

返回:

```
{"errcode":0,"nonce_str":"abcdefg","encrypted_data":"jfiwajeofjiefef","iv":"afweifwefe"}
```

Incorrect translation.
