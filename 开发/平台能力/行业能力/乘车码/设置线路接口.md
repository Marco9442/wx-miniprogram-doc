# [#](#设置线路接口) 设置线路接口

设置公交/地铁线路。

## [#](#_1、请求参数) 1、请求参数

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| type | int | Y | 类型 0-地铁 1-公交 |
| conf | object | Y | 设置的线路配置 |

其中 conf 的内容如下：

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| line\_list | array | Y | 线路信息 |

其中 conf.line\_list 的每一项内容如下：

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| id | int | Y | 线路的唯一 id |
| start\_station | string | Y | 起点站 |
| end\_station | string | Y | 终点站 |
| line\_name | string | Y | 线路名称 |

## [#](#_2、返回参数) 2、返回参数

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| errcode | int | Y | 错误码 |
| errmsg | string | Y | 错误信息 |
