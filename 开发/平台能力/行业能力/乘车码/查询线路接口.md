# [#](#查询线路接口) 查询线路接口

查询设置的公交/地铁线路。

## [#](#_1、请求参数) 1、请求参数

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| type | int | Y | 类型 0-地铁 1-公交 |

## [#](#_2、返回参数) 2、返回参数

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| errcode | int | Y | 错误码 |
| errmsg | string | Y | 错误信息 |
| results | object | N | 线路信息 |

其中 results 的内容如下：

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| line\_list | array | Y | 线路信息 |

其中 results.line\_list 的每一项内容如下：

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| id | int | Y | 线路的唯一 ID |
| start\_station | string | Y | 起点站 |
| end\_station | string | Y | 终点站 |
| line\_name | string | Y | 线路名称 |
