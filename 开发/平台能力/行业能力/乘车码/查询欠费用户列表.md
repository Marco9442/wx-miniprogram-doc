# [#](#查询欠费用户列表) 查询欠费用户列表

微信后台会定时（每天6点开始）获取所有欠费用户列表，并提供接口查询列表接口，此后如果有用户完成欠费缴纳会在收到成功支付通知时删除记录。

## [#](#_1、请求参数) 1、请求参数

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| start\_openid | string | N | 开始的openid,从头开始填空，start\_openid不会包含在返回结果中 |
| limit | int | Y | 最大返回数量(0,10000] |

## [#](#_2、返回参数) 2、返回参数

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| errcode | int | Y | 错误码 |
| errmsg | string | Y | 错误信息 |
| list | array | N | 返回欠费用户列表 |

其中list的每一项的内容如下：

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| openid | string | Y | 用户openid |
| fee | int | Y | 欠费金额 |
| create\_time | int | Y | 更新的时间 |
| out\_user\_id | string | N | 用户在业主方的id，当设置了注册回调后才有 |
