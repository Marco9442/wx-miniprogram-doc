# [#](#用户签约状态查询) 用户签约状态查询

业主方查询用户签约状态接口。

## [#](#_1、请求参数) 1、请求参数

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| openid | string | N | 用户openid(优先使用) |
| cardid | string | N | 业主方的用户标识，注册接口返回 |

## [#](#_2、返回参数) 2、返回参数

| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| errcode | int32 | Y | 返回码 |
| errmsg | string | N | 返回信息 |
| status | int | Y | 用户签约状态 0-已签约 1-未签约 |

## [#](#_3、示例代码) 3、示例代码

请求：

```
{"openid":"afefawefwef","cardid":"123"}
```

返回:

```
{"errcode":0,"errmsg":"ok","status":0}
```

Incorrect translation.
