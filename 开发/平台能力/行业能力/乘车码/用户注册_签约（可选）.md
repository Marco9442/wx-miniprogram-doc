## [\#](https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/industry/ridecode/user-registration-contract.html\#\_1%E3%80%81%E8%AF%B7%E6%B1%82%E5%8F%82%E6%95%B0) 1、请求参数
| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| appid | string | Y | 小程序 |
| appidmch\\_id | string | Y | 支付商户号 |
| nonce\\_str | string | Y | 随机字符串 |
| encrypted\\_data | string | Y | 使用AESCBCPKCS7PADDING |
| iv | string | Y | 用于解密的IV |
| sign | string | Y | 1~5字段的签名 |
encrypted\\_data解密后的数据
| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| openid | string | Y | 用户id |
## [\#](https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/industry/ridecode/user-registration-contract.html\#\_2%E3%80%81%E8%BF%94%E5%9B%9E%E5%8F%82%E6%95%B0) 2、返回参数
| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| errcode | int | Y | 0为成功 |
| errmsg | string | N | 错误信息 |
| nonce\\_str | string | Y | 原样带回 |
| encrypted\\_data | string | Y | 使用AESCBCPKCS7PADDING |
| iv | string | Y | 用于解密的IV |
encrypted\\_data解密后的数据
| 参数名称 | 类型 | 必选 | 备注 |
| --- | --- | --- | --- |
| cardid | string | Y | 用户卡ID |
## [\#](https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/industry/ridecode/user-registration-contract.html\#\_3%E3%80%81%E7%A4%BA%E4%BE%8B%E4%BB%A3%E7%A0%81) 3、示例代码
请求：
```json
{"appid":"test","mch\_id":"123456","nonce\_str":"abcdefg","encrypted\_data":"jfiwajeofjiefef","iv":"afweifwefe"}
```
encrypted\\_data解密后为:
```json
{“openid”:”1234”}
```
返回:
```json
{"errcode":0,"nonce\_str":"abcdefg","encrypted\_data":"jfiwajeofjiefef","iv":"afweifwefe"}
```
encrypted\\_data解密后的数据:
```json
{“card\_id”:”xxafdafd”}
```
