# [#](#直播与实时音视频使用指南) 直播与实时音视频使用指南

## [#](#_1、使用前须知) 1、使用前须知

为了帮助开发者在 App 中实现直播以及实时音视频相关功能，多端框架已经支持和[腾讯云直播 SDK](https://cloud.tencent.com/document/product/454) 以及[腾讯云实时音视频（TRTC）](https://cloud.tencent.com/document/product/647)集成，参考下方的指引完成相关的配置以及按照指南进行接入即可实现相关功能。

## [#](#_2、关于合规指南) 2、关于合规指南

根据监管部门要求，使用 SDK 时必须在《隐私政策》中告知终端用户 SDK 使用用途，并且在终端用户未同意《隐私政策》前不得初始化任何 SDK。请确保你开发或运营的应用有符合监管要求的《隐私政策》文本。同时请你务必明确告知终端用户你的应用使用了移动推送服务。

- 《[实时音视频 TRTC SDK 个人信息保护规则](https://cloud.tencent.com/document/product/647/57574)》
- 《[实时音视频 TRTC SDK 合规使用指南](https://cloud.tencent.com/document/product/647/97575)》
- 《[腾讯云视立方·直播 SDK 个人信息保护规则](https://cloud.tencent.com/document/product/454/61839)》
- 《[直播 SDK 合规使用指南](https://cloud.tencent.com/document/product/454/97573)》

### [#](#_3、关于问题反馈) 3、关于问题反馈

- 如果是小程序多端框架的问题，可前往[社区](https://developers.weixin.qq.com/community/develop/mixflow)反馈。
- 如果是直播 SDK 的功能或者相关问题，可[点此](https://cloud.tencent.com/document/product/454/7998)联系腾讯云官方团队反馈
- 如果是实时音视频的功能或者相关问题，可[点此](https://cloud.tencent.com/document/product/647/19906)联系腾讯云官方团队反馈
