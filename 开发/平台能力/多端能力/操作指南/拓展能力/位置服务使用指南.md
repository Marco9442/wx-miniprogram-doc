# [#](#位置服务使用指南) 位置服务使用指南

## [#](#一、使用前须知) 一、使用前须知

多端应用中地图与位置服务相关 JSAPI 能力，如 `Map 组件`、`wx.openLocation` 等 location 相关接口能力，是基于[腾讯位置服务](https://lbs.qq.com/)服务实现，开发者需前往腾讯位置服务控制台注册开发者账号，并创建对应以获取 LBS SDK 所需的 Key。为方便开发者更好地理解整体逻辑，需认真阅读本章节的内容：

- 首先，前往[腾讯位置服务](https://lbs.qq.com/)控制台注册开发者账号，并创建应用以获取 LBS SDK 所需的 Key
- 然后，在开发者工具中配置启用「LBS SDK」，并填入对应 Key
- 最后，在 JS 代码侧使用调用 location 相关 JSAPI
- 此服务是腾讯位置服务的服务，个人开发者、企业开发者、商业授权开发者初始额度不同，如果需更高的额度则需付费提额，详情可查看[配额限制说明](https://lbs.qq.com/dev/console/quotaImprove)
- 以及，如需商业化授权可查看详情[腾讯位置服务商业化服务](https://lbs.qq.com/dev/console/authorization)

### [#](#_1、关于-SDK-版本要求) 1、关于 SDK 版本要求

- iOS SDK：需使用版本号 ≥ 1.0.14
- Android SDK：需使用版本号 ≥ 1.0.7
- HarmonyOS SDK：需使用版本号 ≥ 0.5.9

**补充**：Android core sdk 选择 1.2.0 及以上，Android 对应的 lbs sdk 也要选 1.2.0 及以上，否则构建会失败的。

### [#](#_2、关于合规指南) 2、关于合规指南

根据监管部门要求，使用 SDK 时必须在《隐私政策》中告知终端用户 SDK 使用用途，并且在终端用户未同意《隐私政策》前不得初始化任何 SDK。请确保你开发或运营的应用有符合监管要求的《隐私政策》文本。同时请你务必明确告知终端用户你的应用使用了腾讯位置服务。

- [Android LBS SDK 合规指南](https://lbs.qq.com/mobile/androidLocationSDK/androidLBSInfo)
- [iOS LBS SDK 合规指南](https://lbs.qq.com/complianceGuides/guides/sdkGuides/positionSdkComplianceGuide)

### [#](#_4、JSAPI-列表) 4、JSAPI 列表

LBS SDK，包括地图、定位、罗盘、加速计和设备方向等能力；其中地图和定位能力需配置腾讯位置服务 Key，相关的 JSAPI 列表如下（下面接口 Android 和 iOS 端）：

| 名称 | 功能说明 | 鸿蒙端支持情况 |
| --- | --- | --- |
| [wx.stopLocationUpdate](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.stopLocationUpdate.html) | 关闭监听实时位置变化，前后台都停止消息接收 | 支持 |
| [wx.startLocationUpdateBackground](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.startLocationUpdateBackground.html) | 开启小程序进入前后台时均接收位置消息，需引导用户开启[授权](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/authorize) | 支持 |
| [wx.startLocationUpdate](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.startLocationUpdate.html) | 开启小程序进入前台时接收位置消息 | 支持 |
| [wx.openLocation](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.openLocation.html) | 使用微信内置地图查看位置 | 支持 |
| [wx.onLocationChangeError](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.onLocationChangeError.html) | 监听持续定位接口返回失败时触发 | 支持 |
| [wx.onLocationChange](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.onLocationChange.html) | 监听实时地理位置变化事件，需结合 wx.startLocationUpdateBackground、wx.startLocationUpdate 使用 | 支持 |
| [wx.offLocationChangeError](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.offLocationChangeError.html) | 移除持续定位接口返回失败时触发 | 支持 |
| [wx.offLocationChange](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.offLocationChange.html) | 移除实时地理位置变化事件的监听函数 | 支持 |
| [wx.getLocation](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.getLocation.html) | 获取当前的地理位置、速度 | 支持 |
| [wx.chooseLocation](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.chooseLocation.html) | 打开地图选择位置 | 尚未支持 |

**注意事项**

- 使用该能力，构建 IPA 时不可选择「临时签名」，必须选择「证书签名」

**补充说明**

- wx.chooseLocation 涉及在腾讯位置服务的相关接口为：逆地址解析（/ws/geocoder/v1/?location=）、关键词提示（/ws/place/v1/suggestion）、周边推荐（/ws/place/v1/explore）
