# [#](#使用「苹果登录」配置) 使用「苹果登录」配置

使用[wx.appleLogin](../../api/auth/wx.appleLogin)需完成以下配置内容。

## [#](#一、开发平台控制台) 一、开发平台控制台

接入 Apple 登录，首先需要从苹果开发者网站上获取如下几个信息：

- Team ID：唯一标识苹果开发者的信息
- Bundle ID：唯一标识苹果应用的信息
- Key ID：私钥 ID
- Private Key：私钥

开发者可根据以下步骤指引完成：

### [#](#_1-1-获取-Team-ID) 1.1 获取 Team ID

使用苹果开发者账号登录前往 Membership 页面，获取 Team ID（需要是认证且付费过的开发者）

![](https://res.wx.qq.com/op_res/ReLDBB615JweK2uM2d6UDxICPua1Sphm3RiNXerj1E2jDjcz2nB-JY86se486SeTxt6QwBZEHLMiE1s5S1HmlQ)

### [#](#_1-2-获取-Bundle-ID) 1.2 获取 Bundle ID

前往苹果开发者页面，在「Certificates, Identifiers & Profiles > Identifiers」页面，点击图标创建应用

![](https://res.wx.qq.com/op_res/ReLDBB615JweK2uM2d6UD6firZbrNoEyhThPooMbgoltmwGFG7jyXnCYnvCLPIFyO6k_gfM7yWWGr7pl4vOaww)

选择 App IDs 然后点击 Continue 按钮继续

![](https://res.wx.qq.com/op_res/ReLDBB615JweK2uM2d6UD-jWIHEkcb4Ot8OPCTTH94-JPri2GSGzGL2wZksgYABn1wt9zz7A2VJtthNfycDD5g)

选择格式的应用类型，然后点击 Continue 按钮继续

![](https://res.wx.qq.com/op_res/ReLDBB615JweK2uM2d6UD0MTDwmBsTJE1UAZ12KZkTUlu--b7vzqwnMDxtpgG4zqeO4CXtaRIw-tj0SeW57H7A)

填写应用描述和 Bundle ID，请记录下此 Bundle ID

![](https://res.wx.qq.com/op_res/ReLDBB615JweK2uM2d6UD-NC0CB0YJL2hlK998MC5Jx5lvuJ6bVmRfofwmKc5_YI_hVDbqsjVEuzsC3T4lGtDg)

滑动浏览器到下面找到 Sign in with Apple 并勾选

![](https://res.wx.qq.com/op_res/ReLDBB615JweK2uM2d6UD2TK2hjQc32QZCY4iZN1EM7id9StT5cadAOVL6Z3uxxzIZvEJBG79yl0nQRKH_5WPw)

最后点击 Continue 按钮创建应用

### [#](#_1-3-获取-Key-ID-和-Private-Key) 1.3 获取 Key ID 和 Private Key

前往[苹果开发者页面](https://idmsa.apple.com/IDMSWebAuth/signin?appIdKey=891bd3417a7776362562d2197f89480a8547b108fd934911bcbea0110d07f757&path=%2Faccount%2F&rv=1)，在「Certificates, IDs & Profiles > Keys Tab」页面，点击图标

![](https://res.wx.qq.com/op_res/ReLDBB615JweK2uM2d6UD_Tqgqwc3zothyAZv-ybwScVSS-5VV4lEP_MileYCltzQuFv9WdXlrKIg6zcfOfyEQ)

输入名称并勾选上 Sign in with Apple，点击 Configure，确保选中的 Primary App ID 是你刚刚创建的那一个

![](https://res.wx.qq.com/op_res/ReLDBB615JweK2uM2d6UD1TIbVgoabuHczoihRKo8mxd74-pqm1V32qHhlUHiR98WGgUcjGRNmCbqge1shZV9Q)

点击 Save，Continue，最后点击 Register

![](https://res.wx.qq.com/op_res/ReLDBB615JweK2uM2d6UDwJTGt8jqjOWfUEOfcBbhxt6CSdMHMDbXfkqREfv4CEN6JLdzCUwYI08RyUya5H_2A)

创建之后，获得 Key ID，然后点击 Download 下载该密钥

![](https://res.wx.qq.com/op_res/ReLDBB615JweK2uM2d6UD2DRnUr1aix_i-OGjX0pi-5eCYvHg0IkaQll25aFV3L1xlc3obVuzltTBvFbaRq3Gg)

打开下载的密钥，并记录其中的内容，格式为

```
-----BEGIN PRIVATE KEY-----
xxxxxxxxxxx
xxxxxxxxxxx
xxxxxxxxxxx
xxxxxxxxxxx
-----END PRIVATE KEY-----
```

### [#](#_1-4-配置身份管理控制台信息) 1.4 配置身份管理控制台信息

打开开发平台控制台，选择「多端身份管理 -> 指定应用 -> Apple 登录」。将在「前期准备」中记录的 Bundle ID、Team ID、Key ID 和 Private Key 填入并保存。

![](https://res.wx.qq.com/op_res/y7APHxNwLLTKYnax4NQlTsgxBR_TeNQU87kRQ-CItEYyT405fhyOJxiiwYVvCIdRM2LhPsN_zeq2q2FtWgXeHA)

## [#](#二、开发者工具) 二、开发者工具

完成以上控制台配置以后，需在开发者工具的 `project.miniapp.json` 中勾选使用 `IdaasSDK`。

![](https://res.wx.qq.com/op_res/cQsSj--IJG9pjMcNbjsSKTa9Pznw42VArxmb7dMqntSfYAmELBCIxhPrSCZGmo2T-hu6yZTb5HoXcLIDy6qonA)
