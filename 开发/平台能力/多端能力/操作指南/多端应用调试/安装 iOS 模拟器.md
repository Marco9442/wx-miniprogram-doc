# [#](#安装-iOS-模拟器) 安装 iOS 模拟器

## [#](#一、Windows-系统) 一、Windows 系统

- Windows 系统不支持安装 iOS 模拟器

## [#](#二、Mac-系统) 二、Mac 系统

### [#](#_1、安装-Xcode) 1、安装 Xcode

- 通过 App Store 或前往 [Apple 开发者官网](https://developer.apple.com/xcode/)下载
- 安装 Xcode 后打开并安装 Apple SDK（完成后这一步骤会同时安装 Xcode IDE、Xcode 的命令行工具和 iOS 模拟器）

![](https://testchu-7gy8occc8dcc14c3-1304825656.tcloudbaseapp.com/img%2Fmelody%2F202306122340422.png)

### [#](#_2、查看已安装的模拟器) 2、查看已安装的模拟器

- 执行命令 `xcrun xctrace list devices` 可以查看所有已经安装的模拟器
