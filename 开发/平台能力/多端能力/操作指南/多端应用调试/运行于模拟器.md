# [#](#运行于模拟器) 运行于模拟器

为方便调试多端应用，开发者可选择使用 Android 模拟器和 iOS 模拟器进行调试。

- 前往工具栏，在「运行」下拉选择「Android 模拟器」或「iOS 模拟器」，点击「运行」，稍等片刻，等待资源包编译完成

![](https://testchu-7gy8occc8dcc14c3-1304825656.tcloudbaseapp.com/img%2Fmelody%2F202306120124416.png)

连接 Android 模拟器和 iOS 模拟器，需先进行安装，详情可查看下方对应的安装指南

- [安装 Android 模拟器](android-simulator)
- [安装 iOS 模拟器](ios-simulator)
- [安装 HarmonyOS 模拟器](harmony-simulator)

**注意**

- 暂不支持 HarmonyOS 模拟器 cpu 类型为 x86\_64, 目前只能 arm 模拟器或真机测试
- 如出现以下报错，请检查模拟器的 cpu 类型，如果是 x86\_64 ，则会报错
