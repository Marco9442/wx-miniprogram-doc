# [#](#预览开发版) 预览开发版

为方便 Android 应用开发者调试 Android 应用，可选择基于[移动应用助手](../assistant/quickstart)进行调试，具体操作步骤如下:

1、前往工具栏，在「设备选择框」下拉选择「Android 移动应用助手」，点击「运行」，稍等片刻，等待开发版编译完成。

- 补充说明：如选择的版本为「正式版」时，不支持选择「移动应用助手」

![](https://res.wx.qq.com/op_res/uDKuTPyS1b8yy_qWqbn2gLhNapCr1JZHt9DDKUwRoocG2sB9k1Im537dE0RfVs3LalmI7BnwTpbjsKpNZrEfjg) ![](https://res.wx.qq.com/op_res/uDKuTPyS1b8yy_qWqbn2gOgWc22_y7fhzzFH32ZJRWUkkWcYxoBBV6A7Y1Bv-VOEWMsjx87ZnUU90dV-ZUT6_w)

2、如已安装「移动应用助手」，开发者可使用「移动应用助手」进行扫码体验；如尚未安装「移动应用助手」，开发者可先使用微信进行扫码并下载安装「移动应用助手」。

- 也可前往[移动应用助手更新日志](../../changelog/assistant/changelog)下载安装「移动应用助手」
