# [#](#多端应用-We-分析) 多端应用 We 分析

为了方便多端应用的开发者对 App 的性能数据、错误日志等信息进行查看与分析，当前多端应用已支持与 We 分析平台对接。当前已上线支持的数据模块如下：

- JS 分析与实时日志已支持
- 体验分析也已支持
- 及其他性能数据分析仍在开发中，如下图

![](https://testchu-7gy8occc8dcc14c3-1304825656.tcloudbaseapp.com/img%2Fmelody%2F202502241410294.png)

- 如有更多数据分析需求，可联系[小助手](https://developers.weixin.qq.com/community/personal/oCJUswzW6Jdy9Iyn4fJHItBzvLXg)进行反馈&评估排期支持

## [#](#一、使用介绍) 一、使用介绍

多端应用使用 We 分析服务的步骤如下：

1、前往多端应用控制台 - We 分析，同意服务协议&开通 We 分析服务（注意，需已上架的多端应用方可开通 We 分析服务）

2、打开「JS 分析」或者「实时日志」日志上报开关（补充，如果使用体验分析，无需在多端应用控制台上打开开关，而是在 We 分析平台中打开开关）

3、多端 App 中需将 SDK 更新至最新版本，然后重新构建安装包并进行访问

4、前往 [We 分析](https://wedata.weixin.qq.com/mp2/login)平台，使用微信扫码，选择「多端应用」账号进行登录；登录成功后即可进入多端应用的 We 分析平台查看相关数据

## [#](#二、操作详情) 二、操作详情

### [#](#_2-1-开通-We-分析服务) 2.1 开通 We 分析服务

- 前往多端应用控制台，点击进入「We 分析」模块，同意服务协议&开通 We 分析服务（说明，必须要在多端应用控制台开通 We 分析服务，才可以登录 We 分析控制台）

![](https://testchu-7gy8occc8dcc14c3-1304825656.tcloudbaseapp.com/img%2Fmelody%2F202412092024260.png)

- 如多端应用尚未上架，则出现下方弹窗提示

![](https://testchu-7gy8occc8dcc14c3-1304825656.tcloudbaseapp.com/img%2Fmelody%2F202412092025051.png)

#### [#](#补充：配置多端应用上架状态的方法) 补充：配置多端应用上架状态的方法

1、前往「应用概览 - 移动应用信息」检查是否已经绑定移动应用账号，如果还没绑定，就添加绑定，详情可查看[移动应用绑定指南](bind-openapp)

2、如果已绑定移动应用账号，则前往「微信开放平台 - 移动应用 - 详情 - 基础配置 - 上架信息」查看应用的上架状态，如果是未上架，则点击「编辑」，修改上架状态，然后重新提交审核，审核通过后，即可在多端应用控制台看到状态变更为已上架

![](https://testchu-7gy8occc8dcc14c3-1304825656.tcloudbaseapp.com/img%2Fmelody%2F202409191722171.png)

### [#](#_2-2-开启「JS-分析」上报) 2.2 开启「JS 分析」上报

- Android SDK >= 1.4.5
- iOS SDK >= 1.4.9

![](https://testchu-7gy8occc8dcc14c3-1304825656.tcloudbaseapp.com/img%2Fmelody%2F202412092028184.png)

### [#](#_2-3-开启「实时日志」上报) 2.3 开启「实时日志」上报

- Android SDK >= 1.4.17
- iOS SDK >= 1.5.1
- 注意：需是「正式版」的 APK 或者 IPA 实时日志上报才会生效

![](https://testchu-7gy8occc8dcc14c3-1304825656.tcloudbaseapp.com/img%2Fmelody%2F202412092026548.png)

### [#](#_2-4-扫码选择多端应用账号登录-We-分析) 2.4 扫码选择多端应用账号登录 We 分析

- 前往 [We 分析](https://wedata.weixin.qq.com/mp2/login)平台，使用微信扫码
- 选择「多端应用」账号进行登录；登录成功后即可进入多端应用的 We 分析平台查看相关数据
- 出现可选择多端应用账号的条件为：当前微信用户是某小程序的管理员或者开发者，并且该小程序已经绑定某多端应用账号，且该多端应用账号已开通 We 分析服务

![](https://testchu-7gy8occc8dcc14c3-1304825656.tcloudbaseapp.com/img%2Fmelody%2F202409191726454.png)

#### [#](#补充：多端应用-We-分析权限说明) 补充：多端应用 We 分析权限说明

- 首次使用多端应用 We 分析服务，成员管理是从该多端应用所绑定的小程序的「成员」中具有数据分析权限的用户同步过来
- 而后续新增的用户权限，均需管理员在 We 分析平台添加用户权限（即，再在小程序平台添加权限是不生效的）
