# [#](#需适配的组件汇总) 需适配的组件汇总

- 多端框架是基于与小程序同源的技术实现，大部分的小程序组件在多端应用中均可使用，但的确有部分的组件因为产品载体已经变成为 App，无法再支持的，开发者需对这部分的组件进行兼容性处理

## [#](#一、需开发者进行适配兼容的组件) 一、需开发者进行适配兼容的组件

- 下方功能需使用新的接口或者组件进行实现

| 名称 | 功能说明 | 备注 |
| --- | --- | --- |
| [button](https://developers.weixin.qq.com/miniprogram/dev/component/button.html) | 按钮 | 支持，但 open-type 涉及的微信开放能力均不支持 |
| [image](https://developers.weixin.qq.com/miniprogram/dev/component/image.html) | 图片 | 支持，但是长按识别的功能尚不支持 |

### [#](#_2、image) 2、image

- [image](https://developers.weixin.qq.com/miniprogram/dev/component/image.html) 组件中 show-menu-by-longpress 的功能（长按图片显示发送给朋友、收藏、保存图片、搜一搜、打开名片/前往群聊/打开小程序）暂不支持

### [#](#_3、web-view) 3、web-view

- 从 iOS >= 1.0.17，Android >= 1.0.8 开始，web-view 打开 h5 获取到的 UA 将不再带有`微信`相关的标识，同时新增了 `SAAASDK` 用于表示多端的运行环境。
- 如开发者在多端应用中的 h5 中使用到了 jssdk 用于与小程序交互，需将 jssdk 升级至 [1.6.2](https://res.wx.qq.com/open/js/jweixin-1.6.2.js)
- 补充说明 1：在多端应用中通过 web-view 打开 H5，无需在平台中配置业务域名，直接可打开
- 补充说明 2：Skyline 暂不支持 web-view 组件，建议承载 web-view 的页面单独配置 `"renderer": "webview"`，详情可查看[文档](https://developers.weixin.qq.com/miniprogram/dev/framework/runtime/skyline/component)
- jssdk 支持的接口情况可查看

### [#](#_4、video) 4、video

在 App 中使用 video 组件实现投屏的功能时，需要申请组播权限，相关的操作如下：

- 使用苹果开发者主账号访问 <https://developer.apple.com/contact/request/networking-multicast> 申请组播权限
- 大概 3 天左右查看开发者账号，会多一个 Additional Capabilities，然后勾选 Multicast Networking 权限
- 重新生成描述文件，下载新的描述文件；并且使用新的描述文件重新打包 IPA 即可

#### [#](#注意) 注意

- Android 端使用该组件，依赖 Media SDK,需前往 project.miniapp.json 中勾选扩展 Media SDK
- iOS 端使用该组件，依赖 video 和 audio 这两个扩展 SDK，都需要勾上
