# [#](#升级-SDK-版本) 升级 SDK 版本

开发者可通过此功能检测 SDK 是否有新的版本，若有新版本开发者即可一键升级。

点击「工具 - SDK 版本检测」。

![](https://res.wx.qq.com/op_res/3oKwlcOk3XBulkMNyj2DpzRlnmoWrULG5BFyk7I5bjavMRyX3IXPZC-3u24sbTH1AlkxbWxzwGfIPTTAgb_O7w)

如有新版本，工具右侧会弹出新版本提示框，开发者可点击「立即更新」。
