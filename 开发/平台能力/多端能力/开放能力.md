# [#](#OpenSdk-能力初始化) OpenSdk 能力初始化

在多端应用中使用微信开放平台移动应用能力，例如微信登录、微信分享、App 拉起小程序等能力，开发者需先完成移动应用账号创建，并且将移动应用绑定于多端应用中，相关的初始化操作步骤如下：

## [#](#一、创建移动应用) 一、创建移动应用

- 详情可查看[创建移动应用操作指引](../handbook/web/open_application_create)

## [#](#二、绑定移动应用) 二、绑定移动应用

- 移动应用创建后，需前往多端应用控制台-详情中，将移动应用账号绑定于多端应用中，详情可查看[多端应用管理操作指引](../handbook/web/application_create#_3%E3%80%81%E7%BB%91%E5%AE%9A%E7%A7%BB%E5%8A%A8%E5%BA%94%E7%94%A8%E5%B8%90%E5%8F%B7)

## [#](#三、相关-API) 三、相关 API

开放能力基于微信 Open SDK，关联的是微信开放平台的应用 ID。开发者调用相关接口获取的用户身份数据。如果需要关联小程序的数据，需要获取 UnionID，将移动应用和小程序应用关联起来。

| 名称 | 功能说明 |
| --- | --- |
| 微信登录 | 官方提供 [wx.login](../api/diffapi/wx.login) 和 [wx.miniapp.login](../api/miniapp/login) 以及 [wx.getMiniProgramCode](../api/auth/wx.getMiniProgramCode) 和 [wx.weixinMiniProgramLogin](../api/auth/wx.weixinMiniProgramLogin) 这 4 个 API，详情可查看[微信登录](../api/diffapi/WeChatLogin) |
| [wx.miniapp.login](../api/miniapp/login) | 微信登录 |
| [wx.miniapp.requestPayment](../api/miniapp/requestPayment) | 微信支付 |
| [wx.miniapp.hasWechatInstall](../api/miniapp/hasWechatInstall) | 判断是否安装微信 |
| [wx.miniapp.launchMiniProgram](../api/miniapp/launchMiniProgram) | 跳转微信小程序 |
| [wx.miniapp.shareTextMessage](../api/miniapp/shareTextMessage) | 分享文本到微信 |
| [wx.miniapp.shareImageMessage](../api/miniapp/shareImageMessage) | 分享图片到微信 |
| [wx.miniapp.shareVideoMessage](../api/miniapp/shareVideoMessage) | 分享视频到微信 |
| [wx.miniapp.shareMiniProgramMessage](../api/miniapp/shareMiniProgramMessage) | 分享小程序到微信 |
| [wx.miniapp.shareWebPageMessage](../api/miniapp/shareWebPageMessage) | 分享网页到微信 |
| [wx.miniapp.requestSubscribeMessage](../api/miniapp/requestSubscribeMessage) | 请求微信一次性订阅消息 |
| [wx.miniapp.openCustomerServiceChat](../api/miniapp/openCustomerServiceChat) | 微信客服 |
| [wx.miniapp.onOpensdkLog](../api/miniapp/onOpensdkLog) | 监听日志 |
