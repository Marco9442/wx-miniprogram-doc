## [#](#五、媒体组件) 五、媒体组件

- 在 Android 端使用 camera 组件，需勾选「XWeb Embed SDK」或者「XWeb SDK」
- 在 Android 端使用 camera 组件的 scancode 模式，还需勾选 「Scanner SDK」
- 使用 live-player 和 live-pusher 组件需要勾选 「Live SDK」（如果开发者工具上没看到该扩展 SDK ，请将开发者工具升级到最新）
- 使用「Live SDK」时，还需配置 LiveLicenseUrl 和 LiveLicenseKey,详细操作可查看[live-player 与 live-pusher 使用说明](LiveSDK)
- 使用下方组件能力需勾选 Media SDK

| 名称 | 功能说明 | 备注 |
| --- | --- | --- |
| [audio](https://developers.weixin.qq.com/miniprogram/dev/component/audio.html) | 音频 | 已废弃 |
| [camera](https://developers.weixin.qq.com/miniprogram/dev/component/camera.html) | 系统相机 | 支持 |
| [image](https://developers.weixin.qq.com/miniprogram/dev/component/image.html) | 图片 | 支持，但是长按识别的功能尚不支持 |
| [live-player](https://developers.weixin.qq.com/miniprogram/dev/component/live-player.html) | 实时音视频播放（v2.9.1 起支持[同层渲染](https://developers.weixin.qq.com/miniprogram/dev/component/native-component.html#原生组件同层渲染.html）) ） | Android SDK 需 ≥ 1.2.9 ； iOS SDK 需 >= 1.6.3 |
| [live-pusher](https://developers.weixin.qq.com/miniprogram/dev/component/live-pusher.html) | 实时音视频录制（v2.9.1 起支持[同层渲染](https://developers.weixin.qq.com/miniprogram/dev/component/native-component.html#原生组件同层渲染.html）)） | Android SDK 需 ≥ 1.2.10 ； iOS SDK 需 >= 1.6.3 |
| [video](https://developers.weixin.qq.com/miniprogram/dev/component/video.html) | 视频（v2.4.0 起支持[同层渲染](https://developers.weixin.qq.com/miniprogram/dev/component/native-component.html#原生组件同层渲染.html） )） | 支持，需要勾选 Media SDK 详情可查看[video 适配说明](adapt_component#_4%E3%80%81video) |
| [voip-room](https://developers.weixin.qq.com/miniprogram/dev/component/voip-room.html) | 多人音视频对话 | 暂不支持 |
