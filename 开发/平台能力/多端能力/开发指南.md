# [#](#开发指引) 开发指引

本文档整理了在多端应用开发时，一些必要的基础知识和注意事项。

前往以下文档，了解详细使用：

- [配置文件](config)：project.miniapp.json 是多端项目的专用配置文件，用于多端 App 应用配置。
- [SDK](sdk/)：SDK 集成丰富的 API 和组件，保障多端项目正常运行，分 Android 和 iOS 两种。
- [条件编译](condition-compile)：条件编译语法支持在不同平台有不同的呈现/逻辑的需求。
- [vConsole](vconsole)：轻量、可拓展、针对移动端的开发者调试面板，由多端框架直接集成。
