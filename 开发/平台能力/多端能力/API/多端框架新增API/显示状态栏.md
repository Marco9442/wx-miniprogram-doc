# [#](#wx-miniapp-showStatusBar) wx.miniapp.showStatusBar

> iOS >= 1.5.8

该接口用于显示状态栏(即，顶部展示电量、时间的地方)，如果需要隐藏状态栏则可以使用 `wx.miniapp.hideStatusBar`

#### [#](#JSAPI-代码例子) JSAPI 代码例子

```
wx.miniapp.showStatusBar({
  success (res) {
    console.log('showStatusBar success', res)
  }
})
```
