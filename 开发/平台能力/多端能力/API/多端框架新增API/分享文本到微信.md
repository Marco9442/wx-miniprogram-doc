# [#](#wx-miniapp-shareTextMessage) wx.miniapp.shareTextMessage

分享文本到微信

注：

1、该接口仅适用于多端应用，不支持在小程序内使用

2、该接口不支持在「移动应用助手」中调试，开发者需构建 APK 或者 IPA 安装到手机后才能调试

3、该接口已支持在鸿蒙端使用

## [#](#接入前注意事项) 接入前注意事项

- 该能力依赖[微信 Open SDK](https://developers.weixin.qq.com/doc/oplatform/Mobile_App/WeChat_Pay/Vendor_Service_Center)，需按照指引在[微信开放平台](https://open.weixin.qq.com/)创建移动应用账号，以完成相关初始化配置，详情可查看[微信移动应用能力初始化指引](../../new-capability/opensdk)

### [#](#参数) 参数

方便开发者理解，wx.miniapp.shareImageMessage 参数与[微信开放平台 Open SDK 分享接口](https://developers.weixin.qq.com/doc/oplatform/Mobile_App/Share_and_Favorites/Share_and_Favorites)参数一致

| 属性 | 类型 | 默认值 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| text | string | - | 是 | 分享的文本 |
| scene | number | - | 是 | 发送的目标场景,0=分享到会话,1=分享到朋友圈，2=分享到收藏 |

## [#](#JSAPI-代码例子) JSAPI 代码例子

```
wx.miniapp.shareTextMessage({
    text: '分享稳步',
    scene: 0, // 分享到会话
    success(res) {
        wx.showToast({
            title: '成功：分享文字',
        })
    },
    fail() {
        wx.showToast({
            title: '失败：分享文字',
        })
    }
})
```
