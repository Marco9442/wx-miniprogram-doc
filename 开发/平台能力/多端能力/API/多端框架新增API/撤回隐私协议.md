# [#](#wx-miniapp-revokePrivacySetting) wx.miniapp.revokePrivacySetting

> Android >= 1.4.2；iOS >= 1.4.10

该接口用于撤销用户同意隐私协议的设置，恢复成需要同意隐私协议弹窗前的状态

补充：通常需要与[`wx.miniapp.closeAppModule`](closeAppModule) 搭配使用，即当用户撤回同意隐私协议了，即用户没有同意隐私协议了，那么就无法使用 App 了，需通过[`wx.miniapp.closeAppModule`](closeAppModule) 接口关闭 App，然后用户重新打开 App 后会重新再出现隐私弹窗。

#### [#](#JSAPI-代码例子) JSAPI 代码例子

```
wx.miniapp.revokePrivacySetting({
  success (res) {
    console.log('revokePrivacySetting success', res)
  }
})
```
