# [#](#wx-miniapp-hideStatusBar) wx.miniapp.hideStatusBar

> iOS >= 1.5.8

该接口用于隐藏状态栏(即，顶部展示电量、时间的地方)，如果需要显示状态栏则可以使用 `wx.miniapp.showStatusBar`

#### [#](#JSAPI-代码例子) JSAPI 代码例子

```
wx.miniapp.hideStatusBar({
  success (res) {
    console.log('hideStatusBar success', res)
  }
})
```
