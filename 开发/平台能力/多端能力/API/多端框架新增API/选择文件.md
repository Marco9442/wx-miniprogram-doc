# [#](#wx-miniapp-chooseFile) wx.miniapp.chooseFile

> iOS >= 1.2.8；Android >= 1.1.10

拉取系统文件选择框去选择文件

注意：此接口不支持在微信开发者工具调试、不支持在移动应用助手调试，需构建安装包安装到手机进行测试

#### [#](#参数) 参数

| 属性 | 类型 | 默认值 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| allowsMultipleSelection | boolean | false | 否 | 是否允许选择多个文件 |

### [#](#返回参数) 返回参数

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| tempFiles | Array | 选择的文件列表 |
| tempFiles[].path | string | 本地文件临时路径，形如 wxfile://tmp\_xxxxx.jpg |
| tempFiles[].name | string | 本地文件名称 |
| tempFiles[].size | number | 本地临时文件大小，单位 B |

#### [#](#JSAPI-代码例子) JSAPI 代码例子

```
wx.miniapp.chooseFile({
    success(res) {
        const tempFiles = res.tempFiles
        console.log('wx.miniapp.chooseFile success', tempFiles)
    },
    fail(err) {
        console.log('wx.miniapp.chooseFile fail', err)
    }
})
```
