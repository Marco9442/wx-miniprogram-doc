# [#](#wx-miniapp-getPrivacySetting) wx.miniapp.getPrivacySetting

> Android >= 1.1.10；iOS >= 1.6.2

该接口用于查询「用户是否已经同意隐私协议」

- 注意：在用户未同意隐私服务协议情况下，开发者不可调用任何与个人信息相关的接口能力

#### [#](#JSAPI-代码例子) JSAPI 代码例子

```
wx.miniapp.getPrivacySetting({
  success (res) {
    console.log('getPrivacySetting success', res)
    if (res.needAuthorization) {
      console.log('需要用户先同意隐私协议，即用户还没同意协议')
    } else {
      console.log('用户已经同意隐私协议了')
    }
  }
})
```
