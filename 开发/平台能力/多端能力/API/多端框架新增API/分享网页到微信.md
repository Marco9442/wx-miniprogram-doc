# [#](#wx-miniapp-shareWebPageMessage) wx.miniapp.shareWebPageMessage

分享网页到微信

注：

1、该接口仅适用于多端应用，不支持在小程序内使用

2、该接口不支持在「移动应用助手」中调试，开发者需构建 apk 或者 ipa 安装到手机后才能调试

3、该接口已支持在鸿蒙端使用

## [#](#接入前注意事项) 接入前注意事项

- 该能力依赖[微信 Open SDK](https://developers.weixin.qq.com/doc/oplatform/Mobile_App/WeChat_Pay/Vendor_Service_Center) ，需按照指引在[微信开放平台](https://open.weixin.qq.com/)创建移动应用账号，以完成相关初始化配置，详情可查看[微信移动应用能力初始化指引](../../new-capability/opensdk)

### [#](#参数) 参数

方便开发者理解，wx.miniapp.shareWebPageMessage 参数与[微信开放平台 opensdk 分享接口](https://developers.weixin.qq.com/doc/oplatform/Mobile_App/Share_and_Favorites/Share_and_Favorites)参数一致

| 属性 | 类型 | 默认值 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| title | string | - | 是 | 网页标题 |
| description | string | - | 是 | 网页描述 |
| thumbPath | string | - | 是 | 分享缩略图，支持代码包图片资源路径或者本地临时、缓存、用户文件；不支持网络图片路径 |
| webpageUrl | string | - | 是 | 分享 webpage url |
| scene | number | - | 是 | 发送的目标场景,0=分享到会话,1=分享到朋友圈，2=分享到收藏 |

## [#](#JSAPI-代码例子) JSAPI 代码例子

```
wx.miniapp.shareWebPageMessage({
    title: '网页标题',
    description: '网页描述',
    thumbPath: '/pages/thumb.png',
    webpageUrl: 'www.qq.com',
    scene: 0, 
    success(res) {
        wx.showToast({
            title: '成功：分享网页',
        })
    },
    fail() {
        wx.showToast({
            title: '失败：分享网页',
        })
    }
})
```
