# [#](#wx-miniapp-openCustomerServiceChat) wx.miniapp.openCustomerServiceChat

支持调用该接口拉起微信客服功能。移动应用（APP）接入此功能后，用户可以从 APP 拉起指定的微信客服会话。该功能已向全体开发者开放，开发者在已认证的微信开放平台账号下.申请移动应用审核通过后并上架，即可获得移动应用拉起微信客服的功能权限。

说明：该接口已支持在鸿蒙端使用（需使用最新版 SDK）

## [#](#使用说明) 使用说明

### [#](#账号要求) 账号要求

移动应用开发者使用该功能，需同时满足以下条件：

1. 微信开放平台账号已认证
2. 移动应用审核通过并上架

> 注意：若移动应用未上架，则最多只能拉起微信客服100次/天，用于满足调试需求。

### [#](#关联说明) 关联说明

移动应用仅可拉起具有绑定关系的微信客服，开发者需前往微信客服官网完成移动应用(appid)和企业 id 的绑定。

> 注意：一个移动应用（appid）最多绑定15个企业 id

## [#](#接入前注意事项) 接入前注意事项

- 该能力依赖[微信 Open SDK](https://developers.weixin.qq.com/doc/oplatform/Mobile_App/WeChat_Pay/Vendor_Service_Center) ，需按照指引在[微信开放平台](https://open.weixin.qq.com/)创建移动应用账号，以完成相关初始化配置，详情可查看[微信移动应用能力初始化指引](../../new-capability/opensdk)

### [#](#参数) 参数

方便开发者理解，wx.miniapp.openCustomerServiceChat 参数与[微信开放平台 opensdk APP 拉起微信客服功能](https://developers.weixin.qq.com/doc/oplatform/Mobile_App/APP_launch_wechat_customer_service)参数一致

| 属性 | 类型 | 默认值 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| corpId | string | - | 是 | 企业 id 开发者需前往微信客服官网完成移动应用(appid)和企业 id 的绑定。 |
| url | string | - | 是 | 客服 URL |

## [#](#调用示例) 调用示例

```
wx.miniapp.openCustomerServiceChat({
  corpId: 'xxxx', // 企业id
  url: 'https://work.weixin.qq.com/kfid/kfcxxxxx',  
  complete(res) {
    console.error('miniapp.openCustomerServiceChat', res)
  },
  success(res) {
    wx.showToast({
      title: '成功：分享图片',
    })
  },
  fail() {
    wx.showToast({
      title: '失败：分享图片',
    })
  }
})
```
