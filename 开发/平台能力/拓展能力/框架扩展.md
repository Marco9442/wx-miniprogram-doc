# [#](#框架扩展) 框架扩展

## [#](#计算属性-computed) 计算属性 computed

小程序自定义组件扩展 behavior，计算属性 `computed` 和监听器 `watch` 的实现。

在 data 或者 properties 改变时，会重新计算 `computed` 字段并触发 `watch` 监听器。

> 此 behavior 依赖开发者工具的 npm 构建。具体详情可查阅[官方 npm 文档](https://developers.weixin.qq.com/miniprogram/dev/devtools/npm)。

> 更为详细的说明和指引，可点击[项目地址](https://github.com/wechat-miniprogram/computed)。

## [#](#MobX-绑定辅助库) MobX 绑定辅助库

小程序的 MobX 绑定辅助库。

> 此 behavior 依赖开发者工具的 npm 构建。具体详情可查阅[官方 npm 文档](https://developers.weixin.qq.com/miniprogram/dev/devtools/npm)。

> 可配合 MobX 的小程序构建版 npm 模块 [`mobx-miniprogram`](https://github.com/wechat-miniprogram/mobx) 使用。
