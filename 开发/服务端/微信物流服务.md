## [#](#同城配送) 同城配送

| 接口名称 | 请求路径 | 描述 |
| --- | --- | --- |
| [开通门店权限](./same_city_distribution/api_intracity_apply) | /cgi-bin/express/intracity/apply | 在使用门店相关接口前需要先开通门店权限，开通门店权限前可以使用页面或者使用此API开通门店（无加密，可直接调用） |
| [创建门店](./same_city_distribution/api_intracity_createstore) | /cgi-bin/express/intracity/createstore | 创建门店时需要传入自定义的门店编号，自定义的门店编号需要唯一，确保不重复创建 门店创建后系统生成全局唯一门店编号wxstoreid，后续创建运力订单时需要该门店 |
| [查询门店](./same_city_distribution/api_intracity_querystore) | /cgi-bin/express/intracity/querystore | 获取本小程序所创建的门店，不传wxstoreid和outstoreid则返回本小程序所有门店信息 |
| [更新门店](./same_city_distribution/api_intracity_updatestore) | /cgi-bin/express/intracity/updatestore | 更新门店信息 |
| [门店运费充值](./same_city_distribution/api_intracity_storecharge) | /cgi-bin/express/intracity/storecharge | 返回微信服务市场的充值页面地址，通过该页面可以为门店充值指定运力的运费，充值后运费有使用有效期，默认有效期为1个月，超期未使用的运费降原路退回 |
| [门店运费退款](./same_city_distribution/api_intracity_store_refund) | /cgi-bin/express/intracity/storerefund | 该接口可以将门店指定运力的运费余额退还，如果门店有在途的配送订单，需要等配送完成或者取消配送订单之后才可以操作退款；操作退款后，退款金额五分钟内到账 |
| [门店运费流水查询](./same_city_distribution/api_intracity_queryflow) | /cgi-bin/express/intracity/queryflow | 查询门店运力资金流水 |
| [门店余额查询](./same_city_distribution/api_intracity_balancequery) | /cgi-bin/express/intracity/balancequery | 查询门店运力余额 |
| [查询运费](./same_city_distribution/api_intracity_preaddorder) | /cgi-bin/express/intracity/preaddorder | 商家通过该接口传入配送单的相关信息，同城配送后台将根据配送信息向运力查询并返回实时的运费和配送距离 |
| [创建配送单](./same_city_distribution/api_intracity_addorder) | /cgi-bin/express/intracity/addorder | 创建同城配送单，会根据门店设置的运力偏好来选择运力公司下单 |
| [查询配送单](./same_city_distribution/api_intracity_queryorder) | /cgi-bin/express/intracity/queryorder | 通过该接口查询订单是否创建成功，以及订单创建后的状态更新 |
| [取消配送单](./same_city_distribution/api_intracity_cancelorder) | /cgi-bin/express/intracity/cancelorder | 通过该接口可以取消已创建的订单，取消配送中的订单需要扣减违约金 |
| [设置扣费主体](./same_city_distribution/api_intracity_setpaymode) | /cgi-bin/express/intracity/setpaymode | 默认扣费主体和充值主体都是门店，该接口可以让开发者设置门店的扣费主体，接口调用成功后，小程序的管理员会收到模板消息，点击模板消息确认更改门店扣费主体后，修改生效 |
| [查询扣费主体](./same_city_distribution/api_intracity_getpaymode) | /cgi-bin/express/intracity/getpaymode | 查询小程序的扣费主体 |
| [查询支持同城配送的城市](./same_city_distribution/api_intracity_getcity) | /cgi-bin/express/intracity/getcity | 用于查询全国可以使用微信同城配送的城市 |
| [模拟回调接口](./same_city_distribution/api_intracity_mocknotify) | /cgi-bin/express/intracity/mocknotify | 由于测试订单没有快递员接单，不会自动推送订单状态变化回调，为了方便开发者在沙箱环境联调，我们提供了模拟回调接口，针对测试订单开发者可以通过该接口触发其他说明中订 |
