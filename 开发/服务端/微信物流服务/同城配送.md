| [更新门店](https://developers.weixin.qq.com/miniprogram/dev/server/API/weixin-express/same\_city\_distribution/api\_intracity\_updatestore) | /cgi-bin/express/intracity/updatestore | 更新门店信息 |

| [门店运费流水查询](https://developers.weixin.qq.com/miniprogram/dev/server/API/weixin-express/same\_city\_distribution/api\_intracity\_queryflow) | /cgi-bin/express/intracity/queryflow | 查询门店运力资金流水 |

| [创建配送单](https://developers.weixin.qq.com/miniprogram/dev/server/API/weixin-express/same\_city\_distribution/api\_intracity\_addorder) | /cgi-bin/express/intracity/addorder | 创建同城配送单，会根据门店设置的运力偏好来选择运力公司下单 |

| [取消配送单](https://developers.weixin.qq.com/miniprogram/dev/server/API/weixin-express/same\_city\_distribution/api\_intracity\_cancelorder) | /cgi-bin/express/intracity/cancelorder | 通过该接口可以取消已创建的订单，取消配送中的订单需要扣减违约金 |
| [设置扣费主体](https://developers.weixin.qq.com/miniprogram/dev/server/API/weixin-express/same\_city\_distribution/api\_intracity\_setpaymode) | /cgi-bin/express/intracity/setpaymode | 默认扣费主体和充值主体都是门店，该接口可以让开发者设置门店的扣费主体，接口调用成功后，小程序的管理员会收到模板消息，点击模板消息确认更改门店扣费主体后，修改生效 |
| [查询扣费主体](https://developers.weixin.qq.com/miniprogram/dev/server/API/weixin-express/same\_city\_distribution/api\_intracity\_getpaymode) | /cgi-bin/express/intracity/getpaymode | 查询小程序的扣费主体 |
