# [#](#付费管理订单有效期告警事件) 付费管理订单有效期告警事件

> 本文档描述服务器端接收的消息或事件，详细说明参见[消息推送](https://developers.weixin.qq.com/miniprogram/dev/framework/server-ability/message-push)。

事件英文名：charge\_mp\_service\_validity\_notify

小程序开发者在付费管理所购买的订单，在配置消息推送地址后，可以接收到所购买的订单的有效期告警事件。

消息推送时机：所购SPU有效期到期 前 `15天`、`7天`、`3天`、`1天` 到期时间

## [#](#_1-消息参数) 1. 消息参数

### [#](#请求体-Request-Payload) 请求体 `Request Payload`

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| event\_type | number | 事件类型，固定值 4 |
| appid | string | 小程序AppID |
| spu\_id | number | 购买的商品的SPU\_ID |
| spu\_name | string | 购买的商品的SPU\_NAME |
| validity\_end\_time | string | 购买的SPU的有效期到期时间 |

## [#](#_2-消息返回) 2. 消息返回

### [#](#返回体-Response-Payload) 返回体 `Response Payload`

回复 `success` 或空字符串（无需加密）
