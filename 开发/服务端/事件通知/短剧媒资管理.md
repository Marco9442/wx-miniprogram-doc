# [#](#短剧媒资管理-媒资上传完成事件) 短剧媒资管理-媒资上传完成事件

如果开发者是小程序商家，请移步：[消息推送](https://developers.weixin.qq.com/miniprogram/dev/framework/server-ability/message-push)

如果开发者是服务商第三方平台，请移步：[消息与事件接收配置](https://developers.weixin.qq.com/doc/oplatform/Third-party_Platforms/2.0/operation/thirdparty/prepare#_6%E3%80%81%E6%B6%88%E6%81%AF%E4%B8%8E%E4%BA%8B%E4%BB%B6%E6%8E%A5%E6%94%B6%E9%85%8D%E7%BD%AE)

### [#](#请求参数) 请求参数

| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| media\_id | number | 是 | 媒资id。 |
| source\_context | string | 否 | 透传上传接口中开发者设置的值。 |
| errcode | number | 是 | 错误码，上传失败时该值非0。 |
| errmsg | string | 否 | 错误提示。 |
