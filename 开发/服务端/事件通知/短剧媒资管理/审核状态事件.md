# [#](#短剧媒资管理-审核状态事件) 短剧媒资管理-审核状态事件

### [#](#请求参数) 请求参数

| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| drama\_id | number | 是 | 剧目id。 |
| audit\_detail | DramaAuditDetail | 是 | 剧目审核结果，单独每一集的审核结果可以根据drama\_id查询剧集详情得到。 |
