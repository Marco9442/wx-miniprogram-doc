# [#](#短剧媒资管理) 短剧媒资管理

小程序需申请【文娱-微短剧】或【文娱-互动微短剧】类目，审核通过后会自动开通以下 API 调用权限。

## [#](#媒资上传) 媒资上传

| 接口名称 | 请求路径 | 描述 |
| --- | --- | --- |
| [单个文件上传](./vod_fileupload/api_singlefileupload) | /wxa/sec/vod/singlefileupload | 该接口用于上传媒体（和封面）文件，上传小文件（小于10MB）时使用 |
| [拉取上传](./vod_fileupload/api_pullupload) | /wxa/sec/vod/pullupload | 该接口用于将一个网络上的视频拉取上传到平台 |
| [查询任务](./vod_fileupload/api_gettask) | /wxa/sec/vod/gettask | 该接口用于查询拉取上传的任务状态 |
| [申请分片上传](./vod_fileupload/api_applyupload) | /wxa/sec/vod/applyupload | 上传大文件时需使用分片上传方式，分为 3 个步骤： |
| [上传分片](./vod_fileupload/api_uploadpart) | /wxa/sec/vod/uploadpart | 将文件的其中一个分片上传到平台，最多支持100个分片，每个分片大小为5MB，最后一个分片可以小于5MB |
| [确认上传](./vod_fileupload/api_commitupload) | /wxa/sec/vod/commitupload | 该接口用于完成整个分片上传流程，合并所有文件分片，确认媒体文件（和封面图片文件）上传到平台的结果，返回文件的 ID |
