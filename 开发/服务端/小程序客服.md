# [#](#小程序客服-接口列表) 小程序客服 接口列表

## [#](#客服消息) 客服消息

| 接口名称 | 请求路径 | 描述 |
| --- | --- | --- |
| [添加客服账号](./kf-message/api_addkfaccount) | /customservice/kfaccount/add | 本接口用于为公众号、小程序添加客服账号，每个账号最多添加100个客服账号 |
| [获取所有客服账号](./kf-message/api_getkflist) | /cgi-bin/customservice/getkflist | 本接口用于获取所有客服账号 |
| [获取在线客服列表](./kf-message/api_getonlinekflist) | /cgi-bin/customservice/getonlinekflist | 本接口用于获取当前在线客服列表 |
| [删除客服账号](./kf-message/api_delkfaccount) | /customservice/kfaccount/del | 本接口用于删除客服账号 |
| [发送客服消息](./kf-message/api_sendcustommessage) | /cgi-bin/message/custom/send | 本接口用于发送多种类型的客服消息，主要应用在有人工消息处理环节的场景 |
| [客服输入状态](./kf-message/api_typing) | /cgi-bin/message/custom/business/typing | 本接口用于设置客服输入状态 |
| [设置客服管理员](./kf-message/api_setkfadmin) | /customservice/kfaccount/setadmin | 该接口将账号客服编号对应客服账号设置为客服管理员 |
| [取消客服管理员](./kf-message/api_cancelkfadmin) | /customservice/kfaccount/canceladmin | 该接口根据账号客服编号，解除对应客服账号客服管理员身份 |
| [新增临时素材](./kf-message/api_uploadtempmedia) | /cgi-bin/media/upload | 本接口用于上传临时多媒体文件 |
| [获取临时素材](./kf-message/api_getmedia) | /cgi-bin/media/get | 本接口用于获取临时素材（即下载临时的多媒体文件） |
