# [#](#内置后处理资源) 内置后处理资源

此处列出了框架内置支持的后处理资源类型、参数和对应效果。

以下标题名即为后处理资源里的`type`属性。

## [#](#blur) blur

高斯模糊，效果好但是在`radius`较大时性能开销较高，快速近似方法见[fastblur](#fastblur)。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| radius | number | 5 | 模糊半径 |

示例，radius=64：

![](https://res.wx.qq.com/wxdoc/dist/assets/img/pp-1.6e2ae0b4.jpg)

## [#](#fastblur) fastblur

也是高斯模糊，但是更快速的近似版本。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| radius | number | 5 | 模糊半径 |

时间稳定性高，但效果没有`blur`好，适用于需要不断变更`radius`的场景。

## [#](#bloom) bloom

泛光，建议开启`is-hdr`使用。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| threshold | number | 0.5 | 阈值 |
| softThreshold | number | 0 | 软阈值 |
| radius | number | 20 | 半径 |
| intensity | number | 2 | 亮度 |

示例，radius=64，intensity=2，其他默认：

![](https://res.wx.qq.com/wxdoc/dist/assets/img/pp-2.0bed8df9.jpg)

## [#](#tone) tone

色调映射，ACES曲线，一般配合`hdr`使用。

示例：

![](https://res.wx.qq.com/wxdoc/dist/assets/img/pp-3.3864790a.jpg)

## [#](#vignette) vignette

渐晕。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| center | number[] | [0.5,0.5] | 半径 |
| color | number[] | [0,0,0,1] | 颜色 |
| intensity | number | 1 | 亮度 |
| smoothness | number | 1 | 边缘柔化 |
| roundness | number | 1 | 圆度 |
| rounded | number | 0/1 | 强制为圆形 |

示例，color=[1,0,0,1]，smoothness=2，其他默认：

![](https://res.wx.qq.com/wxdoc/dist/assets/img/pp-4.63ee478e.jpg)
