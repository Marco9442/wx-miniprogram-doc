# [#](#小程序交易投诉流程指引) 小程序交易投诉流程指引

为保障用户的交易体验，当交易中出现分歧需要协商解决时，可通过小程序平台提供的"交易投诉"功能提交申请。具体操作步骤如下：

### [#](#一、交易投诉申请指引) 一、交易投诉申请指引

**1、正常小程序，您可以通过以下方式提交投诉申请，请选择其中一种进行操作。**

路径一：小程序—页面右上角“…”→ 反馈与投诉→ 交易投诉→ 选择投诉订单→ 填写投诉内容→ 提交

![](https://res.wx.qq.com/wxdoc/dist/assets/img/09311-09.d909db30.png)

![](https://res.wx.qq.com/wxdoc/dist/assets/img/09311-10.b7c43cd0.png)

路径二：微信"服务通知" → 点击订单消息中的"进入小程序查看" → 在订单详情页底部点击"交易投诉"按钮

![](https://res.wx.qq.com/wxdoc/dist/assets/img/09311-02.3c22ccf7.png)

路径三：微信→发现→小程序→右上角头像→我的评价→右上角写评价→选择要评价的订单→选择1-2星差评→向平台投诉

![](https://res.wx.qq.com/wxdoc/dist/assets/img/09311-08.091d86d4.png)

**2、如遇到封停小程序或删除小程序使用记录，您可以通过以下方式提交投诉申请**

路径：微信发现 → 小程序→ 任意选择一个小程序 → 页面右上角“…” → 反馈与投诉→ 交易投诉 → 选择全部小程序订单 → 选择需要投诉的订单 → 提交投诉内容

![](https://res.wx.qq.com/wxdoc/dist/assets/img/09311-11.7ac6397a.png)

### [#](#二、交易投诉处理指南) 二、交易投诉处理指南

为确保您的问题能高效解决，请您留意后续流程中的通知与指引。

#### [#](#_1、申请平台介入) 1、申请平台介入

为确保您的权益，若与商家协商不成，您可在48小时内申请平台介入。若逾期未申请，则视为您放弃本次投诉，平台将终止处理，且后续无法再次就本单发起投诉。

操作步骤如下：
微信"服务通知" → 点击订单消息中的"查看详情" → 点击"平台介入"

![](https://res.wx.qq.com/wxdoc/dist/assets/img/09311-04.555070f8.png)

#### [#](#_2、平台处理环节) 2、平台处理环节

1)下发举证

平台将依据现有凭证进行审核。如需补充材料，状态将变更为【待用户补充凭证】，您需在48小时内提交。若逾期未提供，则视为您放弃本次投诉，平台将终止处理，且后续无法再次就本单发起投诉。

操作步骤如下：
微信"服务通知" → 点击订单消息中的"查看详情"→点击"补充凭证"→提交

![](https://res.wx.qq.com/wxdoc/dist/assets/img/09311-07.2e44b885.png)

2)退货流程

根据平台规则，如需客户执行退货行为，状态将变更为【待用户退货】，为保障您的退款权益，您需在7天内提交，若逾期未提交，则视为您自动放弃本次退货退款权利。

操作步骤如下：
微信"服务通知" → 点击订单消息中的"查看详情"→点击"立即退货"→选择提货方式

![](https://res.wx.qq.com/wxdoc/dist/assets/img/09311-03.f1a41c29.png)

### [#](#三、交易投诉撤销指引) 三、交易投诉撤销指引

若您的诉求已得到满足，在平台介入判责前，您可通过以下步骤撤销投诉

**重要提示： 点击"撤销投诉"即视为您确认纠纷已解决，平台将关闭此投诉，且后续无法再次就本单发起投诉。**

路径一：小程序页面 → 右上角"···" → 反馈与投诉 → 交易投诉 →选择【申请退款/其他问题】找到对应订单完成撤销订单

![](https://res.wx.qq.com/wxdoc/dist/assets/img/09311-06.d30a2af5.png)

路径二：微信→服务通知→查找"微信公众平台"通知 → 点击进入投诉单 → 撤销投诉

![](https://res.wx.qq.com/wxdoc/dist/assets/img/09311-05.3c46cc6e.png)
