# [#](#服务质量问题处理细则) 服务质量问题处理细则

## [#](#第一章-总则) 第一章 总则

### [#](#_1、概述) 1、概述

为规范微信小程序平台交易纠纷秩序，明确在"服务无法兑换/使用/不相符"场景下用户与开发者的责任与义务，保障双方的合法权益，公平、公正、高效地处理交易纠纷。依据《中华人民共和国电子商务法》《中华人民共和国消费者权益保护法》《网络交易监督管理办法》等法律法规，以及《微信小程序平台运营规范》等相关平台规则，制定本细则。

### [#](#_2、适用范围) 2、适用范围

本细则适用于所有在微信小程序平台内，因商品"服务无法兑换/使用/不相符"问题引发的交易纠纷处理。

＊"服务无法兑换/使用/不相符"定义参考如下：  
1）服务无法兑换，指用户完成支付后，在尝试激活、获取服务起始权益的阶段即遭遇阻碍，未能成功将购买的服务凭证转换为可使用的服务状态。具体情形包括但不限于：  
a、用户已支付服务费用，但未获得服务兑换码、券码或有效使用入口；  
b、服务兑换码或券码因系统问题、技术故障等原因无法核销；  
c、开发者无正当理由拒绝提供服务兑换。

2）服务无法使用，指用户已成功兑换并获取服务权限后，在服务承诺的有效期内，非因用户自身原因，持续或间歇性地无法正常访问、运行或享受服务核心功能。具体情形包括但不限于：  
a、服务下架/删除：开发者单方面将用户已购买的视频课程、文档资料、软件服务等移除、下架或删除，导致用户无法访问；  
b、技术故障：服务所依赖的服务器崩溃、程序报错、网络接口失效、视频无法播放、音频无法收听、功能按钮点击无响应等，且故障非由用户设备或网络环境引起；  
c、依赖资源失效：服务正常运行所必需的第三方授权（如地图接口、支付接口、版权内容）到期或中断或变更，开发者未及时修复或提供替代方案；  
d、无理由中止：开发者在无明确、合理通知的情况下，中止提供已承诺的服务。

3）服务不相符，指开发者实际提供的服务在质量、内容、功能、标准或条件等方面，与其在销售页面的宣传描述，或与用户达成的特定约定存在实质性差异。具体情形包括但不限于：  
a、服务内容、功能、时长、范围等与页面描述或约定不一致；  
b、服务存在未明确告知的权限限制、设备限制、有效期、使用条件或附加费用；  
c、服务质量明显低于行业同类服务的一般标准或其宣传承诺。

### [#](#_3、基本原则) 3、基本原则

微信小程序平台坚持公平、公正、公开的原则，以事实为依据，以法律法规和平台规则为准绳，协助用户与开发者解决交易纠纷。

## [#](#第二章-开发者责任) 第二章 开发者责任

### [#](#_1、商品描述责任) 1、商品描述责任

开发者对在微信小程序平台所销售商品的描述须真实、准确、完整。所售商品应当与达成交易时开发者对商品的描述一致，不得进行虚假或引人误解的宣传。

### [#](#_2、服务质量要求) 2、服务质量要求

开发者提供的服务应具备其应有的质量、性能和用途，符合国家标准、行业标准或其宣传的标准。

### [#](#_3、信息告知责任) 3、信息告知责任

必须清晰、全面地告知用户服务的核心信息，包括但不限于价格、内容、有效期、使用规则、限制条件等，不得隐瞒关键信息。

## [#](#第三章-纠纷处理细则) 第三章 纠纷处理细则

平台介入后，双方须在48小时内，根据所属品类、投诉场景及以下举证指南提交对应凭证。同时，请务必密切关注微信服务通知或小程序内的处理进度。

### [#](#_2、判责标准) 2、判责标准

平台将基于普通人的认知、交易惯例及审慎原则，对开发者与用户提供的证据进行形式审核，并据此作出判断。请注意，平台的判断是基于所提交证据的中立调解，并非司法认定。

※判责标准细则参考如下：

| 责任类型 | 具体情形 |
| --- | --- |
| **平台免责情形** | **a、** 因不可抗力（包括但不限于自然灾害、战争、罢工或政府行为）导致开发者无法按时履约，开发者应在事后及时向平台及用户说明情况，并提供相应证明材料（如官方通报），经平台审核确认有效； **b、** 用户所反馈问题，经平台核实开发者已介入有效处理的情况，如用户主张券码无法兑换，开发者在纠纷和解阶段已协助用户成功兑换。 |
| **用户责任情形** | **a、** 因用户自身原因（如错误操作、使用不符合要求的设备或环境）导致服务不相符，或因泄露凭证密码导致服务被他人使用等； **b、** 服务已兑换使用，因用户个人喜好或主观感受觉得不喜欢要求退款； **c、** 用户超时未回复/未提供有效凭证，导致平台无法进一步核实开发者问题的； **d、** 用户所反馈问题，开发者已提供相应反驳凭证，平台核查确认有效的； **e、** 用户所反馈问题，经平台核查确认，该诉求不在平台纠纷处理规则范围内。 |
| **开发者责任情形** | **a、** 因开发者原因（如技术故障、涉及违规内容被下架等）导致服务无法兑换或无法使用； **b、** 商品页面描述、宣传素材、客服沟通等内容与实际服务内容、功能、质量等存在显著或实质性的差异，平台核查属实； **c、** 开发者无正当理由拒绝为用户提供服务兑换，或未与用户协商一致的情况下，擅自中止提供已承诺的服务； **d、** 开发者未在和解期间将问题处理妥当，平台介入后核实用户反馈问题属实的； **e、** 在纠纷处理过程中，针对用户所反馈问题，开发者无正当理由拒绝提供有效凭证，或全程未提供有效凭证，或提供的凭证无效、不完整。 |
