# [#](#收费争议处理细则) 收费争议处理细则

## [#](#第一章-总则) 第一章 总则

### [#](#_1、概述) 1、概述

为规范微信小程序平台交易纠纷秩序，明确在"收费不合理"场景下用户与开发者的责任与义务，保障双方的合法权益，公平、公正、高效地处理交易纠纷。依据《中华人民共和国电子商务法》《中华人民共和国消费者权益保护法》《网络交易监督管理办法》《中华人民共和国价格法》等法律法规，以及《微信小程序平台运营规范》等相关平台规则，制定本细则。

### [#](#_2、适用范围) 2、适用范围

本细则适用于所有在微信小程序平台内，因商品或服务"收费不合理"问题引发的交易纠纷处理。包括但不限于：商品/服务未明码标价或价格标示不清晰、实际收费与宣传价格不符、存在隐藏费用、捆绑收费等不合理收费行为，以及开发者单方面变更价格或收费标准。

### [#](#_3、基本原则) 3、基本原则

微信小程序平台坚持公平、公正、公开的原则，以事实为依据，以法律法规和平台规则为准绳，协助用户与开发者解决交易纠纷。

## [#](#第二章-开发者责任) 第二章 开发者责任

### [#](#_1、商品描述责任) 1、商品描述责任

开发者对其在微信小程序平台所销售商品/服务的描述须真实、准确、完整。开发者须在小程序页面清晰、明确标示商品/服务价格，包括但不限于商品/服务的品名、产地、规格、等级、商品基础服务费用及计价单位、可能产生的附加费用及收取条件、优惠活动的具体规则、范围和有效期等信息。

### [#](#_2、价格一致性要求) 2、价格一致性要求

开发者需确保商品/服务宣传价格与实际收费一致，包括但不限于广告、推广内容与实际价格一致、活动期间价格执行到位、不得在交易过程中擅自加价、不得收取任何未予标明的费用。如商品/服务的收费标准发生变更，应及时公示并告知用户。

### [#](#_3、履约责任) 3、履约责任

交易达成后，开发者应严格按照约定价格提供商品或服务，且服务内容与价格相匹配，不得单方面变更价格。

## [#](#第三章-纠纷处理细则) 第三章 纠纷处理细则

### [#](#_1、举证指引) 1、举证指引

平台介入后，双方须在48小时内，根据所属品类、投诉场景及以下举证指南提交对应凭证。同时，请务必密切关注微信服务通知或小程序内的处理进度。

※常见纠纷类型及对应举证规则参考如下：

| 品类 | 投诉场景 | 用户举证指南 | 开发者举证指南 |
| --- | --- | --- | --- |
| 通用商品类 | 定价不合理 | 订单商品存在定价不合理的依据，如：商品公开定价与实际收费不符的凭证说明。 | 包括但不限于： 事先公示的标价与实际收费的对比说明 |
| 非营业性演出票务类 | 退款收取手续费 | 订单票务开发者支持全额退款的凭证，如：商品详情页注明支持退款的截图或与开发者沟通聊天记录等。 | 包括但不限于： 商品详情页已提前告知商品退款需要收取手续费的截图凭证等 |
| 电单车租赁类 | 调度费不合理 | 已在运营区停车点内停放车辆的依据，如：小程序后台内停放车辆定位截图等。 | 包括但不限于： 因用户原因导致的车辆违规停放的后台截图凭证等 |
| 微短剧类 | 剧集未标注消费金额/剧集定价不合理 | / | 包括但不限于： 前端设置事先标注的收费金额明细以及用户后台消费的金额列表明细 |

### [#](#_2、判责标准) 2、判责标准

平台将基于普通人的认知、交易惯例及审慎原则，对开发者与用户提供的证据进行形式审核，并据此作出判断。请注意，平台的判断是基于所提交证据的中立调解，并非司法认定。

※判责标准细则参考如下：

| 责任类型 | 具体情形 |
| --- | --- |
| **平台免责情形** | **a、** 因不可抗力（包括但不限于自然灾害、战争、罢工或政府行为）导致开发者无法按时履约，开发者应在事后及时向平台及用户说明情况，并提供相应证明材料（如官方通报），经平台审核确认有效； **b、** 用户所反馈问题，经平台核实开发者已介入有效处理的情况，如用户主张订单商品收费不合理，开发者在纠纷和解阶段已完成退款。 |
| **用户责任情形** | **a、** 商品或服务已使用，用户仅因个人主观感受（如不喜欢、认为不值）要求退款； **b、** 用户使用租赁商品如共享电单车时，未按商品（未存在质量问题）要求停放在规定运营区导致收取调度费； **c、** 用户超时未回复/未提供有效凭证，导致平台无法进一步核实开发者问题的； **d、** 用户所反馈问题，开发者已提供相应反驳凭证，平台核查确认有效的； **e、** 用户所反馈问题，经平台核查确认，该诉求不在平台纠纷处理规则范围内。 |
| **开发者责任情形** | **a、** 开发者存在商品或服务无明确标价或价格模糊不清的行为，平台核查属实； **b、** 商品或服务宣传价格与实际收费标准存在显著或实质性差异，平台核查属实； **c、** 开发者未提前告知商品/服务的附加费用或强制捆绑消费，平台核查属实； **d、** 开发者未在和解期间将问题处理妥当，平台介入后核实用户反馈问题属实的； **e、** 在纠纷处理过程中，针对用户所反馈问题，开发者无正当理由拒绝提供有效凭证，或全程未提供有效凭证，或提供的凭证无效、不完整。 |
