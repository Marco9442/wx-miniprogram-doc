# [#](#盲盒类交易纠纷处理细则) 盲盒类交易纠纷处理细则

## [#](#第一章-总则) 第一章 总则

### [#](#_1、概述) 1、概述

为规范微信小程序内盲盒类经营活动的交易纠纷处理，保护用户、开发者及平台的合法权益，维护公平、诚信的网络交易环境，依据《中华人民共和国民法典》《中华人民共和国消费者权益保护法》《中华人民共和国电子商务法》，国家市场监督管理总局《盲盒经营行为规范指引（试行）》等法律法规，以及《微信小程序平台服务条款》等平台规则，制定本细则。

### [#](#_2、盲盒的性质及适用范围) 2、盲盒的性质及适用范围

1）盲盒是以随机抽选为特征的销售模式，盲盒内商品款式不透明，商品具体款式等属性存在不确定性，涵盖潮流玩具、文具、美妆、零食等领域，通过互联网、实体店、自动贩卖机等形式，以用户随机抽取的方式销售特定范围内商品或者服务。

2）本细则适用于所有在微信小程序内从事盲盒商品销售或盲盒式服务（如线上抽盒、虚拟抽奖、游戏道具抽取、线下购买盲盒等）的开发者与用户之间产生的交易纠纷处理，盲盒类交易纠纷优先适用本细则。

### [#](#_3、基本原则) 3、基本原则

微信小程序平台坚持公平、公正、公开的原则，以事实为依据，以法律法规和平台规则为准绳，协助用户与开发者解决交易纠纷。

## [#](#第二章-开发者经营义务) 第二章 开发者经营义务

### [#](#_1、信息公示) 1、信息公示

开发者必须在小程序页面的显著位置，以清晰、易懂的方式向用户全面、真实、准确披露以下信息，确保用户在购买前知晓：

1）商品/服务信息：盲盒内可能包含的商品或服务的基本信息、品牌/种类、规格样式、材质、性能等。

2）抽取规则：盲盒商品的投放数量、抽取概率、分布规则等。概率公示必须真实、清晰，不得篡改或隐藏。

3）价值标准：盲盒内关键款、隐藏款等的确定价值或价值范围。

4）购买限制：设置单个用户单次交易金额和次数上限的，应明确公示。

5）售后服务政策：明确的退换货规则、投诉渠道等。

### [#](#_2、依法经营) 2、依法经营

1）开发者应当取得许可后开展相关经营行为。法律法规明确规定禁止销售、流通的商品或者禁止提供的服务，不得以盲盒形式进行销售或者提供。

2）药品、医疗器械、有毒有害物品、易燃易爆物品、活体动物等在使用条件、存储运输、检验检疫等方面有严格要求的商品，不得以盲盒形式销售。食品、化妆品，不具备保障质量安全和用户权益条件的，不应当以盲盒形式销售。无法投递又无法退回的快件，不得以盲盒形式销售。

3）应当按照法律法规规定，通过产品标签、消费提示等方式充分告知用户盲盒商品的名称、产地、生产者、执行标准、性能、规格、成分、生产日期、有效期限、使用存储条件、安全警示、"三包"条款等关系商品质量的基本必要信息，标注的信息应当真实、准确。

4）提供的商品或者服务不符合质量要求的或者与开发者明示不符的，应当依法履行退货、更换、修理等义务，不得故意拖延或者无理拒绝。

### [#](#_3、禁止行为) 3、禁止行为

1）禁止虚构或篡改抽取概率、销售数量、用户评价、商品数量、商品规格、商品质量、服务提供方式等信息，通过后台操纵等方式干预抽取结果，实施虚假宣传或者引人误解的商业宣传，欺骗、误导用户，如暗示必中"隐藏款"等。

2）禁止向未满8周岁的未成年人销售盲盒。向8周岁及以上的未成年人销售盲盒，需以显著方式告知其监护人，并取得监护人同意。

3）不得以提供折现、回购、换购等替代方案的方式，拒绝或者故意拖延履行发放盲盒的义务。不得设置空盒，或销售假冒伪劣、三无产品等。

### [#](#_2、判责标准) 2、判责标准

平台将基于普通人的认知、交易惯例及审慎原则，对开发者与用户提供的证据进行形式审核，并据此作出判断。请注意，平台的判断是基于所提交证据的中立调解，并非司法认定。

※判责标准细则参考如下：

| 责任类型 | 具体情形 |
| --- | --- |
| **平台免责情形** | **a、** 因不可抗力（包括但不限于自然灾害、战争、罢工或政府行为）导致开发者无法按时履约，开发者应在事后及时向平台及用户说明情况，并提供相应证明材料（如官方通报），经平台审核确认有效； **b、** 用户所反馈问题，经平台核实开发者已介入有效处理的情况，如用户主张无法提货，开发者在纠纷和解阶段已发货且提供有效物流单号。 |
| **用户责任情形** | **a、** 用户因"不喜欢"要求退货/商品已被用户拆封影响二次销售，且商品未存在质量问题或描述不符的情况； **b、** 用户超时未回复/未提供有效凭证，导致平台无法进一步核实开发者问题的； **c、** 用户所主张问题，开发者已提供相应反驳凭证，平台核查确认有效的； **d、** 用户所反馈问题，经平台核查确认，该诉求不在平台纠纷处理规则范围内。 |
| **开发者责任情形** | **a、** 开发者超时未发货/上传虚假物流单号，平台将支持用户的退款申请； **b、** 用户主张收到的实物与开发者页面宣传的款式、品质、材质等存在显著差异，且提供清晰的商品照片、视频等有效凭证； **c、** 用户主张收到的商品存在破损、变形、无法正常使用等质量问题，且提供商品质量问题的清晰图片、视频等有效凭证，支持用户退货退款或换货； **d、** 未成年人在未经监护人同意的情况下进行大额盲盒消费，监护人要求退款。     8周岁以下：其购买行为无效，平台支持全额退款。     8周岁以上、未满18周岁：其购买行为需经法定代理人同意或追认。监护人需提供身份关系证明（如户口本）及未成年人消费证明。平台将根据消费金额、未成年人认知能力等因素综合判断； **e、** 开发者未在和解期间将问题处理妥当，平台介入后核实用户反馈问题属实的； **f、** 在纠纷处理过程中，针对用户所反馈问题，开发者无正当理由拒绝提供有效凭证，或全程未提供有效凭证，或提供的凭证无效、不完整。 |
