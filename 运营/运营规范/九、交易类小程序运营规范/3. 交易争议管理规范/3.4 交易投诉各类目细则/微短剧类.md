# [#](#微短剧交易纠纷处理细则) 微短剧交易纠纷处理细则

## [#](#第一章-总则) 第一章 总则

### [#](#_1、概述) 1、概述

为规范微信小程序平台内微短剧类交易秩序，保障用户和开发者的合法权益，公平、公正、高效地处理交易纠纷。依据《中华人民共和国电子商务法》《中华人民共和国消费者权益保护法》《网络交易监督管理办法》《网络短视频内容审核标准细则》等法律法规，以及《微信小程序平台运营规范》等相关平台规则，制定本细则。

### [#](#_2、适用范围) 2、适用范围

本细则适用于所有在微信小程序平台内，用户通过小程序内直接支付、虚拟货币充值兑换、会员订阅等方式，获取开发者以短剧集形式呈现的数字化视频内容观看权限的交易行为，由此产生的关于微短剧付费解锁、服务履行、宣传真实性、退款等问题的纠纷处理。

＊注：微短剧，即单集时长通常在几十秒至15分钟以内，以1-3分钟为主流，具有明确的故事情节和角色设定，以多集形式连载，叙事节奏极快，多数为适应手机观看而采用竖屏拍摄和制作的数字化视频内容。

### [#](#_3、基本原则) 3、基本原则

微信小程序平台坚持公平、公正、公开的原则，以事实为依据，以法律法规和平台规则为准绳，协助用户与开发者解决交易纠纷。

## [#](#第二章-开发者责任) 第二章 开发者责任

### [#](#_1、内容真实合规) 1、内容真实合规

1）开发者应在商品详情页面清晰、准确、完整地披露包括但不限于剧集付费点、付费规则、价格、更新频率、服务期限等信息，保障用户的知情权与选择权。

2）开发者应确保其发布的微短剧内容合法合规，不得含有违反国家法律法规、政治制度、公序良俗、社会道德规范的内容。

3）开发者宣传推广时应确保微短剧内容真实准确，宣传素材（如封面、剧情简介、预告片）应与正片内容实质相符，不得进行虚假或引人误解的商业宣传。

### [#](#_2、服务保障) 2、服务保障

1）开发者应在用户支付成功后，立即或按约定时间为用户提供其所购买的微短剧观看服务。

2）开发者应保障服务的稳定性和连续性。如因技术原因导致服务中断，应及时修复并向用户公告。若因开发者自身原因（非平台原因）导致服务长时间中断，开发者应提供相应补偿或退款方案。

平台介入后，双方须在48小时内，根据所属投诉场景及以下举证指南提交对应凭证。同时，请务必密切关注微信服务通知或小程序内的处理进度。

### [#](#_2、判责标准) 2、判责标准

平台将基于普通人的认知、交易惯例及审慎原则，对开发者与用户提供的证据进行形式审核，并据此作出判断。请注意，平台的判断是基于所提交证据的中立调解，并非司法认定。

※判责标准细则参考如下：

| 责任类型 | 具体情形 |
| --- | --- |
| **平台免责情形** | **a、** 因不可抗力（包括但不限于自然灾害、战争、罢工或政府行为）导致开发者无法按时履约，开发者应在事后及时向平台及用户说明情况，并提供相应证明材料（如官方通报），经平台审核确认有效； **b、** 用户所反馈问题，经平台核实开发者已介入有效处理的情况，如用户主张充值未到账，开发者在纠纷和解阶段已提供充值到账的后台记录。 |
| **用户责任情形** | **a、** 用户已使用会员服务/消费币已消耗，因个人主观原因不喜欢剧集内容要求退款（未存在商品不符或质量问题），开发者有权拒绝； **b、** 未成年人充值消费，开发者已采取充分技术措施（如强制实名认证、人脸识别、消费限额等）验证用户身份，且监护人无法提供有效凭证的； **c、** 用户超时未回复/未提供有效凭证，导致平台无法进一步核实开发者问题的； **d、** 用户所反馈问题，开发者已提供相应反驳凭证，平台核查确认有效的； **e、** 用户所反馈问题，经平台核查确认，该诉求不在平台纠纷处理规则范围内。 |
| **开发者责任情形** | **a、** 微短剧实际内容（如主演、剧情核心、结局类型、总集数、单集时长等）与开发者宣传存在实质性差异，平台核查属实； **b、** 剧集内容无法播放、卡顿严重（非用户网络原因）、涉及违规内容导致下架无法观看； **c、** 非不可抗力因素，如系统异常或小程序无法使用导致开发者无法完成对用户的履约或服务； **d、** 开发者未在和解期间将问题处理妥当，平台介入后核实用户反馈问题属实的； **e、** 在纠纷处理过程中，针对用户所反馈问题，开发者无正当理由拒绝提供有效凭证，或全程未提供有效凭证，或提供的凭证无效、不完整。 |
