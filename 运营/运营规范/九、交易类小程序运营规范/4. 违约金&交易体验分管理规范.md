# [#](#小程序违约金-体验分管理规定) 小程序违约金&体验分管理规定

## [#](#第一章-总则) 第一章 总则

### [#](#_1、概述) 1、概述

本规定以 "违约金" 与 "交易体验分" 双重机制为核心。其中，"违约金" 对经核实的单次违规行为进行定额处理，以发挥即时惩戒与纠正作用；而 "交易体验分" 作为评价小程序长期服务质量的综合量化体系，是平台实施梯度化管理的重要依据。二者相互配合，旨在引导开发者不断提升服务水平，共同推动平台生态的持续健康发展。

### [#](#_2、适用范围-基本原则) 2、适用范围&基本原则

1)本规则适用于所有在微信小程序平台内开展经营活动的小程序开发者（以下简称 "开发者" ）。  
2)微信小程序平台违约金管理遵循合法合理、公平诚信的原则，以事实为依据，以法律法规和平台规则为准绳，旨在弥补守约方损失，惩戒违约行为，维护平台交易秩序。

### [#](#_3、处理-申诉原则) 3、处理&申诉原则

1)违规判定：平台基于用户投诉/举报、监管部门通报、主动排查等合法合规渠道获取开发者涉嫌交易服务违规的相关信息，并结合开发者的举证情况对违规行为进行核实判定。如判定违规，平台将依据本规则采取相应处理措施。  
2)违约金：违约金的产生以纠纷单的最终处理结果为准。若纠纷单被判定为开发者责任，且开发者未能在72小时申诉时效内提出有效申诉或其申诉被驳回，系统将自动生成违约金。  
3)交易体验分：开发者如对平台作出的交易体验分扣分决定存在异议，可自收到扣分通知之日起7个自然日内向平台发起申诉。逾期未申诉，视为认可该扣分处理。

### [#](#_4、-责任界定与豁免) 4、 责任界定与豁免

平台依据本规则及现有证据对违规行为进行审慎判断并作出处理决定。开发者理解并同意，平台并非司法或行政机关，其判断仅以普通理性人的认知水平为标准。除因平台的故意或重大过失直接导致损失外，平台对依据本规则执行的处理措施不承担法律责任。

## [#](#第二章-违约金处理细则) 第二章 违约金处理细则

在微信小程序交易纠纷处理中，违约金是平台针对开发者已确认的违规行为所采取的经济惩戒措施。一旦违规行为经平台核实，开发者即需支付固定金额的违约金，以达成即时纠正偏差与维护交易秩序的目的。

### [#](#_1、违约行为) 1、违约行为

违约类型 | 行为 | 描述 || 商品违规 | 描述不符 | 指开发者实际销售的商品/提供的服务与其对该商品/服务的展示、描述明显不符，包括但不限于商品/服务的性质、价值、外形、物流方式、运费、售后服务等要素不符。 |
| 质量不合格/品质问题 | 指商品/服务质量不符合国家标准、行业标准或平台相关规则要求，或因商品/服务品质问题影响用户对其使用功能、目的的实现。 |
| 假冒品牌 | 出售假冒商品，出售假冒注册商标商品或出售盗版商品的行为。 |
| 故意混淆 | 经判定，所经营的商品或品牌对他人品牌、商品名称、包装或页面设计、企业名称、产品质量标志等构成仿冒或容易造成买家混淆、误认的。 |
| 经营违规 | 发货超时 | 指开发者超过承诺发货时限仍未进行发货；如开发者未约定发货时限，平台以用户支付后72小时内发货为准进行判定。 |
| 诱导线下支付 | 指开发者诱导用户通过微信转账、微信红包等方式进行支付。 |
| 未按约定提供相关资质 | 指开发者未按照平台规则向平台提供相关资质。 |
| 不当获取使用信息 | 指开发者未经允许发布、传递、出售交易信息/用户信息，或致使用户信息存在泄露风险的行为。 |
| 咨询违规 | 消极回复 | 指开发者对用户、举报人或平台工作人员、检测机构工作人员等人实施威胁、恐吓、诽谤、骚扰、跟踪、诋毁、谩骂等行为，或使用引起他人不满的字句等行为。 |
| 恶意屏蔽 | 指开发者利用技术手段无故将用户拉至黑名单，导致用户无法正常享有客服服务等行为。 |
| 售后违规 | 消极售后 | 指开发者在审核处理售后服务环节，存在未与用户核实确认、未协商一致、自行无故/批量驳回用户的售后服务的行为。 |
| 售后服务缺失 | 指开发者不设置售后服务，或虽设置售后服务，但对相关入口或功能进行隐藏，或通过其他方式卡死售后功能导致用户体验受损。 |
| 交易投诉违规 | 和解期超时未回复 | 开发者在用户发起投诉后拒绝主动提供售后服务解决用户问题。 |
| 拒绝举证 | 开发者在平台纠纷介入等环节拒绝提供平台要求的举证材料解决用户问题。 |
| 拒绝执行 | 开发者在交易投诉判责后拒绝执行退款/退货退款等判责结果的行为。 |
| 提供虚假凭证 | 指开发者违背法律法规或者平台规则等的规定，向平台提供不真实的证明材料的行为。 |
| 未按时缴纳保证金 | 指开发者根据本规则规定应缴纳/补缴保证金，而在平台下发系统通知后，未在规定期限内足额缴纳保证金。 |
| 其他违规 | 其他违规行为 | 其他违反法律法规、平台协议、规则或影响用户交易体验的行为。 |

### [#](#_2、违约金规则) 2、违约金规则

1)金额：在平台介入判定存在本规则第二章列举的任一违约行为后，如果出现以下任一情况，开发者须向平台支付违约金15元：  
a、开发者的申诉被平台驳回；  
b、开发者未在平台规定的申诉期限内提交申诉材料（即申诉超时）。  
2)违约金由开发者按周支付。平台将根据开发者违规次数计算开发者应支付的违约金总金额，于每周一向开发者下发支付违约金的通知。  
3)开发者应于接到通知后15个自然日内，按照平台下发通知载明的截止上一周期应支付违约金总额向平台足额支付违约金。  
4)开发者未按期足额支付违约金的，平台将采取限制措施，包括但不限于限制小程序搜索、向用户提示存在交易纠纷等，直至开发者足额支付违约金。

### [#](#_3、其他) 3、其他

1)因不可抗力（包括但不限于自然灾害、战争、或政府行为）导致的违约，开发者应及时向平台和消费者说明情况，并提供相应证明材料（如官方通报），经平台审核确认有效，可酌情减免违约金。  
2)除本规则列举的违约情形外，开发者如存在其他违反法律法规或平台规则的行为，包括但不限于销售违禁商品、销售假冒/三无商品、进行虚假交易等行为，腾讯将按照[《微信小程序平台运营规范》](https://developers.weixin.qq.com/miniprogram/product/#%E4%B8%80%E3%80%81%E5%8E%9F%E5%88%99%E5%8F%8A%E7%9B%B8%E5%85%B3%E8%AF%B4%E6%98%8E) 等平台规则对开发者和/或小程序采取限制功能甚至终止服务等处理。

## [#](#第四章-交易体验分处理细则) 第四章 交易体验分处理细则

小程序交易体验分是一种旨在保障用户交易体验、激励开发者提升服务质量的综合评估机制。该机制通过对开发者的违规行为进行判定，并根据严重程度扣减相应分值，以量化其服务水平。交易体验分作为一项累计性指标，当分数扣减至特定阈值时，平台将触发相应的处理措施，实现对开发者的梯度化管理。

### [#](#_1、交易体验分规则) 1、交易体验分规则

1)交易体验分以小程序为单位进行管理，每一小程序的初始交易体验分分值为100分。如同一开发者有多个小程序，不同小程序将分别计分。但如开发者被平台采取了"终止服务"的处理措施，则该开发者的所有小程序均受影响。  
2)当开发者在其小程序出现本规则第二章列举的任一违规行为，平台将根据违规行为的严重程度对该小程序进行不同分值的交易体验分扣减。  
3)当小程序的交易体验分被扣减至（等于或小于）如下分值节点，平台有权对该小程序/其开发者采取相应节点的处理措施。  
4)小程序交易体验分扣分于每年的1月1日、4月1日、7月1日、10月1日清零。扣分清零后，小程序的交易体验分分值恢复为初始分值（100分）。已被采取终止服务处理措施的开发者及其小程序不适用本条规定。

### [#](#_2、分值及处理措施) 2、分值及处理措施

| 分值 | 处理措施 | 措施/后果描述 | 持续时长 |
| --- | --- | --- | --- |
| 95分 | 交易体验风险预警 | 平台通过站内信、模板消息等方式，对开发者的违规行为及分值情况进行提示告警。 | / |
| 90分 | 交易体验风险预警 | 平台通过站内信、模板消息等方式，对开发者的违规行为及分值情况进行提示告警。 | / |
| 85分 | 交易体验风险预警 | 平台通过站内信、模板消息等方式，对开发者的违规行为及分值情况进行提示告警。 | / |
| 80分 | 保证金缴纳 | 开发者应按照[《小程序交易保证金管理规定》](https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/ministore/minishopopencomponent2/baozhengjin.html) 的规定缴纳相应金额保证金 | / |
| 60分 | 小程序交易风险提示 | 用户在进入支付环节时，系统弹出针对该小程序的交易风险提示页，对用户进行提醒。 | 1天 |
| 40分 | 小程序交易风险提示 | 用户在进入支付环节时，系统弹出针对该小程序的交易风险提示页，对用户进行提醒。 | 3天 |

| 0分 | 停止服务 | 平台将停止为开发者提供服务，用户将无法搜索、打开该开发者的所有小程序，开发者亦无法在平台注册、经营其他新的小程序。 | 永久 |
| 0分 | 停止服务 | 平台将停止为开发者提供服务，用户将无法搜索、打开该开发者的所有小程序，开发者亦无法在平台注册、经营其他新的小程序。 | 永久 |
