# [#](#小商店个人-企业-个体-事业单位-其他组织类型介绍) 小商店个人/企业/个体/事业单位/其他组织类型介绍

## [#](#个人) 个人

1. 什么是个人店：即按电商法规定无须进行市场主体登记的个人主体。
2. 开店个数限制：一个微信号仅能申请1个“个人”主体的微信小商店。
3. 开店规则：注册成功后获得小商店，完善身份证信息（身份证正反面照片）并签约即可拥有支付能力，后续提供银行卡信息（收款银行卡号及其开户省市）即可提现。
4. 结算规则

开通小商店，将自动开通一个全新的微信支付商户号。 商家可以直接在小商店后台进行经营对账。用户的每一笔货款都会直接到达商家自己的微信支付商户号账号中，到账的款项无特殊情况均为待结算状态，商家将在用户确认收货后，可对该笔款项进行提现至银行账户操作。

目前统一的确认收货规则为：用户可手动对订单确认收货，若不手动确认收货，在商家发货15天后系统将自动确认收货。若订单中有商品发生了退款/售后，订单自动确认收货的倒计时将停止。

### [#](#每日收款限额) 每日收款限额

● 正常日收款上限额度为10万，若交易良好则自动提升至20-30万/日，若交易异常则自动下降至5万以下/日。

● 信用卡单日收款上限不超过1千，信用卡单月收款不超过1万。

### [#](#手续费) 手续费

目前平台的单笔交易手续费为0.6%，后续针对不同类别的商家在规划对应的优惠政策。
