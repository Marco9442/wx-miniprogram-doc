## [#](#工信部短信核验常见问答) 工信部短信核验常见问答

### [#](#_1、收不到管局发送的核验短信怎么办？) 1、收不到管局发送的核验短信怎么办？

- 如果你未收到管局发送的核验短信，请按以下信息进行排查。检查信息是否被手机管家识别为垃圾或骚扰短信被拦截，确认能不能正常接收其他短信。
- 检查手机是否欠费停机。
- 建议你将手机卡插入其他手机，再登录[工信部备案管理系统](http://beian.miit.gov.cn/)进行短信重发。
- 接入备案时如果收不到核验短信，请检查手机号码是否正确。

### [#](#_2、工信部短信核验未通过（验证超时或验证失败）怎么办？) 2、工信部短信核验未通过（验证超时或验证失败）怎么办？

若你收到验证短信后，未在24小时内完成短信核验或验证失败，备案信息将自动退回至平台。具体分为以下几种情况：

- 若你的备案信息未进行修改，且备案资料符合当前要求。在微信公众平台-首页-小程序备案-点击【去完善】备案，重新提交备案信息至管局审核，提交后，备案负责人会再次收到工信部发送的短信通知。请按照短信提示，在24小时内登录所在省市的管局网站完成短信核验
- 若你的备案信息或备案资料不符合当前要求，需要进行修改。你的订单将会被驳回，你需要重新提交备案申请，通过平台审核后再次进入短信核验环节。
- 负责人证件号码、手机号码、验证码任意信息共计输错5次后，第6次验证时工信部系统会将你的备案申请信息退回。在微信公众平台-首页-小程序备案-点击【去完善】备案，重新提交备案信息至管局审核。  
   **提示：** 如你确认填写的信息正确无误，但系统还是提示你该条验证库里找不到记录，该问题可能是系统原因造成，实际备案信息已进入管局进行审核中，请你耐心等待管局审核。  
   ![](https://res.wx.qq.com/op_res/OWYK7BDs6Ghzl3zeFaPQKEN28KcGItl0VPPRP-V2iiduPKn-qmtJli3Ee7Ocrr85ZRHi0GMyFD58uZHBvQnBjA)

### [#](#_3、工信部短信核验信息输入错误怎么办？) 3、工信部短信核验信息输入错误怎么办？

- 可能原因：你的信息输入错误或输入的三条信息（短信核验验证码、手机号码、证件号码后6位）不匹配，系统找不到对应的订单。
- 处理方法：请根据下述要求仔细检查你本次备案的短信核验验证码、手机号码、证件号码后6位，核实信息后重新输入正确的信息。  
   **手机号：** 你需根据自身角色填写主体负责人或小程序负责人在备案信息中联系方式的手机号码，不同备案场景下需要验证的负责人不同。  
   **验证码：** 请查看工信部发送的短信核验验证码，填写其中6位数字验证码。如你未收到、遗忘或其他原因丢失了短信核验验证码，可登录工信部备案管理系统重发短信。

### [#](#_4、短信核验提示“暂无待短信核验的备案申请，无需重发短信”怎么办？) 4、短信核验提示“暂无待短信核验的备案申请，无需重发短信”怎么办？

- 问题描述：在[工信部备案管理系统](http://beian.miit.gov.cn/)，单击短信重发根据要求填写信息，单击提交后系统提示如下。
- 可能原因：当前主体单位并未提交备案申请，系统无法匹配到需要进行短信核验的备案订单。
- 处理方法：如你需对小程序进行备案，在微信公众平台-首页-小程序备案-点击去完善备案，重新提交备案信息至管局审核。  
   ![](https://res.wx.qq.com/op_res/OWYK7BDs6Ghzl3zeFaPQKJ3JtJDW_nuGqfMPxCuvoBQy9Of-xZiwqXFDFOsFjtjuJ05K0zqkuHKjj7TeS8bkHg)

### [#](#_5、重发短信提示“该条验证库里找不到记录。”怎么办？) 5、重发短信提示“该条验证库里找不到记录。”怎么办？

- 问题描述：在[工信部备案管理系统](http://beian.miit.gov.cn/)，单击短信重发根据要求填写信息，单击提交后系统提示如下。
- 可能原因：填写的手机号码没有提交过备案申请，可能是手机号码变更或手机号码填写错误，系统无法匹配到需要进行短信核验的备案订单。
- 处理方法：请核对你的手机号码是否填写错误以及是否提交过备案申请，如未提交备案申请且需对小程序进行备案，在微信公众平台-首页-小程序备案-点击去备案，重新提交备案信息至管局审核。如已提交备案申请，且手机号填写无误，请核对你的手机号码是否已变更，如已变更请填写新的手机号码。  
   **提示：** 如你确认填写的信息正确无误，但系统还是提示你该条验证库里找不到记录，该问题可能是系统原因造成，实际备案信息已进入管局进行审核中，请你耐心等待管局审核。  
   ![](https://res.wx.qq.com/op_res/OWYK7BDs6Ghzl3zeFaPQKM29rNNDhrGV3GriAOgtQgv59rwRuZDJeud_IwiNlHxZFT3Qi3CjWhncha639QyTWA)

### [#](#_6、短信核验校验链接打不开怎么办？) 6、短信核验校验链接打不开怎么办？

如果你无法打开工信部向你发送的核验短信中的链接，可以直接访问[工信部备案管理系统](http://beian.miit.gov.cn/)进行短信核验。

### [#](#_7、小程序备案提交后，多久会收到管局的验证码短信？) 7、小程序备案提交后，多久会收到管局的验证码短信？

在小程序管理员收到【公众平台安全助手】公众号推送的“初审通过”模板消息后，5-10分钟左右会收到12381开头的核验短信，请根据[小程序备案类型](https://developers.weixin.qq.com/miniprogram/product/record/sms_verification.html#_8%E3%80%81%E5%B0%8F%E7%A8%8B%E5%BA%8F%E7%9A%84%E5%A4%87%E6%A1%88%E7%B1%BB%E5%9E%8B%E6%9C%89%E5%93%AA%E4%BA%9B%EF%BC%9F%E5%A6%82%E4%BD%95%E8%BF%9B%E8%A1%8C%E5%88%A4%E6%96%AD%EF%BC%9F)和[细分情况](https://developers.weixin.qq.com/miniprogram/product/record/sms_verification.html#_9%E3%80%81%E5%A6%82%E4%BD%95%E7%A1%AE%E5%AE%9A%E5%B7%A5%E4%BF%A1%E9%83%A8%E6%A0%A1%E9%AA%8C%E7%9F%AD%E4%BF%A1%E7%9A%84%E6%A0%B8%E9%AA%8C%E5%AF%B9%E8%B1%A1%EF%BC%9F%E6%98%AF%E5%8F%91%E9%80%81%E5%88%B0%E5%B0%8F%E7%A8%8B%E5%BA%8F%E8%B4%9F%E8%B4%A3%E4%BA%BA%E6%89%8B%E6%9C%BA%E8%BF%98%E6%98%AF%E4%B8%BB%E4%BD%93%E8%B4%9F%E8%B4%A3%E4%BA%BA%E6%89%8B%E6%9C%BA%EF%BC%9F)留意对应核验对象的手机短信，在收到短信后的24小时内完成验证即可。

### [#](#_8、小程序的备案类型有哪些？如何进行判断？) 8、小程序的备案类型有哪些？如何进行判断？

根据备案小程序的主体备案情况、小程序实际备案情况，所提交的备案申请会被分为不同的备案类型。具体类型说明如下：  
若需查询小程序或主体的备案信息，可参考：[备案信息相关](https://developers.weixin.qq.com/miniprogram/product/record/record_faq.html#%E5%8D%81%E4%B8%89%E3%80%81%E5%A4%87%E6%A1%88%E4%BF%A1%E6%81%AF%E7%9B%B8%E5%85%B3)

备案类型 | 类型说明 | 举例说明 || 首次备案 | 为无备案记录的主体增加新的小程序。 | 小程序主体无备案记录，小程序首次在微信平台提交备案申请，则此次备案类型为"首次备案"。 |
| 新增小程序 | 为已经完成备案的主体增加新的小程序。 | 小程序主体已有备案记录，小程序在微信平台提交备案申请，则此次备案类型为"新增小程序"。 |
| 新增接入 | 为已经完成备案的同主体且同名称小程序增加新的运行平台。 | 小程序1在A平台已完成备案且有备案号，与小程序1同主体且同名称小程序2在微信平台提交备案申请，则此次小程序2的备案类型为"新增接入"。 |
| 变更备案 | 为已经完成备案的小程序变更信息。 | 小程序已在微信平台完成备案且有备案号，但备案信息发生变化，如小程序昵称、小程序服务内容、负责人信息、证件信息等，则此次提交申请的备案类型为"变更备案"。 |
| 注销主体 | 为已经完成备案的主体注销备案。 | 小程序已在微信平台完成备案且有备案号，若需注销该主体下全部小程序、APP、网站、快应用等业务类型的备案信息，则此次提交申请的备案类型为"注销主体"。 |
| 注销服务 | 为已经完成备案的小程序注销备案。 | 小程序已在微信平台完成备案且有备案号，若需注销所有平台同主体同名称小程序的备案信息，则此次提交申请的备案类型为"注销服务"。 |
| 取消接入 | 为已经完成备案的微信小程序注销备案。 | 小程序已在微信平台完成备案且有备案号，若仅需注销微信小程序的备案信息，则此次提交申请的备案类型为"取消接入"。 |

### [#](#_9、如何确定工信部校验短信的核验对象？是发送到小程序负责人手机还是主体负责人手机？) 9、如何确定工信部校验短信的核验对象？是发送到小程序负责人手机还是主体负责人手机？

需根据备案小程序的实际备案类型、涉及的变更信息或发起对象来判断短信核验对象。具体判断条件如下：

备案类型 | 细分情况 | 短信核验对象 || 首次备案 | 首次备案 | 主体负责人手机号码 |
| 新增小程序 | 仅新增小程序 | 不验证 |
| 新增小程序同时变更主体信息 | 主体负责人手机号码 |
| 新增接入 | 仅新增接入 | 小程序负责人手机号码 |
| 新增接入同时变更小程序信息 | 小程序负责人手机号码 |
| 新增接入同时变更主体信息 | 主体负责人和小程序负责人手机号码 |
| 新增接入同时变更主体及小程序信息 | 主体负责人和小程序负责人手机号码 |
| 变更备案 | 仅变更主体信息 | 主体负责人手机号码 |
| 同时变更主体及小程序信息 | 主体负责人和小程序负责人手机号码 |
| 仅变更小程序信息 | 小程序负责人手机号码 |
| 注销主体 | 开发者自行发起 | 主体负责人手机号码 |
| 平台发起 | 主体负责人手机号码 |
| 注销服务 | 开发者自行发起 | 小程序负责人手机号码 |
| 取消接入 | 开发者自行发起 | 不验证 |

### [#](#_10、工信部校验短信的时效是多少？) 10、工信部校验短信的时效是多少？

最大核验次数为5次，有效验证时间为24小时，超过验证次数、超时或验证失败备案都将被管局系统驳回。  
备案提交至管局后，若超过12小时还未验证成功，工信部系统将自动重发一次短信，需在有效验证时间内完成验证，一旦超过24小时，不再支持发送短信，可等待备案被管局系统驳回后，重新提交新的备案申请。
