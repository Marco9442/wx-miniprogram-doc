# [#](#实验工具快速入门) 实验工具快速入门

【实验管理-实验前必读】 → 权限准备 → 新建实验 → 实验开发 → 发布实验 → 查看实验结果 → 全量实验

## [#](#一、权限准备) 一、权限准备

**使用实验工具的开发者，需要在小程序成员管理中具备数据分析权限，已开通微信支付的小程序，操作人员需要同时开通数据分析权限和交易分析权限。** 管理员可在小程序后台【成员管理】中修改和设置权限。

实验工具入口：[微信小程序后台](https://mp.weixin.qq.com) → 功能 → 实验工具。

## [#](#二、新建实验) 二、新建实验

找到入口，进入「实验工具」，点击「新建实验」，参考样例填写相关参数

- 实验指标：可使用系统默认提供的指标，自定义指标具体见【指标管理-指标创建】。
- **实验流量：新建实验需要设置实验层及实验总流量比例，各个实验组将均分流量。**
- 实验参数：实验参数、参数值用于开发同学区分实验和实验组，提供默认值，也可自定义填写。
- 实验修改：实验发布前支持修改流量、指标、实验分组。

## [#](#三、实验开发) 三、实验开发

通过基础库接口 `wx.getExptInfoSync(['wxapp_expt_test'])` 获取参数值，`wxapp_expt_test` 为实验参数，参数值为 '0' 为对照组、'1' 为实验组，具体见[实验 API](ExptAPI.md)。

用「测试微信号」测试

- **开发版、体验版** 上测试（建议使用）
- 在 [开发者工具（1.05.2106292 以上版本）](https://developers.weixin.qq.com/miniprogram/dev/devtools/download)且高于`2.17.1` 的基础库上测试，如获取不到重新编译运行即可。
- 测试完成后发布小程序。
