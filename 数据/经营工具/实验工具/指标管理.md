# [#](#指标管理) 指标管理

## [#](#一、事件创建) 一、事件创建

### [#](#_1-1-事件概述) 1.1 事件概述

事件是组成指标的最小单位，开发者可以实现基于事件的运算来定义指标。

开发者可以自定义事件的中英文名，系统会生成对应的事件上报代码，开发者可将这段代码加入小程序代码中需要监控的位置。并且可以通过测试来确认上报代码是否生效。

通过基础库接口 [wx.reportEvent](https://developers.weixin.qq.com/miniprogram/dev/api/data-analysis/wx.reportEvent.html) 上报事件数据。

系统默认提供的通用事件：

- 小程序访问。事件组合时「总和」表示访问耗时。
- 小程序停留。事件组合时「总和」表示停留时长。
- 小程序分享。事件组合时「总和」表示分享次数。
- 小程序支付。事件组合时「总和」表示支付金额。
- 小程序页面切换。事件组合时「总和」表示页面切换耗时。

## [#](#二、指标创建) 二、指标创建

### [#](#_2-1-指标概述) 2.1 指标概述

指标是实验效果评估的基础单元。

指标分为整数型指标、比例型指标、留存型指标：

- 整数型指标：通过简单计数计算得到的指标，如小程序访问 PV，小程序访问 UV 等指标。
- 比例型指标：通过简单计数型指标复合计算得到，主要是比例型指标，如曝光点击率，购买转化率等。
- 留存型指标：用户留存。

进入「We分析」实验工具的「实验指标」页面，可以查看到用户创建的指标列表：

![](https://res.wx.qq.com/op_res/clo3h8yS9OgH6u34v-jLlakikMzUWLAvboAeIpe2RLM1vNlFDyflO-OlnMyIclkLXnmO2WkLx_9PJhK8EqVfFg)

指标列表可以分为系统默认提供的通用指标以及用户自定义创建的指标。

系统默认提供的通用指标：

- 小程序访问次数：打开小程序的总次数。用户从打开小程序到主动关闭或超时退出小程序的过程，计为一次。
- 小程序访问人数：访问小程序的总用户数，同一用户多次访问不重复计。
- 小程序人均访问次数：平均每个用户打开小程序次数，即打开小程序的总次数/访问小程序的总用户数。
- 小程序人均停留时长：平均每个用户停留在小程序页面的总时长（单位为秒），即总停留时长/访问人数。
- 小程序次日活跃留存率：访问小程序的用户，在第 2 天再次访问小程序的用户数占比。
- 小程序支付金额：小程序内访问用户的非免密支付金额总和。
- 小程序支付人数：小程序内非免密支付成功人数，同一用户多次支付不重复计算。
- 小程序支付次数：小程序内非免密支付次数。
- 小程序次均支付金额：小程序内访问用户的非免密支付单次平均支付金额，即小程序支付金额/小程序支付次数。
- 小程序人均支付次数：暂不支持。
- 小程序分享次数：分享小程序页面的总次数。
- 小程序分享人数：分享小程序页面的总人数，同一用户多次分享不重复计。
- 小程序人均分享次数：小程序访问用户分享小程序页面的平均次数，即分享小程序页面的总次数/小程序访问人数。
- 小程序次均打开耗时：打开小程序的单次平均加载耗时（从用户点击小程序到首屏渲染完成的总加载耗时），即打开小程序总耗时/打开小程序次数。
- 小程序次均页面切换耗时：访问小程序页面切换过程中的单次平均加载耗时，即小程序页面切换的总耗时/页面切换次数。

### [#](#_2-2-新建整数型指标) 2.2 新建整数型指标

点击创建指标，指标类型选择整数型

![](https://res.wx.qq.com/op_res/QAHDzUVQUcv7vmklbgV3s1AoPr3Tj8UBhYguNI7OMTT4knNPRUO9CH37C0kcTm36Pk9F3fQPXw7OJZFVOt37fg)

数据类型

- 总和：PV 类型，默认对上报的 value 做求和操作，如果 value 为空，则默认 value 为 1，这里 value 必须是整型。
- 人数：UV 类型，默认对上报的事件用户 id 做唯一去重。
- 次数：CNT 类型，统计事件的上报次数。

事件组合：整数型指标只能选择单个事件，**通用指标不支持组合成整数型指标**。

### [#](#_2-3-新建比例型指标) 2.3 新建比例型指标

点击创建指标，指标类型选择比例型

![](https://res.wx.qq.com/op_res/NExjP3sfSE5OHATdhggEV7l8tTzSC7kkE4T7A3HSh_sZLJDt9snQypIPxWe1n8R_LidyCijmVuGhdJpdRP-0MQ)

数据类型

- 总和/人数：PV/UV 类型，主要计算人均指标。
- 总和/总和：PV/PV 类型，主要计算比例型指标。
- 总和/次数：PV/CNT 类型，主要计算次均指标。
- 次数/人数：CNT/UV 类型，主要计算人均次数指标

事件组合：对应比例类型，总和对应事件的 value 求和，人数对应事件的用户 id 唯一去重，次数对应事件上报次数。
