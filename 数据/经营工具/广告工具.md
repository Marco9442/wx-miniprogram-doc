# [#](#封面广告播控) 封面广告播控

## [#](#一、工具简介) 一、工具简介

小程序封面广告，是利用用户进入小程序时的加载时机，全屏展示广告的一种广告类型，其免开发且收益可观的广告位，受到开发者青睐。

开发者普遍关注封面广告对用户体验的影响，期望能自主控制广告展示；对此，微信广告持续迭代播控能力，**在保障基础播控能力的简单易用的前提下，关注满足开发者个性化需求**，目前已支持 4 类播控能力，下文将详细介绍。

## [#](#二、工具能力) 二、工具能力

## [#](#_2-1-场景值播控) 2.1 场景值播控

- **功能简介**  
  小程序场景值是用来描述用户进入小程序的场景，例如扫描二维码打开、微信钱包打开等。共分为 14 个大类，合计 139 个具体场景值细分，详细的场景值说明参见[场景值列表](https://developers.weixin.qq.com/miniprogram/dev/reference/scene-list)。
  场景值在一定程度上，能把不同体验敏感的场景区分开来，因此将其作为最基础的封面广告播控维度，支持开发者自定义选择。
- **操作指引**  
  进入[微信公众平台](https://mp.weixin.qq.com) 流量主板块，进入【广告管理 → 封面广告 → 场景设置】
  默认全部选中，流量主可根据实际用户体验保护需要进行调整。

![](https://res.wx.qq.com/op_res/Kqkp8iJ8-0AY_5ef4v47sXR97o3W3ZLM7HhplPKLR0PB436rtihWA1fhElRLO4lpSbiNfa3XY0pYRC9z3ishLA)

## [#](#_2-2-人群包播控) 2.2 人群包播控

- **功能简介**  
  人群包播控是对特定的用户群体的广告屏蔽能力，通过自传人群包和平台人群包的形式圈定目标用户，实现封面广告播控。
- **操作指引**

  1. 进入[We分析平台](https://wedata.weixin.qq.com/mp2/login)；
  2. 点击左下方开通【洞察分析】能力（仅首次需要）；
  3. 侧边栏进入【经营工具 - 广告工具 - 封面广告播控】；
  4. 选择人群包播控并点击【去配置】；
  5. 圈定目标屏蔽人群后点击【发布】，预计 10 分钟后生效；

     ![](https://res.wx.qq.com/op_res/Kqkp8iJ8-0AY_5ef4v47sedRdgvq5C0HKdScSft4xfETY_o3bmYtkRR2fR6neBMw1G0YKgaLbCMDUlzBATQi9A)
  6. 若不再需要屏蔽或有屏蔽人群变更需求，点击【播控详情】，将相关配置【结束应用/修改配置】即可。
- **使用限制**

  1. 自传号码包：以 csv 文件的形式上传用户 openid，最多支持 300MB，约千万个 OpenID 的屏蔽，文件命名不超过 20 个中文/40 个英文字符；
  2. 平台人群包：支持 7 类标签画像标签，多选生效逻辑为「且」（交集）。![](https://res.wx.qq.com/op_res/Kqkp8iJ8-0AY_5ef4v47sfY043cmQusYWbpcVK2YHKUiKUfWh2UanJQeVtaHG_S6BL31iTRg3dzXlpcG_M-c_g)
- **支持标签维度:**

  - 新老用户：用户是否首次进入小程序
  - 用户活跃标签：根据用户近 1 周内的活跃天数，区分其活跃程度
  - 访问用户流失标签：近半年有过访问行为的用户中，根据其近期连续不活跃的天数，区分其流失倾向
  - 终端类型：用户设备属性，ios/android
  - 省级地域：用户常驻的省级地域信息
  - 地级地域：用户常驻的市级地域信息
  - 城市级别：用户常驻的城市分级信息，划分为一线城市、新一线城市、二线城市等 8 类

## [#](#_2-3-小程序页面路径播控) 2.3 小程序页面路径播控

- **功能简介**  
  通过在页面路径下添加广告播控参数的方式，来实现针对不同的业务场景的封面广告播控，满足更精细化播控需求。  
  小程序页面路径（path）是指在小程序中跳转页面时使用的 URL 路径。  
  它在小程序内部是唯一的，类似于网页端的 URL 地址。

  ```
  onShareAppMessage() {
    return {
      title: '分享页面',
      path: '/pages/index/index?id=123',
    }
  }
  ```

  在上面的代码中，「page/index/index?id=123」就是小程序的页面路径。
- **操作指引**  
  开发者在小程序页面路径（path）下增加参数 isShowSplashAd，且赋值为 false，则通过该路径打开小程序时不展示封面广告，如下所示：

  ```
  onShareAppMessage() {
      return {
        title: '分享页面',
        path: '/pages/index/index?id=123&isShowSplashAd=false',
      }
  }
  ```
- **使用限制**  
  版本：安卓客户端版本 8.0.37 及以上，iOS 客户端版本 8.0.40 及以上；基础库 2.32.3 及以上  
  场景：仅限支持自定义小程序路径的场景，例如单聊/群聊小程序消息卡片等

## [#](#_2-4-普通二维码链接地址播控) 2.4 普通二维码链接地址播控

- **功能简介**  
  普通二维码进入小程序是比较典型且常见的使用方式，特别是针对以线下服务为主的小程序；
  通过在管理后台维护二维码码值地址包，实现广告展示控制；若用户扫码码值命中该地址包时，则不展示封面广告，保护体验；反之正常展示，产生收入。

![](https://res.wx.qq.com/op_res/Kqkp8iJ8-0AY_5ef4v47sWanRv0fTPcxFJRHhYK6NSXFDh14iVt0XeE3DeoFo-XrASZLIv8uof1PseVBKj3AGA)

- **操作指引**
  1. 进入[We分析平台](https://wedata.weixin.qq.com/mp2/login)；
  2. 点击左下方开通【洞察分析】能力（仅首次需要）；
  3. 侧边栏进入【经营工具 - 广告工具 - 封面广告播控】；
  4. 选择普通二维码链接地址播控并点击【去配置】；
     ![](https://res.wx.qq.com/op_res/Kqkp8iJ8-0AY_5ef4v47sWMxLiNPxBbNMZ5cfnzEUHZfXQPxHHUkfLOlySf2N04u3V4exGyOfPwwAvQzQELitw)
  5. 按照示例，以 .csv 文件的形式上传二维码码值地址包（10M 以内，约 20 万条链接），文件命名不超过 20 个中文/40 个英文字符；
  6. 上传完成后点击发布，具体生效时间以发布后提示为准；  
      ![](https://res.wx.qq.com/op_res/Kqkp8iJ8-0AY_5ef4v47sbv8UhEL8Lw2j32PMybV4wEJjBKyBMF1dPSSIOgUqEd-hQDOU08ceHZ8W0rE1Ez2CQ)
  7. 如需修改，按照上述路径，选择【更新配置】并重新上传文件发布即可。

## [#](#_2-5-小程序码链接地址播控) 2.5 小程序码链接地址播控

- **功能简介**  
  开发者调用小程序码生成接口时，传入播控参数，用户扫码时按照码值携带参数情况展示广告。

![](https://res.wx.qq.com/op_res/Kqkp8iJ8-0AY_5ef4v47sWwVD2xg3Rnagea7W7G1N6EWuXi_G_pG87xlzXwItgqyyja5CiBvgzMW9MEROA26jA)

- **操作指引**  
  在原有无数量限制的小程序码生成规则[（接口文档→）](https://developers.weixin.qq.com/miniprogram/dev/server/API/qrcode-link/qr-code/api_getunlimitedqrcode)的基础上，新增传入请求参数，即可生成带有广告播控参数的小程序码。

| 属性 | 类型 | 默认值 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| show\_splash\_ad | boolean | true | 否 | 控制通过该小程序码进入小程序是否展示封面广告。1、默认为 true，展示封面广告；2、传入为 false 时，不展示封面广告。 |

请求示例：

```
{ 
 "page": "pages/index/index",
 "scene": "a=1",
 "check_path": true,
 "env_version": "release",
 "show_splash_ad": true
}
```
