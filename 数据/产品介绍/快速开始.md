# [#](#「We分析」数据分析平台) 「We分析」数据分析平台

## [#](#_1-产品简介) 1. 产品简介

随着微信基础建设的完善（小程序、服务号、订阅号、视频号等），在微信内建立服务体系，逐步成为各行业的标配。通过微信的能力，商家能为自己的目标用户提供更好的服务。与此同时，各商家对微信域产生的数据分析需求，也逐步追求精细化、个性化、系统化。

为更好满足商家对经营和分析的需求，微信官方推出「We分析」数据分析平台，提供更健全的数据分析工具。目前We分析已提供 Web 端、小程序端，小程序开发者/商家可按需使用。

- **Web 端：** <https://wedata.weixin.qq.com/>
- **小程序端：** 可在微信 APP 内，搜索「We分析」

## [#](#_2-能力简介) 2. 能力简介

作为小程序官方数据平台，「We分析」将重点提供以下 3 类能力：

**（1）数据分析：** 提供平台统计数据、行为分析模型、BI 数据报表等多项数据分析服务，帮助小程序开发者/商家深入洞察经营数据，更高效得发现业务问题与潜在机会。

**（2）性能质量：** 提供小程序性能数据、接口监控、JS 分析等多项小程序性能质量相关的产品功能，帮助开发者了解当前性能现状，及时发现线上故障，保障小程序用户的日常使用体验。

**（3）经营工具：** 提供小程序开发者/商家，在日常经营过程中，使用到的各项经营工具，例如可进行 A/B 测试的**实验工具**，可统计分析各项推广素材的**推广分析**，帮助小程序开发者/商家提高经营效率。

## [#](#_3-如何使用) 3. 如何使用

We分析无需任何额外的注册或开通流程。当在微信公众平台创建小程序后，微信官方将会自动生成该小程序的We分析账号。

当小程序的任意成员，首次使用该小程序的We分析时，会自动将当前【小程序的项目成员】同步至【We分析的项目成员】进行初始化。

初始化完成后，两边平台的项目成员不互通。即如果后续需要添加新的项目成员登录该小程序的We分析账号，需在We分析下的【平台管理-成员管理】单独进行添加操作，并设置相应的权限。
