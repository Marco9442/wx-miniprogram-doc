# [#](#调试相关说明) 调试相关说明

在开发者工具中开发小程序时，根据项目【设置】->【采集配置】->【启动方式】配置的不同，会有不同的表现：

1. "自动启动" 模式下：为避免影响调试，不会自动开启采集。（小于 3.2.3 的旧版本基础库还会自动开启采集，此时 network 面板会看到一些相关请求，如影响调试则选择新版本基础库）
2. "自定义启动" 模式下：只要调用了 `setup` 方法就会开启采集，如不希望在开发者工具环境中启用，可判断仅 `wx.getSystemInfoSync().platform !== 'devtools'` 时调用 `setup` 方法。
