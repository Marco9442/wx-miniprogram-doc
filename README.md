# 微信小程序官方 Markdown 全量离线文档

> 本项目收录微信小程序官方完整文档（包含 3,852 篇独立排版的完整 Markdown 网页），为 AI Agent、RAG 向量检索系统、LLM 以及开发者离线查阅提供结构化文档与导航索引。

---

## 核心特性

- **去重与全页排版**：按官方网页唯一 URL 独立去重，忠实保留完整排版与上下文，无 Fragment 碎片切割。
- **精炼清晰的目录结构**：移除了锚点产生的冗余层级，按“介绍、开发、设计、数据、安全、运营”六大核心分类存放。
- **AI Agent & LLM 检索友好**：提供 `llms.txt` 与 `doc-index.json` 全量元数据索引，方便 RAG 检索与上下文接入。

---

## 核心索引文件

- `llms.txt`: 面向 LLM / Agent 的全局导航与说明
- `doc-index.json`: 3,852 篇 Markdown 完整页面的结构化 JSON 文件清单

---

## 六大核心目录分类

1. **介绍 (`介绍/`)**：小程序背景、接入指南、第三方平台接入与客服指南。
2. **开发 (`开发/`)**：框架、组件、前端 API、服务端 API、云开发/云服务与 AI 平台能力。
3. **设计 (`设计/`)**：微信小程序设计指南、适老化设计规范、大屏适配指南与无障碍规范。
4. **数据 (`数据/`)**：数据分析、体验分析与自定义埋点。
5. **安全 (`安全/`)**：安全门禁、微信网关与数据安全规范。
6. **运营 (`运营/`)**：小程序运营规范、服务条款与类目资质要求。

---

## 离线阅读与接入建议

1. **AI / LLM / Cursor / Copilot 接入**：在项目中添加根目录，或使用 `llms.txt` / `doc-index.json` 进行精准路径定位。
2. **本地文档阅读**：使用任意支持 Markdown 格式的编辑器（如 VSCode, Obsidian 等）进行离线检索与浏览。
