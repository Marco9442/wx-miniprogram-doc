# [#](#服务直达) 服务直达

小程序开发者通过接入搜一搜提供的各类搜索自定义模版，可在搜索结果页前置展示部分服务信息，与搜一搜达成搜索服务直达技术合作。

### [#](#二、合作筛选标准) 二、合作筛选标准

为提高用户搜索体验，搜一搜将在申请合作的开发者中筛选服务质量最佳的开发者进行合作对接。

| 指标 | 详细指标 |
| --- | --- |
| 数据质量 | 数据覆盖度 |
| 结果精度 |
| 数据安全性 |
| 小程序体验 | 服务质量 |
| 页面体验 |
| 合作方影响力 | 小程序规模 |
| 行业影响力 |
| 资质要求 |

#### [#](#_2-1-指标-数据质量) 2.1 指标-数据质量

开发者需确保数据的丰富性、时效性，真实性，安全性（非其他站点数据），具体标准如下：

1. 1.数据覆盖度

   指标定义：开发者提供的数据覆盖度需在行业内处于top5水平，不得有明显的覆盖缺失，如地域性缺失、行业性缺失等。

1. 2.结果精度

   指标定义：开发者在搜索场景提供的相关信息（包含服务）的准确度。

   搜一搜抽检开发者提供的相关业务的信息数据准确度，合作方信息数据准确度不得低于96%。

1. 3.数据安全性

   开发者需保证数据的安全性，提供的数据信息真实有效，且数据不得来自于其他站点。

#### [#](#_2-2-指标-小程序体验) 2.2 指标-小程序体验

| 评价维度 | 详细标准 | 标准分级-好 | 标准分级-中 | 标准分级-差 |
| --- | --- | --- | --- | --- |
| 服务质量 | 页面简洁，服务直达 | 服务颗粒度精准，且体验通畅 | 页面为聚合链接，但可用 | 杂乱，页面聚合不好定位服务 |
| 加载速度 | 快速打开，且体验流畅 | 中 | 慢/无法正常打开 |
| 页面体验 | 无广告 | ✓ |  |  |
| Banner广告、格子广告 | / | 不影响服务的体验和流程 | 可能会误触广告，影响服务的体验和流程 |
| 插屏广告 | / | 不影响服务的体验和流程 | 信息杂乱，容易误触，影响服务的体验和流程 |
| 激励式广告 |  | 用户可不看直接选择关闭继续使用服务，不影响服务的体验和流程 | 强制性观看， 影响服务的体验和流程 |

#### [#](#_2-3-指标-合作方影响力) 2.3 指标-合作方影响力

1. 1.小程序规模

   为保证用户在微信生态内的搜索体验，要求所接入的开发者对应小程序的月均日活跃用户数不低于10000。
2. 2.行业影响力

   指标定义：开发者需提供在全网行业内的排名以及基础服务情况，全网行业排名不得低于TOP5。（基础服务情况包括但不限于小程序DAU、MAU、 覆盖城市等）
3. 3.资质要求

   小程序开发者需符合微信小程序开放的服务类目中的资质要求并提供相应证明。[小程序开放的服务类目](https://developers.weixin.qq.com/miniprogram/product/material/)。
